> **컨벌루션 신경망(CNN: Convolutional Neural Network)**은 하위 레이어와 상위 레이어의 유닛을 부분적으로만 연결해 모델 복잡도를 낮추고 과잉 적합을 피하면서, **영상 인식(image recognition)** 분야에서 뛰어난 성능을 내는 신경망 구조다. 입력층에서 컨벌루션 연산으로 **특징맵(feature map)**을 만들고 **풀링(pooling)**으로 차원을 줄이는 과정을 여러 차례 반복한 뒤, 말단의 **완전 연결 레이어(fully connected layer)**에서 추출된 특징을 종합해 물체를 분류한다.

### 학습 목표와 컨벌루션 신경망(CNN)의 개요
- **학습 목표**
  - **컨벌루션 신경망(CNN)**의 구조와 동작 원리 이해
  - CNN을 활용한 **영상 인식(image recognition)** 원리 이해
- **부분 연결 구조와 과잉 적합 방지**
  - 부분 연결 = 하위 레이어 유닛과 상위 레이어 유닛 전체를 잇지 않고 일부만 연결하는 구조
  - 연결 축소 → 모델 복잡도 감소 → **과잉 적합(과대 적합)** 방지
  - 바이어스 보유 = 일반 신경망과 마찬가지로 컨벌루션 신경망도 **바이어스(bias)**를 포함함
- **중요성과 주요 용도**
  - 위상과 성능 = 신경망 구조 가운데 뛰어난 성능을 보이는 모델 중 하나로, 여러 문제 중 특히 **영상 인식** 분야에서 가장 두드러진 성과를 거둠
  - 주요 활용 분야:
    - 이미지 종류 판별 및 내용 이해 기반 분류 · 주석 부여
    - 이미지 내부 물체 추적
    - 숫자 및 얼굴 인식
- **실습 항목**
  - **Lab: 컨벌루션 네트워크 체험하기** = 강의자료에 제목만 제시된 실습 항목(세부 절차 텍스트 미기재)

### 생물학적 기원과 네오코그니트론(Neocognitron)
- **고양이 시각 피질 연구에서 얻은 영감**
  - 연결 패턴의 기원 = 고양이 시각 세포의 연결 방식에서 착안
  - 허벨(Hubel) · 위젤(Wiesel)(1962) = 노벨상 수상 신경학자로, 시각 피질에 **단순 세포**와 **복합 세포** 두 종류의 세포가 존재함을 발견함
- **네오코그니트론(Neocognitron)**
  - 제안 배경 = **후쿠시마(Kunihiko Fukushima)**가 1980년 발표한 패턴 인식용 신경망 구조
  - 계층적 모델 구성 = 허벨과 위젤이 밝힌 단순 세포 · 복합 세포 원리를 패턴 인식에 적용하기 위해 두 유형의 세포를 계층 구조로 배치함
  - 기본 레이어 도입 = 이후 CNN의 두 가지 기본 구성 요소인 **컨벌루션 레이어**와 **서브 샘플링 레이어**를 처음 도입함

### CNN의 일반적인 구조와 계층별 역할
- **전체 구조의 이분화**
  - 전체 아키텍처 = 앞단의 **특징 추출(feature extraction)** 영역 + 말단의 **물체 분류(object classification)** 영역으로 구성됨
  - 특징 추출 구간 = 컨벌루션 레이어와 풀링 레이어를 교대로 여러 차례 반복 배치함
  - 물체 분류 구간 = 신경망 맨 끝에 전통적인 완전 연결 분류 신경망을 배치함
- **계층별 처리 단계**
  - 1단계(입력층) = 입력 데이터를 신경망으로 전달하며, 여기서 컨벌루션 연산을 통해 특징을 뽑아내는 **특징맵(feature map)**이 형성됨
  - 2단계(풀링 연산) = **풀링(Pooling)**을 적용해 입력 데이터의 차원을 축소함
  - 3단계(계층 반복) = 컨벌루션 레이어와 풀링 레이어 연산을 여러 번 되풀이함
  - 4단계(최종 물체 인식) = 마지막에 놓인 완전 연결 구조의 전통적 분류 신경망이 앞단에서 추출된 특징을 입력받아 물체를 인식함

### 컨벌루션 연산의 원리와 신경망 적용
- **컨벌루션(Convolution) 연산의 정의**
  - 정의 = 대상 위치 주변의 화소값에 각각 가중치를 곱해 모두 더한 값으로 새로운 화소값을 산출하는 연산
- **영상 처리에서의 구체적 예: 라플라시안 연산자**
  - 필터 구성 = 중앙 값만 8이고 나머지 주변 값이 모두 −1인 필터를 적용하는 사례
  - **라플라시안 연산자** = 위와 같은 가중치 구조를 지니며 영상에서 **에지(edge)**를 검출하는 필터 → 영상에 적용 시 에지가 추출된 결과를 얻음
- **신경망에서의 컨벌루션 필터 특성**
  - 사전 설계 미사용 = 특정 특징을 뽑으려고 가중치를 사전에 고정한 필터를 미리 제작하지 않음
  - 해석 불가성 = CNN 내부에서 개별 컨벌루션 필터가 구체적으로 어떤 특징을 추출하는지는 사전에 알 수 없음
- **컨벌루션 레이어 내부 연산 흐름**
  - 1단계(선형 결합) = 이전 레이어의 값 X에 각 커널 가중치 W를 곱해 합산하고 바이어스 b를 더해 `WX + b`를 구함
  - 2단계(활성화 통과) = 계산된 `WX + b`를 `ReLU()` 같은 활성화 함수에 통과시킴
  - 3단계(출력 저장 및 필터 이동) = 결과값 `ReLU(WX + b)`를 다음 레이어의 동일한 위치에 기록한 뒤, 가중치 필터를 한 칸 옮겨 동일 연산을 이어 감

### 하이퍼 파라미터와 출력 크기 계산
- **컨벌루션 레이어 출력 크기 결정 요소**
  - 3가지 **하이퍼 파라미터** = **필터 크기(filter size)**, **보폭(stride)**, **패딩(padding)**
- **보폭(stride)**
  - 정의 = 입력 데이터 위에서 커널을 옮겨가며 적용하는 간격 거리
  - 보폭 = 1 → 한 번에 1픽셀씩 이동하며 커널 적용
  - 보폭 = 2 → 픽셀을 하나씩 건너뛰며 커널 적용
- **패딩(padding)**
  - 목적 = 이미지 가장자리 픽셀에 커널을 적용할 때 경계 영역을 처리하기 위한 기법
  - **패딩의 종류** = `valid`, `same`
- **커널의 개수**
  - 다중 커널 학습 = 단일 컨벌루션 레이어에서 여러 커널을 동시에 학습하는 경우가 많으며, 128개 또는 256개 커널도 자주 사용됨
- **출력 크기 계산 공식**
  - 변수 정의:
    - 입력 크기 = (n, m, 3)
    - 필터 크기 = (f, f)
    - 필터 개수 = c · 보폭 = s · 패딩 = p
  - 출력 크기 = ((n + 2p − f)/s + 1, (m + 2p − f)/s + 1, c)
- **출력 크기 계산 예제**
  - 조건 = 입력 크기 (32 × 32 × 3) · 10개의 (5 × 5) 필터 · 보폭 s = 1 · 패딩 p = 2
  - 가로 · 세로 계산(위 공식 대입) = (32 + 2·2 − 5)/1 + 1 = 32
  - 출력 채널 수 = 필터 개수 c = 10 → 최종 출력 크기 (32 × 32 × 10)

### 풀링(Pooling)과 완전 연결 레이어(Fully Connected Layer)
- **풀링(Pooling) / 서브 샘플링(Sub-sampling)**
  - 정의 = 컨벌루션 레이어 등에서 전달된 입력 데이터의 크기를 줄여 차원을 축소하는 연산
  - **풀링의 종류** = 강의자료에 소제목만 제시된 항목(구체적 유형 구분은 텍스트 미기재)
- **풀링의 장점**
  - 계산 속도 향상 = 레이어 크기 감소 → 연산 부담이 줄어 계산 속도가 빨라짐
  - 과적합 억제 = 레이어 크기 감소 → 신경망의 매개변수 수가 줄어들어 과적합 발생 가능성이 낮아짐
  - 공간 이동 둔감성 = 공간 내에서 물체 위치가 이동해도 결과가 바뀌지 않음 → 물체의 공간 이동 변화에 둔감해짐
- **완전 연결 레이어(Fully Connected Layer)**
  - **평탄화(Flatten)** = 직전 레이어의 출력을 1차원 벡터로 변환함
  - 전결합 및 가중치 갱신 = 변환된 1차원 벡터의 원소들과 완전 연결 레이어의 모든 뉴런이 연결되며, 학습 과정에서 연결 가중치를 업데이트함
  - 라벨 분류 = 컨벌루션 레이어와 풀링 레이어가 뽑아낸 특징들을 종합해 정의된 라벨로 물체를 분류함

### 핵심 요약
- **CNN의 정의와 기원** = 영상 인식에 널리 쓰이는 신경망으로, 고양이 시각 세포 연구(허벨 · 위젤)와 네오코그니트론(후쿠시마) 등 동물의 조직에서 영감을 얻어 발전함
- **부분 연결과 과잉 적합 방지** = 하위 레이어 노드와 상위 레이어 노드를 부분적으로만 연결해 복잡도를 낮추고 과대 적합에 빠지지 않음
- **컨벌루션 연산** = 주변 화소값에 가중치를 곱해 더한 뒤 새 화소값을 만들고, 신경망 내에서는 바이어스와 `ReLU()` 활성화 함수를 거쳐 다음 레이어에 저장함
- **풀링(서브 샘플링)** = 입력 데이터의 크기를 줄여 연산 속도를 높이고 매개변수를 감소시키며 공간 이동에 둔감하게 만듦
- **완전 연결 레이어** = 앞선 레이어 출력을 1차원 벡터로 평탄화해 모두 연결한 뒤, 추출된 특징을 종합해 라벨로 분류함
