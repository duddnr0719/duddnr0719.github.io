# HTML
## <!DOCTYPE> 선언
- 브라우저가 올바르게 웹 페이지를 표시할 수 있도록 도움.
- 웹 페이지에 사용된 HTML의 종류와 버전을 알고 있어야 브라우저는 올바르게 HTML 페이지를 표시할 수 있다.
- <!DOCTYPE html>은 HTML5 버전을 의미한다.
## 주석
- <!-- … -->을 사용하여 주석 처리를 한다.
- 브라우저에 의하여 무시되고 표시되지 않는다.
## 헤드와 바디
- HTML 문서는 크게 헤드와 바디로 구성 된다.
- <head> … </head> : 문서의 제목, 문자 인코딩, 외부 파일 연결 등 메타데이터(데이터에 대한 데이터)를 포함한다.
- <title> : HTML 문서의 제목을 정의
- 요소 : 시작 태그와 종료 태그로 이루어진 HTML 문서의 구성 요소
- 속성 : 요소에 대한 추가적인 정보
- <body> … </body> : 실제 브라우저 화면에 표시되는 모든 콘텐츠(텍스트, 이미지, 비디오 등)를 담는다.
  - <body> 안에 텍스트 입력 시 엔터키를 사용하여 줄 바꿈을 하여도 브라우저에는 표시되지 않는다.
> 💡 
태그 이름은 대소문자를 구별하지 않는다. → <head> = <HEAD>
하나의 요소 안에 다른 요소들이 포함될 수 있다.
시작 태그와 종료 태그 사이의 연속된 공백은 하나의 공백으로 취급한다.
- <p> : 문단, 한 개의 단락을 생성한다.
- <br> : 강제 줄 바꿈 태그.
- <pre> : 프로그래머가 입력한 그대로 화면에 표시하는 태그
- <h> : 헤딩, 웹 페이지의 headline / h1 ~ h6까지 존재, 번호가 작아질 수록 표시되는 글자의 크기가 커진다.
### 텍스트 서식
- <b> : 볼드체로 만든다.
- <i> : 이탤릭체로 만든다.
- <strong> : 텍스트를 강하게 표시한다.
- <em> : 텍스트를 강조한다.
- <code> : 텍스트가 코드임을 표시한다.
- <sup> : 위첨자
- <sub> : 아래첨자
- <hr> : 수평선
### 특수문자
- &nbsp; : non-breaking space : 공백 문자 한 개
- &lt; : < (less than)
- &gt; : > (greater than)
- &quot; : “
- &amp; : &
### 리스트
: 항목들을 나열하는데 사용
- <ol> : 번호 있는 리스트 (ordered list)
- <ul> : 번호 없는 리스트 (un-ordered list)
- <li> : 리스트 항목 생성
→ <ol> / <ul> 로 리스트 생성 후 <li> 태그를 사용하여 리스트 항목을 생성한다.
- <dl> : 정의 리스트 → 항목들과 함께 항목들의 정의가 표시되는 리스트
### 이미지
- <img> 태그를 사용하여 생성한다.
- src 속성을 사용하여 이미지 파일 이름을 지정한다.
- width, height 속성을 사용하여 가로, 세로 크기를 설정한다.
- alt 속성을 사용하여 이미지가 표시되지 않을 경우 화면에 표시되는 대체 텍스트를 설정한다.
### 하이퍼링크
- <a> 태그를 사용하여 하이퍼링크를 사용한다.
- href 속성을 사용하여 하이퍼링크 페이지를 설정한다.
- target 속성을 사용하여 링크가 클릭 되었을 때 새로운 페이지가 어디에 열릴 지 지정한다.
  - _blank : 새로운 윈도우에서 새로운 페이지를 연다
  - _self : 현재 윈도우에 새로운 페이지를 적재한다.
  - _parent : 부모 프레임에 새로운 페이지를 적재한다.
  - _top : 현재 윈도우에 새로운 페이지를 적재하고 모든 프레임을 취소한다.
### 테이블
- 표 형태의 데이터를 표시할 때 사용
- <table> 태그를 사용하여 정의
- 행은 <tr> , 데이터는 <td> 를 사용하여 표현
- <thead>를 사용하여 테이블 헤더 정의 
- <caption>을 사용하여 테이블의 이름을 설정
- <tbody>를 사용하여 테이블의 값 설정
- rowspan 속성을 사용하여 열 병합, colspan 속성을 사용하여 행 병합
### 비디오
- 웹페이지에 비디오를 삽입할 때 사용
- <video> 태그를 사용하여 정의
- <video src=”…” (속성) (제어기여부)> 의 형태로 사용
  - video 태그의 속성
    - autoplay : 비디오를 자동으로 재생한다.
    - controls : 브라우저가 비디오 재생을 제어하는 컨트롤러를 표시한다.
    - loop : 비디오를 반복하여 재생한다.
    - poster : 비디오를 다운로드할 때 표시하는 이미지
    - preload : 사용자가 사용할 생각이 없더라도 전체 비디오를 다운로드한다.
    - muted : 비디오 출력을 중지한다.
    - src : 재생할 비디오가 존재하는 URL을 지정한다.
    - width, height : 비디오 재생기의 너비와 높이를 지정한다.
### 오디오
- 웹페이지에 오디오를 삽입할 때 사용
- <audio> 태그를 사용하여 정의
- <audio src=”…” (속성) (제어기여부)> 의 형태로 사용
  - audio 태그의 속성
    - autoplay : 음악을 자동으로 재생한다.
    - controls : 브라우저가 오디오 재생을 제어하는 제어기를 표시한다.
    - loop : 오디오를 반복하여 재생한다.
    - preload : 사용자가 사용할 생각이 없더라도 오디오를 미리 다운로드한다.
    - src : 재생할 오디오가 존재하는 URL을 지정한다.
    - volume : 오디오의 재생 볼륨을 설정한다.(0.0 ~ 1.0)
