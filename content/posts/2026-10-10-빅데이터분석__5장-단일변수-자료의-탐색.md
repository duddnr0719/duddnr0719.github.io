> 변수 하나를 들여다볼 때, 범주형이면 개수를 세서(table) 막대·원그래프로, 양적이면 대표값(평균, 중앙값)과 퍼짐(분산, 표준편차, 사분위수)을 구하고 히스토그램·상자그림으로 본다.
### 데이터 탐색 (EDA)
- 분석 과정: 문제 정의 → 수집 → 전처리(7장) → **탐색(5~6장)** → 분석 → 보고
- 본격 분석 전에 데이터를 직관적으로 관찰하는 가벼운 분석: 개수, 비율, 평균 같은 간단한 기술통계와 그래프
- 목적
  - 분포 확인, 값이 예상 범위에 있는지
  - 결측치(NA), 이상치(outlier) 같은 문제 발견
  - 변수 간 관계 확인 (상관, 회귀)
  - 문제 정의 때 몰랐던 패턴 발견
- 단일변수(지진 횟수, 환자 수) / 다중변수(키와 몸무게의 관계)
| 자료 | 단일변수 탐색 |
|---|---|
| 범주형(질적) | 빈도, 최빈값, 비율 → 막대·원그래프 |
| 수치형(양적) | 평균, 분산, 표준편차, 왜도, 첨도 → 히스토그램, 상자그림 |
- 왜도와 대표값의 위치
  - 오른쪽 꼬리(양의 왜도): 최빈값 < 중앙값 < 평균
  - 대칭: 평균 = 중앙값 = 최빈값
  - 왼쪽 꼬리(음의 왜도): 평균 < 중앙값 < 최빈값
- 다중변수: 범주-범주는 교차표·막대, 수치-수치는 산점도·피어슨 상관계수, 범주-수치는 그룹별 상자그림 비교 (6장)
### 자료의 종류
| 대분류 | 소분류 | 설명 | 예 |
|---|---|---|---|
| 질적(범주형) | 명목 | 크기·순서 없음 | 혈액형, 지역, 종교 |
| | 순서 | 크기는 없지만 순서 있음 | 학력, 학년 |
| 양적(숫자형) | 이산 | 셀 수 있음 | 통화 건수, 쪽수, 취업자 수 |
| | 연속 | 구간에서 측정 | 키, 몸무게, 온도, 강수량 |
- 질적: 대소 비교·산술 불가 / 양적: 대소 비교, 평균·최댓값 계산 가능
- 단일변수(일변량) → R의 벡터, 다중변수(다변량) → 매트릭스·데이터프레임
| | 분석 기법 |
|---|---|
| 단일 범주형 | 도수분포표, 카이제곱 적합도 검정, 막대·원그래프 |
| 단일 양적 | 중심(평균, 중앙값, 최빈값), 산포(분산, 표준편차, 범위, IQR), 치우침(왜도, 첨도), 히스토그램·상자그림 |
| 범주 X → 범주 Y | 분할표, 카이제곱 독립성 검정, 모자이크 플롯 |
| 범주 X → 양적 Y | t-검정, ANOVA |
| 양적 X → 범주 Y | 의사결정나무, 로지스틱 회귀 |
| 양적 X → 양적 Y | 상관분석, 회귀분석, 산점도 |
### 범주형: 도수분포표와 그래프
```r
favorite <- c("WINTER", "SUMMER", "SPRING", "SUMMER", "SUMMER",
              "FALL", "FALL", "SUMMER", "SPRING", "SPRING")
table(favorite)                     # FALL 2, SPRING 3, SUMMER 4, WINTER 1
table(favorite) / length(favorite)  # 0.2 0.3 0.4 0.1 (비율)

ds <- table(favorite)
barplot(ds, main = "favorite season")
pie(ds, main = "favorite season")
```
- `table()`에 두 변수를 넣으면 **교차표(분할표)**
```r
gender <- c("남", "여", "여", "남", "남", "여", "남", "여", "남", "여")
result <- c("합격", "불합격", "합격", "합격", "불합격", "합격", "합격", "불합격", "합격", "합격")
table(gender, result)
#       result
# gender 불합격 합격
#     남      1    4
#     여      2    3
```
- 숫자로 코딩된 범주(1 = 초록, 2 = 빨강, 3 = 파랑)도 똑같이
```r
favorite.color <- c(2, 3, 2, 1, 1, 2, 2, 1, 3, 2, 1, 3, 2, 1, 2)
ds <- table(favorite.color)        # 1: 5, 2: 7, 3: 3
colors <- c("green", "red", "blue")
names(ds) <- colors                # green 5, red 7, blue 3
barplot(ds, main = "favorite color", col = colors)
pie(ds, main = "favorite color", col = colors)
```
- 플롯 창: Zoom(큰 창으로), Export(이미지·PDF 저장, 클립보드 복사). 창이 너무 작으면 `figure margins too large` 에러
### 양적: 평균, 중앙값, 절사평균
- 평균 x̄ = (x₁ + x₂ + … + xₙ) / n, 중앙값 = 크기순 정렬 시 가운데 값
- 극단값에 평균은 끌려가고 중앙값은 버팀: 60, 62, 64, 65, 68, 69, **120** → 중앙값 65, 평균 72.57
- **절사평균**: 위아래 n%를 잘라내고 평균
```r
weight <- c(60, 62, 64, 65, 128)
mean(weight)               # 75.8
median(weight)             # 64
mean(weight, trim = 0.2)   # 63.66667  (위아래 20% = 60과 128 제외)
```
### 사분위수
- 크기순으로 4등분하는 세 지점 Q1, Q2(= 중앙값), Q3. 각 구간에 25%씩. R에선 `quantile()`
```r
mydata <- c(60, 62, 64, 65, 68, 69, 120)
quantile(mydata)
#   0%  25%  50%  75% 100%
# 60.0 63.0 65.0 68.5 120.0
quantile(mydata, (0:10) / 10)   # 10% 단위
summary(mydata)
#  Min. 1st Qu. Median   Mean 3rd Qu.   Max.
# 60.00   63.00  65.00  72.57   68.50 120.00
```
- 사분위수 계산법은 여러 가지라 교재 그림(14 ~ 47의 12개 값을 3개씩 나누기)과 R 결과가 다를 수 있음: 같은 자료로 `quantile()`은 Q1 = 16.75, Q3 = 39.5, `fivenum()`은 16.5, 40 (R 기본값은 선형 보간인 type 7)
### 산포도
- 분산 s² = Σ(xᵢ − x̄)² / (n − 1), 표준편차 s = √s². 작을수록 평균 근처에 몰려 있음
- n−1로 나누는 건 **표본** 분산이라서 (R의 `var()`, `sd()`도 n−1)
```r
var(mydata)          # 447.2857
sd(mydata)           # 21.14913
range(mydata)        # 60 120  (최솟값, 최댓값)
diff(range(mydata))  # 60      (통계학의 범위)
```
### 히스토그램
- 연속형은 "값의 종류"가 없으니 **구간(계급)** 을 나누고 구간별 개수를 셈
```r
dist <- cars[, 2]                    # 자동차 제동거리 (cars: 속도·제동거리 50건)
hist(dist,
     main = "Histogram for 제동거리",
     xlab = "제동거리", ylab = "빈도수",
     border = "blue", col = "green",
     las = 2,                         # x축 글씨 방향 (0~3)
     breaks = 5)                      # 계급 수 (R은 보기 좋게 근사해서 정함)
```
| | 막대그래프 | 히스토그램 |
|---|---|---|
| 대상 | 범주형 | 연속형 |
| 막대 간격 | 있음 | 없음 (붙어 있음) |
| 면적 | 의미 없음 | 의미 있음 (빈도 ∝ 면적) |
### 상자그림
- 사분위수를 그림으로. 위치 척도(중앙값, 사분위수)를 써서 이상치에 강함
- 구성: 상자 아래 변 Q1, 굵은 선 중앙값, 위 변 Q3, 상자 길이 **IQR = Q3 − Q1**(가운데 50%), 수염(정상 범위 안의 최소·최대), 점(이상치)
- 정상 범위: Q1 − 1.5·IQR ~ Q3 + 1.5·IQR. 수염은 이 범위 **안에 있는 실제 값**까지
```r
boxplot(dist, main = "자동차 제동거리")
boxplot.stats(dist)
# $stats  2 26 36 56 93    ← 아래 수염, Q1, 중앙값, Q3, 위 수염
# $n      50
# $conf   29.29663 42.70337
# $out    120              ← 이상치
quantile(dist)   # 2 26 36 56 120
```
- 계산 확인: IQR = 56 − 26 = 30 → 위 한계 56 + 45 = 101 → 101 이하 최댓값 93이 수염, 120은 이상치 (아래 한계 −19라 아래쪽 이상치 없음)
- `$conf` = 중앙값 ± 1.58 × IQR / √n = 36 ± 1.58 × 30 / √50 = (29.30, 42.70) — 중앙값의 약 95% 신뢰구간 (노치)
- 그룹별 상자그림: `boxplot(Petal.Length ~ Species, data = iris, main = "품종별 꽃잎의 길이")` (`~` 왼쪽이 값, 오른쪽이 그룹)
