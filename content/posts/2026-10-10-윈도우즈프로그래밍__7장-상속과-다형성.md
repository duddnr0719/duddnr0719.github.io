> 상속은 클래스 쪽 중복을, 다형성은 쓰는 쪽(호출부) 중복을 없앤다. 부모 타입으로 다룰 때 자식의 동작이 나오게 하려면 virtual/override(오버라이딩), new는 그냥 가리기(하이딩)라 부모 타입에선 부모 것이 나온다.
### 왜 상속인가
- Dog와 Cat에 `Age`, `Eat()`, `Sleep()`이 똑같이 들어 있음 → 중복은 생산성·유지보수의 적
- 공통 부분을 부모 `Animal`로 올리고, 자식은 `class 자식 : 부모`
```csharp
class Animal
{
    public int Age { get; set; }
    public Animal() { this.Age = 0; }
    public void Eat()   { Console.WriteLine("냠냠 먹습니다."); }
    public void Sleep() { Console.WriteLine("쿨쿨 잠을 잡니다."); }
}

class Dog : Animal
{
    public string Color { get; set; }
    public void Bark() { Console.WriteLine("왈왈 짓습니다."); }
}

class Cat : Animal
{
    public void Meow() { Console.WriteLine("냥냥 웁니다."); }
}
```
- 자식은 부모의 public·protected 멤버를 그대로 사용 (`Eat();`), 부모를 명시적으로 가리킬 땐 `base`
- C# 클래스는 부모를 **하나만** 상속 가능 (다중 상속은 인터페이스로)
### 접근 제한자
| 제한자 | 같은 클래스 | 자식 클래스 | 같은 어셈블리(프로젝트) | 다른 어셈블리 |
|---|---|---|---|---|
| public | O | O | O | O |
| protected internal | O | O | O | 자식만 O |
| internal | O | 같은 어셈블리면 O | O | X |
| protected | O | O | X (자식이 아니면) | 자식만 O |
| private | O | X | X | X |
```csharp
class Animal
{
    private void Private() { }
    protected void Protected() { }
    public void Public() { }
    public void TestA() { Private(); Protected(); Public(); }   // 자기 안: 전부 OK
}
class Dog : Animal
{
    public void TestB() { Protected(); Public(); }             // 자식: private만 불가
}
// 외부: dog.Public()만 가능
```
### 다형성
- 자식 인스턴스를 **부모 타입 변수**에 담을 수 있음: `Animal dog = new Dog();`
  - 겉 타입은 Animal이라 Animal의 멤버만 보임 (Bark 호출 불가), 실체는 Dog
- 호출부 중복 제거
```csharp
List<Animal> animals = new List<Animal>()
{
    new Dog(), new Cat(), new Cat(), new Dog(),
};
foreach (var item in animals)
{
    item.Eat();
    item.Sleep();
}
```
- 무작정 `((Cat)item).Meow()` → Dog가 섞여 있으면 `InvalidCastException: 'Dog' 형식 객체를 'Cat' 형식으로 캐스팅할 수 없습니다`
- 모든 클래스는 자동으로 최상위 **`Object`**를 상속 (`Equals`, `GetHashCode`, `GetType`, `ToString` 등을 가짐) → `List<Object>`에는 Dog, Cat, 52, 52.273 무엇이든 담김 (값 형식은 박싱)
### is와 as
- `객체 is 클래스`: 그 타입(또는 그 자식)이면 true. Dog 인스턴스라면 `is Dog`, `is Animal`, `is Object` 모두 true
- 변환 두 가지
  - `(클래스)변수`: 실패하면 **예외**
  - `변수 as 클래스`: 실패하면 **null** (참조 형식에만)
```csharp
foreach (var item in animals)
{
    item.Eat();
    item.Sleep();

    if (item is Dog) ((Dog)item).Bark();

    var cat = item as Cat;
    if (cat != null) cat.Meow();

    // 최신 C# 패턴 매칭: 검사와 변환을 한 번에
    // if (item is Dog d) d.Bark();
}
```
### 상속과 생성자
- 자식 생성 시 **부모 생성자 → 자식 생성자** 순서로 호출 (부모 쪽을 먼저 초기화)
- `: base(인자)`로 어떤 부모 생성자를 부를지 지정
```csharp
class Parent
{
    public Parent()             { Console.WriteLine("Parent()"); }
    public Parent(int param)    { Console.WriteLine("Parent(int param)"); }
    public Parent(string param) { Console.WriteLine("Parent(string param)"); }
}
class Child : Parent
{
    public Child() : base(10)             { Console.WriteLine("Child() : base(10)"); }
    public Child(string input) : base(input) { Console.WriteLine("Child(string input) : base(input)"); }
}

new Child();          // Parent(int param) → Child() : base(10)
new Child("string");  // Parent(string param) → Child(string input) : base(input)
```
### 섀도잉과 하이딩
- 이름 재사용 종류: 오버로딩, 오버라이딩, 섀도잉, 하이딩, 업스큐어링
- **섀도잉**: 가까운 범위의 이름이 먼 범위를 가림. 클래스 변수 number = 10이 있어도 Main 안에서 `int number = 20;` 하면 20
- **하이딩**: 자식이 부모와 같은 이름의 멤버를 선언해 부모 것을 가림
```csharp
class Parent { public int variable = 273; }
class Child : Parent { public new string variable = "hiding"; }

Child child = new Child();
Console.WriteLine(child.variable);             // hiding
Console.WriteLine(((Parent)child).variable);   // 273 (가려졌을 뿐 그대로 있음)
```
- `new`를 안 붙이면 경고 CS0108 ("상속된 멤버를 숨깁니다. 숨기려면 new 키워드를 사용하십시오") — 의도한 거라면 `new`로 명시
### 하이딩 vs 오버라이딩
| | 하이딩 | 오버라이딩 |
|---|---|---|
| 키워드 | 자식에 `new` | 부모 `virtual`, 자식 `override` |
| 대상 | 변수, 메서드 | 메서드(속성, 이벤트) |
| 부모 타입으로 호출하면 | **부모** 것 | **자식** 것 |
```csharp
class Animal { public virtual void Eat() { Console.WriteLine("냠냠 먹습니다."); } }
class Dog : Animal { public new void Eat()      { Console.WriteLine("강아지 사료를 먹습니다."); } }
class Cat : Animal { public override void Eat() { Console.WriteLine("고양이 사료를 먹습니다."); } }

foreach (Animal a in new Animal[] { new Dog(), new Cat() })
    a.Eat();
// 냠냠 먹습니다.          ← Dog는 하이딩이라 Animal 타입에선 부모 것
// 고양이 사료를 먹습니다.  ← Cat은 오버라이딩이라 실제 타입 것
```
- 셋 다 하이딩이면 리스트 전체가 "냠냠", 셋 다 오버라이딩이면 각자 사료 → **다형성의 핵심은 오버라이딩**
### 상속·오버라이딩 제한
- **sealed**
  - 클래스: 더 이상 상속 불가 (`class Child : Parent` → CS0509 "sealed 형식에서 파생될 수 없습니다")
  - 메서드: `sealed public override void Test()` → 손자 클래스에서 재정의 불가 (CS0239)
- **abstract**
  - 클래스: 직접 `new` 불가, 반드시 상속해서 사용
  - 메서드: 본문 없이 선언만 (`public abstract void Speak();`), 자식이 **반드시** override. abstract 메서드는 abstract 클래스 안에만
```csharp
abstract class Shape
{
    public abstract double Area();          // 자식이 꼭 구현
    public void Print() { Console.WriteLine(Area()); }
}
class Circle : Shape
{
    public double R;
    public override double Area() { return Math.PI * R * R; }
}
```
### 윈도 폼에서의 상속과 다형성
- `public partial class Form1 : Form` → 내 폼은 Form을 상속
- `Controls.Add(Control value)`: Button은 Control → ButtonBase(추상) → Button으로 이어지는 자식이라 다형성으로 그냥 넣을 수 있음
- **MessageBox.Show()**: 20개 넘게 오버로딩된 static 메서드
```csharp
private void button1_Click(object sender, EventArgs e)
{
    MessageBox.Show("내용");
    MessageBox.Show("내용", "제목");

    DialogResult result;
    do
    {
        result = MessageBox.Show("내용", "제목", MessageBoxButtons.RetryCancel);
    } while (result == DialogResult.Retry);   // '다시 시도'를 누르는 동안 반복
}
```
  - 버튼 종류: `OK`, `OKCancel`, `YesNo`, `YesNoCancel`, `RetryCancel`, `AbortRetryIgnore` / 반환은 `DialogResult`
- **enum(열거형)**: 숫자에 이름을 붙인 자료형
```csharp
enum OrderState { Ordered, Paymented, Prepared, Sended };   // 0, 1, 2, 3
if (OrderCheck(12345) == OrderState.Ordered)
    Console.WriteLine("주문 완료되었습니다.");
```
- 새 창 띄우기
  - 코드로: `class CustomForm : Form { public CustomForm() { Text = "제목 글자"; } }`
  - 디자이너로: 솔루션 탐색기 → 추가 → 양식(Windows Form) → `Form2.cs` + `Form2.Designer.cs`
  - `form.Show()`: **모달리스** — 새 창이 떠 있어도 원래 창 조작 가능
  - `form.ShowDialog()`: **모달** — 새 창을 닫기 전엔 원래 창 조작 불가 (설정 창, 확인 대화상자)
