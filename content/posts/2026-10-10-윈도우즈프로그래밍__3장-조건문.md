> 범위로 나눌 땐 if / else if, 딱 떨어지는 값으로 나눌 땐 switch, 값 하나를 고를 땐 조건 연산자 `? :`. C#의 switch는 문장이 있는 case에서 다음 case로 흘러내리지 않는다.
### if
- 불 표현식이 `true`면 실행, `false`면 건너뜀. 실행할 문장이 한 줄이면 중괄호 생략 가능, 여러 줄이면 필수
```csharp
static void Main(string[] args)
{
    Console.Write("숫자 입력: ");
    int input = int.Parse(Console.ReadLine());

    if (input % 2 == 0)
    {
        Console.WriteLine("짝수입니다!");
    }
    if (input % 2 == 1)
    {
        Console.WriteLine("홀수입니다!");
    }
}
```
- 입력 `52273` → `홀수입니다!`
- 주의: C#의 `%`는 왼쪽 부호를 따르므로 `-3 % 2`는 `-1` → 음수 홀수는 위 코드에서 아무것도 출력되지 않음. `input % 2 != 0`으로 쓰는 게 안전
- 중괄호 스타일: `if (true)` 다음 줄에 `{`를 두는 게 MS 공식 C# 코딩 규칙의 기본
- 현재 시간: `DateTime.Now.Year / Month / Day / Hour / Minute / Second`
```csharp
if (DateTime.Now.Hour < 12) Console.WriteLine("오전입니다.");
if (12 <= DateTime.Now.Hour) Console.WriteLine("오후입니다.");
```
### if else
- 서로 반대인 두 경우. if를 두 번 쓰면 비교가 2번, if else는 1번이라 더 효율적
```csharp
if (input % 2 == 0)
    Console.WriteLine("짝수입니다!");
else
    Console.WriteLine("홀수입니다!");
```
### 중첩 조건문과 if else if
- 조건문 안에 조건문
```csharp
if (DateTime.Now.Hour < 11)
{
    Console.WriteLine("아침 먹을 시간입니다.");
}
else
{
    if (DateTime.Now.Hour < 15)
        Console.WriteLine("점심 먹을 시간입니다.");
    else
        Console.WriteLine("저녁 먹을 시간입니다.");
}
```
- else 블록의 중괄호를 없애면 그게 바로 **if else if**: 겹치지 않는 조건 3개 이상을 순서대로 검사
```csharp
if (DateTime.Now.Hour < 11)
    Console.WriteLine("아침 먹을 시간입니다.");
else if (DateTime.Now.Hour < 15)
    Console.WriteLine("점심 먹을 시간입니다.");
else
    Console.WriteLine("저녁 먹을 시간입니다.");
```
- 범위 비교는 `4.0 < score < 4.5`처럼 못 씀 (`'<' 연산자는 bool 및 double 형식의 피연산자에 적용할 수 없습니다`) → `4.0 < score && score < 4.5`
- else if는 앞 조건에서 걸러진 나머지만 오므로 **아래쪽 경계는 생략 가능**
```csharp
double score = 3.6;
if (score == 4.5)        Console.WriteLine("신");
else if (4.2 <= score)   Console.WriteLine("교수님의 사랑");
else if (3.5 <= score)   Console.WriteLine("현 체제의 수호자");     // ← 3.6은 여기
else if (2.8 <= score)   Console.WriteLine("일반인");
else if (2.3 <= score)   Console.WriteLine("일탈을 꿈꾸는 소시민");
else if (1.75 <= score)  Console.WriteLine("오락문화의 선구자");
else if (1.0 <= score)   Console.WriteLine("불가촉천민");
else if (0.5 <= score)   Console.WriteLine("자벌레");
else if (0 < score)      Console.WriteLine("플랑크톤");
else                     Console.WriteLine("시대를 앞서가는 혁명의 씨앗");
```
### switch
- 값 하나를 여러 `case` 값과 비교. 맞는 case부터 실행하다 `break`를 만나면 switch를 빠져나감, 맞는 게 없으면 `default`
```csharp
Console.Write("숫자를 입력하세요: ");
int input = int.Parse(Console.ReadLine());
switch (input % 2)
{
    case 0:
        Console.WriteLine("짝수입니다.");
        break;
    case 1:
        Console.WriteLine("홀수입니다.");
        break;
}
```
- **case 묶기**: 문장이 없는 case는 다음 case로 이어짐
```csharp
switch (input)
{
    case 12:
    case 1:
    case 2:
        Console.WriteLine("겨울입니다.");
        break;
    case 3: case 4: case 5:
        Console.WriteLine("봄입니다.");
        break;
    case 6: case 7: case 8:
        Console.WriteLine("여름입니다.");
        break;
    case 9: case 10: case 11:
        Console.WriteLine("가을입니다.");
        break;
    default:
        Console.WriteLine("대체 어떤 행성에 살고 계신가요?");
        break;
}
```
- C/Java와 다른 점: **문장이 있는** case가 break 없이 다음 case로 흘러가면 컴파일 오류(CS0163). 반드시 `break`, `return`, `goto case`, `throw` 같은 점프문으로 끝나야 함
- 연습문제 O/X 정리
  - case 뒤의 여러 줄 문장은 중괄호가 필요 없음 (X)
  - "case는 반드시 break로 끝나야 한다"도 X: 빈 case는 그냥 이어지고, break 대신 return·goto 등도 가능
- switch vs if: **범위** 비교면 if, 딱 떨어지는 값이면 읽기 좋은 쪽 아무거나
### 조건 연산자 (삼항 연산자)
- `불_표현식 ? 참일 때 값 : 거짓일 때 값`
  - 참·거짓 쪽은 **같은 자료형**, 문장이 아니라 **값을 내는 표현식**이어야 함
  - 한 줄로 명확할 때만
```csharp
int number = int.Parse(Console.ReadLine());
Console.WriteLine(number > 0 ? "자연수입니다" : "자연수가 아닙니다");
Console.WriteLine(number % 2 == 0 ? "짝수" : "홀수");
```
- 피연산자 수: 단항(`-x`), 이항(`a + b`), 삼항 — C#의 삼항 연산자는 조건 연산자 하나뿐
### 응용
- 메서드의 bool 반환값을 조건으로: `string.Contains()`
```csharp
Console.Write("입력: ");
string line = Console.ReadLine();
if (line.Contains("안녕"))
    Console.WriteLine("안녕하세요...!");
else
    Console.WriteLine("^^");
```
- 키 입력: `Console.ReadKey()`는 `ConsoleKeyInfo`를 반환, `.Key`는 `ConsoleKey` 열거형 → switch와 잘 어울림
```csharp
ConsoleKeyInfo info = Console.ReadKey();
switch (info.Key)
{
    case ConsoleKey.UpArrow:    Console.WriteLine("위쪽으로 이동");   break;
    case ConsoleKey.RightArrow: Console.WriteLine("오른쪽으로 이동"); break;
    case ConsoleKey.DownArrow:  Console.WriteLine("아래쪽으로 이동"); break;
    case ConsoleKey.LeftArrow:  Console.WriteLine("왼쪽으로 이동");   break;
    default:                    Console.WriteLine("다른 키를 눌렀습니다"); break;
}
```
### 연습문제 예시 풀이
- 중첩 → 단일: `if (x > 10) { if (x < 20) … }` = `if (x > 10 && x < 20)`
- 띠 구하기: 출생 연도 % 12 → 0 원숭이, 1 닭, 2 개, 3 돼지, 4 쥐, 5 소, 6 호랑이, 7 토끼, 8 용, 9 뱀, 10 말, 11 양
```csharp
int year = int.Parse(Console.ReadLine());
string[] tti = { "원숭이", "닭", "개", "돼지", "쥐", "소", "호랑이", "토끼", "용", "뱀", "말", "양" };
Console.WriteLine($"{year}년생은 {tti[year % 12]}띠입니다.");   // 2000 → 용띠
```
