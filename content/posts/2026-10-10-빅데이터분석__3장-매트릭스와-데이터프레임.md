> 2차원 표에서 모든 칸이 같은 자료형이면 매트릭스, 열마다 달라도 되면 데이터프레임. 둘 다 `[행, 열]`로 접근하고, 데이터프레임은 `$열이름`, `subset()`, `read.csv()`/`write.csv()`를 자주 쓴다.
### R 자료구조 정리
| 구조 | 차원 | 자료형 |
|---|---|---|
| 벡터 | 1차원 | 모두 같음 |
| 리스트 | 1차원 | 달라도 됨 |
| 매트릭스 | 2차원 | 모두 같음 |
| 데이터프레임 | 2차원 | **열마다** 달라도 됨 (같은 길이 벡터들의 리스트) |
- 표 용어: 세로 = **열(column) = 변수(variable)**, 가로 = **행(row) = 관측값(observation)**, 칸 = 셀
### 매트릭스 만들기
```r
z <- matrix(1:20, nrow = 4, ncol = 5)                # 기본은 열 방향으로 채움
#      [,1] [,2] [,3] [,4] [,5]
# [1,]    1    5    9   13   17
# [2,]    2    6   10   14   18
# [3,]    3    7   11   15   19
# [4,]    4    8   12   16   20

z2 <- matrix(1:20, nrow = 4, ncol = 5, byrow = TRUE) # 행 방향으로 채우기
# [1,] 1 2 3 4 5 / [2,] 6 7 8 9 10 / …
```
- 벡터·매트릭스 붙이기: `cbind()`(열로 붙임), `rbind()`(행으로 붙임)
```r
x <- 1:4; y <- 5:8
cbind(x, y)      # 4행 2열, 열 이름 x, y
rbind(x, y)      # 2행 4열, 행 이름 x, y
rbind(rbind(x, y), x)   # 행 하나 더
cbind(z, x)      # z 오른쪽에 열 x 추가
```
### 값 추출
```r
z[2, 3]          # 10   (2행 3열)
z[1, 4]          # 13
z[2, ]           # 2 6 10 14 18  (2행 전체)
z[, 4]           # 13 14 15 16   (4열 전체)
z[2, 1:3]        # 2 6 10
z[1, c(1, 2, 4)] # 1 5 13
z[1:2, ]         # 1~2행
z[, c(1, 4)]     # 1, 4열
```
- 주의: 행 전체는 반드시 쉼표를 붙여 `z[2, ]`. 슬라이드의 `z[2]`는 쉼표가 없어서 행이 아니라 **2번째 원소 하나(값 2)** 가 나옴 (매트릭스도 내부적으론 열 방향으로 늘어선 벡터라서)
- 행·열 이름
```r
score <- matrix(c(90, 85, 69, 78,
                  85, 96, 49, 95,
                  90, 80, 70, 60), nrow = 4, ncol = 3)
rownames(score) <- c("John", "Tom", "Mark", "Jane")
colnames(score) <- c("English", "Math", "Science")

score["John", "Math"]              # 85
score["Tom", c("Math", "Science")] # Math 96, Science 80
score["Mark", ]                    # Mark의 전 과목
score[, "English"]                 # 모든 학생의 영어
colnames(score)[2]                 # "Math"
```
### 데이터프레임
- 서로 다른 자료형의 벡터들을 세로로 묶은 표
```r
city <- c("Seoul", "Tokyo", "Washington")
rank <- c(1, 3, 2)
city.info <- data.frame(city, rank)
#         city rank
# 1      Seoul    1
# 2      Tokyo    3
# 3 Washington    2
```
- **iris**: R 내장 데이터. 붓꽃 150송이, 품종별 50송이
| 열 | 의미 | 자료형 |
|---|---|---|
| Sepal.Length / Sepal.Width | 꽃받침 길이 / 폭 | 숫자 |
| Petal.Length / Petal.Width | 꽃잎 길이 / 폭 | 숫자 |
| Species | 품종 (setosa, versicolor, virginica) | 팩터 |
```r
iris[, c(1:2)]                       # 1, 2열
iris[, c("Sepal.Length", "Species")] # 이름으로
iris[1:5, ]                          # 1~5행
iris[1:5, c(1, 3)]
```
### 기본 정보 확인
```r
dim(iris)        # 150 5
nrow(iris); ncol(iris)
colnames(iris)   # names()와 같음
head(iris); tail(iris)   # 앞/뒤 6행
str(iris)
# 'data.frame': 150 obs. of 5 variables:
#  $ Sepal.Length: num 5.1 4.9 4.7 …
#  $ Species     : Factor w/ 3 levels "setosa","versicolor",..: 1 1 1 …
unique(iris[, 5])        # setosa versicolor virginica
table(iris[, "Species"]) # 각 50
```
- `str()` 읽기: 150 obs.(행) × 5 variables(열), `num`은 숫자형, `Factor w/ 3 levels`의 `1 1 1`은 품종을 정수 코드로 표현한 것
### 자주 쓰는 함수
```r
colSums(iris[, -5])    # 876.5 458.6 563.7 179.9   (-5: 5번째 열 제외)
colMeans(iris[, -5])   # 5.843333 3.057333 3.758000 1.199333
rowSums(iris[, -5]); rowMeans(iris[, -5])
t(z)                   # 전치 (행 ↔ 열)
```
- 조건으로 행 고르기: `subset(데이터, 조건)`
```r
IR.1 <- subset(iris, Species == "setosa")                  # 50행
IR.2 <- subset(iris, Sepal.Length > 5.0 & Sepal.Width > 4.0)
#    Sepal.Length Sepal.Width Petal.Length Petal.Width Species
# 16          5.7         4.4          1.5         0.4  setosa
# 33          5.2         4.1          1.5         0.1  setosa
# 34          5.5         4.2          1.4         0.2  setosa
IR.2[, c(2, 4)]
```
- 산술 연산은 원소별: `2 * a`, `a + b`, `b / a`, `a * b`(행렬곱이 아니라 원소곱; 행렬곱은 `%*%`)
### 자료구조 확인·변환
```r
class(iris)              # "data.frame"
class(state.x77)         # "matrix" "array"  (매트릭스 = 2차원 배열)
is.matrix(state.x77)     # TRUE
is.data.frame(iris)      # TRUE

st <- data.frame(state.x77)         # 매트릭스 → 데이터프레임
iris.m <- as.matrix(iris[, 1:4])    # 데이터프레임 → 매트릭스 (숫자 열만; 팩터가 섞이면 전부 문자로)
```
- 열 하나를 꺼낼 때 결과 형태가 다름
| 코드 | 결과 | 매트릭스 | 데이터프레임 |
|---|---|---|---|
| `iris[, "Species"]`, `iris[, 5]` | 벡터 | O | O |
| `iris["Species"]`, `iris[5]` | 데이터프레임 | X | O |
| `iris$Species` | 벡터 | X | O |
### csv 읽기·쓰기
- 엑셀 표 → `.csv`(쉼표 구분)로 저장 → R에서 읽으면 **데이터프레임**
```r
setwd("D:/source")                                   # 작업 폴더
air <- read.csv("airquality.csv", header = TRUE)     # 첫 줄이 열 이름
head(air)
#   Ozone Solar.R Wind Temp Month Day
# 1    41     190  7.4   67     5   1
# 5    NA      NA 14.3   56     5   5   ← 결측값 NA

my.iris <- subset(iris, Species == "setosa")
write.csv(my.iris, "my_iris.csv", row.names = FALSE) # 행 번호 빼고 저장
```
- 슬라이드 코드 `subset(iris, Species='Setosa')`는 두 군데가 틀림
  - `=`는 비교가 아니라 인자 이름 지정이라 "extra argument 'Species' will be disregarded" 경고와 함께 **150행 전체**가 저장됨
  - 품종 값도 소문자 `"setosa"`
  - 올바른 코드는 `Species == "setosa"` (R 4.3으로 확인: 150행 → 50행)
### 자료형 확인 함수
- 기본 자료형: 수치형(double), 정수형(`100L`, integer), 문자형, 논리형, 팩터형
- `typeof(1)` → "double", `typeof(100L)` → "integer", `mode(1L)` → "numeric"
- `is.numeric()`, `is.character()` … (확인) / `as.numeric()`, `as.character()` … (변환)
