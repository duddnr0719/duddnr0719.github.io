> 회귀 = 독립변수로 종속변수를 설명·예측하는 식 찾기. 단순·다중 선형회귀는 `lm()`(최소제곱법, R²로 설명력 평가, stepAIC로 변수 선택), 종속변수가 범주면 로지스틱 회귀 `glm(family = binomial)`(로짓 → 시그모이드로 확률).
### '회귀'의 유래
- 갈톤(1885): 키 큰 부모의 자녀는 평균보다 크지만 부모보다는 대개 작고, 키 작은 부모의 자녀는 반대 → 키가 **평균으로 돌아가려는(regression toward mediocrity)** 경향
### 용어
- **독립변수**(설명변수): 결과에 영향을 주는 요인 / **종속변수**(반응변수): 그 영향으로 정해지는 값
| 모델 | 종속변수 | 독립변수 |
|---|---|---|
| 아이스크림 판매 | 판매량 | 일평균 기온 |
| 광고 효과 | 월 매출 | 온라인·TV·인쇄 광고비 |
| 집값 | 아파트 매매가 | 면적, 방 수, 지역, 연식 |
| 성적 | 시험 점수 | 출석률, 학습 시간, 수면 시간 |
| 이직 | 이직 여부(0/1) | 근속 연수, 월급, 만족도 |
- 종류: **단순**(독립변수 1개), **다중**(2개 이상), **로지스틱**(종속변수가 범주 → 사실상 분류: 스팸, 암 양성, 고객 이탈, 합격)
### 단순선형 회귀와 최소제곱법
- y = β₀ + β₁x + ε (ε ~ N(0, σ²), 오차·잔차)
- **최소제곱법**: 잔차 제곱합 S = Σ(yᵢ − b₀ − b₁xᵢ)²를 최소로 하는 b₀, b₁ → b₀, b₁로 각각 편미분해 0으로 놓고 풀면
  - **b₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)² = Sxy / Sxx** (= 공분산 / x의 분산)
  - **b₀ = ȳ − b₁x̄** (회귀선은 항상 평균점 (x̄, ȳ)을 지남)
- 예: 기온(20~40℃) vs 아이스크림 판매량 9일치 → **ŷ = 10.07x − 103.31**
- 예: 자동차 예약 대수 x(11, 19, …, 49) vs 실제 판매 y(29, 33, …, 89) → **ŷ = 9.74 + 1.44x**, 예측값 25.5(25.6), 37.1, 42.8, …, 80.3
### R: lm()
```r
plot(dist ~ speed, data = cars)        # 산점도로 선형성 확인
model <- lm(dist ~ speed, cars)        # 종속 ~ 독립 (순서 고정)
model
# (Intercept) -17.579   speed 3.932
abline(model)                          # 회귀선

b <- coef(model)[1]                    # 절편 -17.57909
W <- coef(model)[2]                    # 기울기 3.932409
W * 30 + b                             # 속도 30 → 100.3932
W * 35 + b                             # 120.0552
W * 40 + b                             # 139.7173
# 같은 계산: predict(model, data.frame(speed = c(30, 35, 40)))

pred <- W * cars$speed + b
compare <- data.frame(예상 = pred, 실제 = cars$dist, 오차 = pred - cars$dist)
head(compare)
#      예상 실제      오차
# -1.849460    2 -3.849460
# -1.849460   10 -11.849460
#  9.947766    4  5.947766 …
```
- 속도 4에서 제동거리가 −1.85로 나옴 → 회귀식은 관측 범위(4~25) 근처에서만 믿을 것. 30, 35, 40은 **범위 밖 외삽**이라 실제와 다를 수 있음
### 변동분해와 결정계수
- Σ(Yᵢ − Ȳ)² = Σ(Ŷᵢ − Ȳ)² + Σ(Yᵢ − Ŷᵢ)² → **SST = SSR + SSE**
| | 편차 | 제곱합 | 자유도 |
|---|---|---|---|
| 총 (SST) | Yᵢ − Ȳ | Σ(Yᵢ − Ȳ)² | n − 1 |
| 회귀로 설명됨 (SSR) | Ŷᵢ − Ȳ | Σ(Ŷᵢ − Ȳ)² | 1 |
| 설명 안 됨 (SSE, 잔차) | Yᵢ − Ŷᵢ | Σ(Yᵢ − Ŷᵢ)² | n − 2 |
- **결정계수 R² = SSR / SST = 1 − SSE / SST** (0~1): 종속변수 변동 중 회귀가 설명하는 비율. 단순회귀에선 상관계수의 제곱 (cars는 R² = 0.651)
- **분산분석표(ANOVA)**: MSR = SSR / 1, MSE = SSE / (n − 2), **F = MSR / MSE** → F가 클수록 p-value가 작고 회귀식이 유의미
### 다중선형 회귀
- y = α + β₁x₁ + β₂x₂ + … + βₚxₚ + ε (예: 매출 = 1625 + 2100·가격 + 15·광고비 + 8.4·매장 수)
```r
library(car)                       # Prestige 데이터 (carData)
newdata <- Prestige[, 1:4]         # education, income, women, prestige
plot(newdata, pch = 16, col = "blue", main = "Matrix Scatterplot")
mod1 <- lm(income ~ education + prestige + women, data = newdata)
summary(mod1)
#              Estimate Std. Error t value Pr(>|t|)
# (Intercept)  -253.850   1086.157  -0.234    0.816
# education     177.199    187.632   0.944    0.347
# prestige      141.435     29.910   4.729 7.58e-06 ***
# women         -50.896      8.556  -5.948 4.19e-08 ***
# Residual standard error: 2575 on 98 degrees of freedom
# Multiple R-squared: 0.6432, Adjusted R-squared: 0.6323
# F-statistic: 58.89 on 3 and 98 DF, p-value: < 2.2e-16
```
- 읽는 법
  - 각 계수의 p-value(별표): 그 변수가 의미 있는지. education은 0.347로 유의하지 않음
  - 맨 아래 F 검정 p-value: 모델 전체가 의미 있는지
  - **수정 R²**: 변수 수를 감안한 설명력 (변수를 넣기만 해도 오르는 R²의 단점 보정)
  - 해석 예: 직업 위신 점수 1점 ↑ → 소득 약 141 ↑, 여성 비율 1%p ↑ → 소득 약 51 ↓ (다른 변수 고정 시)
### 변수 선택: AIC와 stepAIC
- **오컴의 면도날**: 같은 설명력이면 단순한 모델. 변수가 많으면 과적합 위험, 필요한 데이터도 늘어남
- **AIC = 2P + n·log(RSS / n)** (P 변수 수, n 데이터 수) → 변수 k개 추가하면 2k 벌점. **작을수록 좋음**
- 단계적 회귀: 변수를 넣고 빼며 AIC 최소 모델 탐색. `MASS::stepAIC(model, direction = "backward" | "forward" | "both")` (기본 both)
```r
library(MASS)
mod2 <- lm(income ~ education + prestige + women + census, data = Prestige[, 1:5])
mod3 <- stepAIC(mod2)
# Start AIC = 1607.93 → census 빼면 1606.0 (최소) → 제거
# Step  AIC = 1606.03 → education 빼면 1605.0 (최소) → 제거
# Step  AIC = 1604.96 → <none>이 최소 → 종료
summary(mod3)
# income ~ prestige + women
# (Intercept) 431.574, prestige 165.875 (< 2e-16), women -48.385 (4.02e-08)
# R-squared 0.64, Adjusted R-squared 0.6327, F = 87.98
```
- 변수 4개 → 2개로 줄였는데 수정 R²는 0.6323 → **0.6327**로 오히려 조금 상승 = 빠진 변수들은 설명에 기여하지 않았음
### 로지스틱 회귀
- 종속변수가 범주면 직선으로 맞출 수 없음 (확률은 0~1인데 직선은 −∞~∞)
- **Odds** = p / (1 − p) (성공 확률 / 실패 확률)
| | 환자 | 비환자 | p | Odds |
|---|---|---|---|---|
| 흡연 | 80 | 40 | 2/3 | 2 |
| 비흡연 | 20 | 60 | 1/4 | 1/3 |
  - **Odds ratio** = 2 / (1/3) = **6**: 흡연군의 발병 odds가 비흡연군의 6배 ("확률이 6배"가 아님: 확률 비는 (2/3)/(1/4) = 2.67)
- **로짓** = ln(Odds): p가 0 → 1/2 → 1일 때 odds는 0 → 1 → ∞, 로짓은 −∞ → 0 → +∞ → 이제 선형식으로 둘 수 있음
  - ln(p / (1 − p)) = β₀ + β₁x₁ + … + β_q x_q
  - 풀면 **p = 1 / (1 + e^−(β₀ + β₁x₁ + …))** = 시그모이드(S자) 함수
- 계수 해석: x가 1 늘면 odds가 **e^β배** (β = 0.7 → e^0.7 ≈ 2.01배)
- 절차: ① **최우추정법**(최소제곱 아님)으로 계수 추정 ② 로짓 → 시그모이드로 확률 p ③ 임계값(보통 0.5)으로 0/1 분류
- 시그모이드는 z = 0 근처에서 급격히 변해 애매한 구간(0.3 < p < 0.7)을 줄여 줌
- **다항 로짓**: 범주가 N개(영화 장르 예측 등) → 기준 범주 N에 대한 로그 비 ln(P(Y = j) / P(Y = N)) = αⱼ + βⱼ'x 를 N − 1개
### R 실습과 주의할 점
```r
iris.new <- iris
iris.new$Species <- as.integer(iris.new$Species)   # setosa 1, versicolor 2, virginica 3
mod.iris <- glm(Species ~ ., data = iris.new)
summary(mod.iris)
# (Intercept) 1.18650, Sepal.Length -0.11191, Sepal.Width -0.04008,
# Petal.Length 0.22865 (***), Petal.Width 0.60925 (***)
# AIC: -22.874

unknown <- data.frame(Sepal.Length = 5.1, Sepal.Width = 3.5, Petal.Length = 1.4, Petal.Width = 0.2)
pred <- predict(mod.iris, unknown)        # 0.9174506
levels(iris$Species)[round(pred)]         # "setosa"

pred <- round(predict(mod.iris, iris[, 1:4]))
mean(pred == as.integer(iris$Species))    # 0.9733333
```
- **중요**: `glm()`에 `family`를 안 주면 기본값이 `gaussian` → 위 코드는 로지스틱이 아니라 **품종 번호(1, 2, 3)를 숫자로 놓고 푼 일반 선형회귀**와 같음 (R로 확인: `family(mod.iris)$family` = "gaussian"). 예측값이 0.917처럼 확률이 아닌 숫자로 나오는 것도 그 때문
  - 품종에 1 < 2 < 3 순서와 등간격이 있다고 가정하는 셈이라 원리상 맞지 않음 (iris는 우연히 순서가 맞아서 97.3%가 나옴)
- 실제 로지스틱 회귀는
```r
# 이진: versicolor vs virginica
b <- subset(iris, Species != "setosa")
b$y <- as.integer(b$Species == "virginica")
g <- glm(y ~ Petal.Length + Petal.Width, family = binomial, data = b)
p <- predict(g, type = "response")        # 확률
mean((p > 0.5) == b$y)                    # 0.94

# 3개 범주: 다항 로지스틱
library(nnet)
m <- multinom(Species ~ ., data = iris)
mean(predict(m) == iris$Species)          # 0.987
```
### 보충: 신경망
- 입력층 → 은닉층 → 출력층. 노드는 선형결합 L = Σwᵢxᵢ에 활성화 함수(로지스틱 1/(1 + e^−L), tanh) 적용, 출력은 연속형이면 L 그대로, 범주형이면 softmax
- 은닉 노드 출력 = 1 / (1 + e^−(θ + w₁x₁ + w₂x₂)) — 로지스틱 회귀를 여러 겹 쌓은 모양
- 역전파는 층이 깊어지면 **기울기 소실**로 앞쪽 층이 학습되지 않음 → 2006년 힌튼의 RBM 사전학습으로 심층 신경망 학습이 가능해지며 "딥러닝"으로 부활
