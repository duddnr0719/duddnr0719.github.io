> 수치-수치는 산점도와 피어슨 상관계수(공분산을 표준편차로 나눠 −1~1로 표준화), 시간에 따른 변화는 선그래프, 범주-범주는 분할표와 카이제곱 검정(적합도·동질성·독립성)으로 본다.
### 변수 조합별 분석 기법
| X (독립) \ Y (종속) | 범주형 | 양적 |

| 범주형 | 분할표, 카이제곱 독립성 검정, 모자이크 플롯 | t-검정, ANOVA |
| 양적 | 의사결정나무, 로지스틱 회귀 | 상관분석, 회귀분석, 산점도 |

### 분산과 공분산
- 분산: 한 변수가 평균에서 얼마나 떨어져 있나
  - 모분산 Var(X) = E[(X − μ)²], 표본분산 s² = Σ(xᵢ − x̄)² / (n − 1)
- **공분산**: 두 변수가 **함께** 평균에서 벗어나는 정도
  - Cov(X, Y) = E[(X − μX)(Y − μY)], 표본 cov(x, y) = Σ(xᵢ − x̄)(yᵢ − ȳ) / (n − 1)
  - Var(X + Y) = Var(X) + Var(Y) + 2Cov(X, Y)
- 해석: 평균을 원점으로 4분면을 나누면 오른쪽 위·왼쪽 아래 점은 (+), 나머지는 (−)를 기여
  - 같은 방향으로 움직이면 Cov > 0, 반대면 Cov < 0, 관계없으면 ≈ 0
  - 문제: 값이 **단위(분산 크기)에 따라** 커지고 작아져서 관계의 세기를 비교할 수 없음 → 표준화 필요
### 상관계수
- 모상관계수 ρ = Cov(X, Y) / (σX σY)
- **피어슨 표본상관계수** r = cov(x, y) / (sx sy) = Σ(xᵢ − x̄)(yᵢ − ȳ) / √(Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)²)
- −1 ≤ r ≤ 1. 부호는 방향(양/음), 절댓값은 **선형** 관계의 세기 (±0.9 강함, ±0.5 약함, 0 없음, 1은 완전한 직선)
- 0이라고 관계가 없는 게 아니라 "직선 관계가 없는" 것 (곡선 관계는 못 잡음)
```r
beers <- c(5, 2, 9, 8, 3, 7, 3, 5, 3, 5)                          # 맥주 잔 수
bal   <- c(0.10, 0.03, 0.19, 0.12, 0.04, 0.095, 0.07, 0.06, 0.02, 0.05)   # 혈중 알코올
plot(bal ~ beers)
abline(lm(bal ~ beers))       # 회귀선
cor(beers, bal)               # 0.8882323
```
  - 슬라이드 코드엔 6번째 값이 `0.0095`(오타)로 들어가 결과가 `0.6797025`로 나옴. 데이터 표대로 `0.095`를 넣으면 **0.888** (R 4.3으로 둘 다 확인)

### 선그래프
- 시간에 따라 모은 **시계열 자료**의 추이
```r
month <- 1:12
late1 <- c(5, 8, 7, 9, 4, 6, 12, 13, 8, 6, 6, 4)
late2 <- c(4, 6, 5, 8, 7, 8, 10, 11, 6, 5, 7, 3)
plot(month, late1, main = "Late Students",
     type = "b", lty = 1, col = "red",
     xlab = "Month", ylab = "Late cnt",
     ylim = c(1, 15))                       # 두 번째 선이 잘리지 않게 y 범위 고정
lines(month, late2, type = "b", col = "blue")   # 선 추가
```
- `type`: `"p"` 점(기본), `"l"` 선, `"b"` 점+선, `"o"` 겹침, `"h"` 수직선, `"s"`/`"S"` 계단
- `lty`: 1 실선, 2 파선, 3 점선 / `lwd`: 굵기

### 가설 검정 기본
- **귀무가설 H₀**: 기존(보수적) 주장, "차이·관계가 없다" / **대립가설 H₁**: 새 주장
- 검정 통계량: 평균 차이는 t, 분산 차이는 F, 범주형 적합도·동질성·독립성은 **χ²**
- **기각역**: 유의수준 α(보통 0.05)로 정한 영역. 통계량이 그 안에 들면 H₀ 기각 (R에선 **p-value < α**면 기각)
### 카이제곱 통계량
- χ² = Σ (O − E)² / E — O 관측빈도, E는 **H₀가 맞다면** 기대되는 빈도
- 관측과 기대가 다를수록 커짐 → 임계값보다 크면 H₀ 기각
| 검정 | 질문 | 자유도 |
|---|---|---|
| 적합도 | 관측 분포가 이론 분포(균등, 9:3:3:1 등)를 따르나 | k − 1 |
| 동질성 | 여러 모집단의 범주 비율이 같나 | (k − 1)(l − 1) |
| 독립성 | 한 모집단의 두 범주형 변수가 독립인가 | (k − 1)(l − 1) |
### 적합도 검정
- 예 1: 학교 바우처 찬성 23, 모름 17, 반대 50 (n = 90). H₀: 세 비율이 모두 1/3 → 기대 30씩
| | O | E | (O − E)² / E |
|---|---|---|---|
| 찬성 | 23 | 30 | 1.63 |
| 모름 | 17 | 30 | 5.63 |
| 반대 | 50 | 30 | 13.33 |
| 합 | 90 | 90 | **20.59** |
  - df = 2, χ²₀.₀₅(2) = 5.99 < 20.59 → H₀ 기각 (비율이 같지 않음)
  - R: `chisq.test(c(23, 17, 50))` → X-squared = 20.6, p = 3.4 × 10⁻⁵
- 예 2: 멘델 9 : 3 : 3 : 1, 관측 A 310, B 120, C 100, D 30 (n = 560)
  - 기대 560 × 9/16 = 315, 105, 105, 35
  - χ² = 25/315 + 225/105 + 25/105 + 25/35 ≈ 3.175
  - df = 3, χ²₀.₀₅(3) = 7.815 > 3.175 → H₀ 기각 못함 (멘델 법칙에 어긋난다고 할 수 없음)
  - R: `chisq.test(c(310, 120, 100, 30), p = c(9, 3, 3, 1) / 16)` → 3.1746, p = 0.366
### 동질성·독립성 검정
- k × l 분할표, 기대빈도 **eᵢⱼ = (행 합 × 열 합) / n**
- 독립성 H₀: pᵢⱼ = pᵢ· × p·ⱼ (두 속성이 독립)
- 예: 신상품 선호와 성별 (n = 200)
| | A | B | C | 합 |
|---|---|---|---|---|
| 남 | 10 (12) | 50 (36) | 20 (32) | 80 |
| 여 | 20 (18) | 40 (54) | 60 (48) | 120 |
| 합 | 30 | 90 | 80 | 200 |
  - (괄호는 기대빈도) χ² ≈ 17.13, df = (2 − 1)(3 − 1) = 2, 임계값 5.99 → H₀ 기각, **선호도와 성별은 관계 있음**
  - R: `chisq.test(matrix(c(10, 20, 50, 40, 20, 60), 2))` → 17.13, p = 0.00019
- 동질성 예: 학년별 흡연(1학년 140/60, 2학년 160/40, 3학년 150/150, 4학년 100/200) → `chisq.test()`로 χ² = 128.6, df = 3, p < 2.2 × 10⁻¹⁶ (학년별 흡연 비율이 다름)
### R로 독립성 검정: 성별과 선호 계절
```r
df.season <- data.frame(성별, 선호계절)   # 21명
table.result <- table(df.season)
#        선호계절
# 성별    FALL SPRING SUMMER WINTER
#   Man      2      1      5      3
#   Woman    2      4      2      2
mosaicplot(table.result, main = "성별 응답현황", color = c("red", "blue", "green", "black"))
chisq.test(table.result)
# X-squared = 3.2455, df = 3, p-value = 0.3553
```
  - p = 0.355 > 0.05 → H₀ 기각 못함: 성별에 따라 선호 계절이 다르다고 할 수 없음
  - 슬라이드의 "X-squared = 3, p-value = 0.4"는 반올림된 표기. 실제 값은 위와 같고, 기대빈도가 모두 5 미만이라 "근사가 부정확할 수 있다"는 경고가 함께 나옴 (표본이 작으면 `fisher.test()` 고려)
