> 이전 10초 맥락을 읽어 최대 40초까지 장면을 잇고, 시작과 끝 프레임을 지정해 샷을 연결하는 생성 비디오 모델이 나왔다 !

# 개요
- 무엇 : Google DeepMind가 2026.08.27에 개발자용 생성 비디오 모델 Gemini Omni 1.1 Flash를 공개함.
- 한 줄 정의 : Gemini Omni 1.1 Flash는 장면 연장 · 키프레임 보간 · 360p 초안 렌더링 · 4K 업스케일링을 지원하는 비디오 생성 모델이다.
- 원문 : [Gemini Omni 1.1 Flash lets you build with more control](https://deepmind.google/blog/gemini-omni-1-1-flash-lets-you-build-with-more-control/)

# 그래서 도대체 뭔데 ?
- 프롬프트 1번에 짧은 영상을 뽑고 끝내던 기존 비디오 생성의 한계를 넘는 업데이트임.
- 이미 생성된 영상의 앞선 흐름을 길게 읽어 다음 장면을 매끄럽게 연장함.
- 시작과 끝 그림 2장을 주면 그 사이 움직임을 자연스럽게 채워주는 키프레임 보간을 지원함.
- 360p 해상도로 빠르게 초안을 뽑아보고 검증된 장면만 1080p나 4K로 키우는 워크플로우를 제공함.
	- 💡 장면 연장 (Scene extension) : 기존 영상 끝에서 자연스럽게 추가 분량을 이어 붙여 생성하는 기법.
	- 💡 프레임 보간 (Interpolation) : 시작과 끝 이미지를 지정하고 그 사이 전환 과정을 연속 영상으로 채우는 기술.

# 어떻게 동작하나 ?
1. 문맥 분석 기반 장면 연장
	- API 호출 시 `previous_interaction_id`로 직전 생성 상태를 넘겨줌.
	- 모델이 직전 영상에서 최대 10초 분량의 시각 맥락을 분석함.
	- 10초 단위로 영상을 이어 나가며 최대 40초까지 길이를 늘림.
	→ 카메라 구도와 캐릭터 일관성을 유지하면서 긴 호흡의 스토리를 이어붙일 수 있음.

2. 양 끝단 프레임 지정과 보간
	- 입력 리스트에 시작 프레임과 끝 프레임 이미지 2장을 함께 전달함.
	- 프롬프트로 카메라 무빙이나 장면 변화를 지시함.
	- 모델이 두 키프레임 사이를 자연스럽게 이어주는 연속 프레임을 생성함.
	→ 컷 전환 없이 매끄럽게 연결되는 샷이나 완벽히 맞물리는 무한 루프 영상을 얻게 됨.

3. 3초 비디오 참조 입력
	- 텍스트 프롬프트 외에 최대 3초 길이의 레퍼런스 비디오를 함께 제공함.
	- 모델이 참조 영상의 시각 맥락을 바탕으로 캐릭터 일관성을 유지함.
	→ 비디오 레퍼런스를 통해 시각적 연속성과 캐릭터 일관성을 확보함.

4. 360p 초안과 4K 업스케일
	- 기획 단계에서는 `resolution`을 360p로 지정해 빠르게 렌더링함.
	- 구도와 움직임이 확인되면 최종 단계에서 1080p 또는 4K로 업스케일함.
	→ 제작 파이프라인의 렌더링 시간과 API 사용 비용을 줄임.

# 기존이랑 뭐가 다른가 ?
- 이전 방식 : 이전 영상 연장 시 마지막 1초만 참조하여 맥락이 끊기고 피사체가 갑자기 변함.
- 이번 방식 : 직전 10초를 통째로 분석하여 시각적 연속성과 서사 일관성을 유지함.
→ 참조하는 맥락의 길이가 1초에서 10초로 늘어나 장면 간 이음새가 어색해지지 않음.

- 이전 방식 : 표준 720p 해상도로 바로 생성하여 반복 테스트 시 비용과 지연이 큼.
- 이번 방식 : 360p 해상도로 1/3 비용에 빠르게 초안을 확인한 뒤 필요한 컷만 1080p나 4K로 업스케일함.
→ 실험 단계와 최종 마스터링 단계가 분리되어 제작 효율이 올라감.

- 이전 방식 : 프롬프트나 시작 이미지 1장만 주고 결과를 기다려 카메라 궤적 제어가 어려움.
- 이번 방식 : 시작과 끝 프레임을 둘 다 고정해 두고 사이를 보간함.
→ 영상의 도착점을 사전에 지정할 수 있어 의도한 연출과 루프 클립을 정확히 구현함.

# 주의할 점 / 한계
- 누적 길이 제한 : 장면 연장은 10초 단위로 가능하지만 총 누적 길이는 최대 40초로 제한됨.
- 비디오 참조 길이 : 멀티모달 프롬프트에 넣을 수 있는 참조 비디오는 최대 3초까지만 허용됨.
- 해상도 구현 방식 : 1080p와 4K는 네이티브 생성이 아니라 업스케일 처리임.
- 속도 향상 수치 조건 : 360p의 최대 60% 속도 개선은 360p 대 720p 해상도 간 시스템 처리량 기준 실측임.
- 화면 비율 한계 : 지원되는 비율은 16:9 가로와 9:16 세로의 2가지만 제공됨.

# 정리
- 긴 맥락 참조(10초)와 키프레임 보간, 3초 비디오 참조를 통해 생성 비디오의 제어력을 실무 수준으로 끌어올림.
- 360p 초안 검증 후 4K 업스케일로 이어지는 제작 흐름 덕분에 영상 워크플로우나 창작 도구, 미디어 편집 소프트웨어 개발자가 비용을 통제하며 도입하기 좋음.
