> 유사도는 거리로 잰다. kNN은 레이블 있는 이웃 k개의 다수결로 분류(지도), K-means는 레이블 없이 중심점과의 거리로 k개 군집을 만든다(비지도).
### 군집화와 유사도
- 군집화(clustering): 주어진 데이터에서 유사한 것끼리 모아 군집으로 나누는 문제
- 유사도: 대상이 얼마나 비슷한지 정량적으로 나타낸 수치. 계산하려면 먼저 데이터를 수치로 변환해야 함
- 주로 **거리**로 측정: 거리 ↑ → 유사도 ↓, 거리 ↓ → 유사도 ↑
### 거리
- 유클리드 거리: 점과 점 사이 직선 거리
  - **d(x, y) = ( Σ |xⱼ − yⱼ|² )^(1/2)**
- 맨하탄 거리: 직선이 아니라 x, y축을 따라간 거리 (격자 도로에서 어느 경로로 가든 같음)
  - **d(x, y) = Σ |xⱼ − yⱼ|**
- 예: 동물을 6개 질문(부리? 수염? 발 개수? 척추? 날 수 있나? 털이 갈색?)의 답으로 벡터화
  - 고양이1 vs 고양이2: 맨하탄 1, 유클리드 1
  - 고양이1 vs 참새: 맨하탄 5, 유클리드 √7 → 훨씬 덜 비슷함
### kNN (k-Nearest Neighbor)
- 가장 간단한 **분류** 알고리즘. 새 데이터 주변의 가장 가까운 k개 이웃을 보고 다수결
- 절차
  1. 데이터 관찰
  1. 새 데이터와 모든 데이터 사이의 거리 계산
  1. 거리순으로 정렬해 가까운 k개 선택 (예: 2.1, 2.4, 3.1)
  1. 투표: k = 3에서 연두 2, 초록 1이면 연두로 분류
- 정규화: 특징마다 범위가 다르면 큰 쪽이 거리를 지배 → 0~1로 맞춤 (Min-max, z-score)
- **k 선택이 핵심**
  - k가 너무 작으면(k = 1) 이웃을 충분히 안 봐서 **과잉적합**
  - k가 너무 크면(k = 60) 세세한 부분을 못 봐서 **과소적합**
  - 검증 데이터로 최적 k를 찾음
- 장점: 직관적, 샘플이 많을 때 좋음, 특정 분포를 가정하지 않아 어떤 분포든 적용 가능
- 단점: 최적 k 찾기 어려움, 데이터·클래스가 많으면 메모리·계산량 큼, 분포 가정이 없어 샘플이 많아야 정확, 특징이 많은 데이터에 약함
### sklearn kNN 실습 (아이리스)
- 150개 샘플(3품종 × 50), 특징 4개: sepal length/width, petal length/width (cm)
- 타깃: 0 = setosa, 1 = versicolor, 2 = virginica
```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn import metrics

iris = load_iris()
X, y = iris.data, iris.target
print(iris.feature_names)

# 80:20 분할
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=4)
print(X_train.shape, X_test.shape)          # (120, 4) (30, 4)

knn = KNeighborsClassifier(n_neighbors=6)
knn.fit(X_train, y_train)
y_pred = knn.predict(X_test)
print(metrics.accuracy_score(y_test, y_pred))   # 0.9666666666666667

# 전체 데이터로 학습 후 새 데이터 예측
knn = KNeighborsClassifier(n_neighbors=5).fit(X, y)
classes = {0: 'setosa', 1: 'versicolor', 2: 'virginica'}
y_predict = knn.predict([[3, 4, 5, 2], [5, 4, 2, 2]])
print(classes[y_predict[0]])   # versicolor
print(classes[y_predict[1]])   # setosa
```
### 비지도 학습
- 정답 레이블이 없는 데이터에서 패턴·특성·구조(데이터 고유의 특징)를 알아내는 학습
- 필요한 이유: 사전 지식이 부족해도 데이터를 쉽게 해석할 수 있음
### K-means
- n개 관측값을 k개 클러스터로 나눔. 각 관측값은 거리가 가장 가까운 클러스터로
- 절차
  1. 임의의 k개 점(중심) 선택
  1. 각 데이터와 k개 중심 사이의 거리 계산
  1. 데이터를 가장 가까운 중심에 할당
  1. 군집별 평균을 계산해 중심 이동
  1. 할당이 더 이상 바뀌지 않을 때까지 2~4 반복
- 문제점
  1. 초기 중심에 따라 결과가 달라짐
  1. 복잡한 분포(초승달 모양 등)는 잘 못 나눔
  1. k 값에 따라 결과가 다름
- k 정하기: k를 바꿔가며 **SSE**(군집 중심과 데이터 사이 오차 제곱합)를 측정
  - **SSE = Σᵢ Σ_{x∈Cᵢ} (x − cᵢ)²**
  - k가 늘면 SSE는 계속 줄지만, 감소 폭이 확 꺾이는 **엘보우 포인트**를 고름
```python
from sklearn.cluster import KMeans
for k in range(1, 7):
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X)
    print(k, round(km.inertia_, 1))   # inertia_ = SSE
# 1 681.4 / 2 152.3 / 3 78.9 / 4 57.2 / 5 46.4 / 6 39.0  → k=3 근처에서 꺾임 (실제 품종 수와 일치)
```
