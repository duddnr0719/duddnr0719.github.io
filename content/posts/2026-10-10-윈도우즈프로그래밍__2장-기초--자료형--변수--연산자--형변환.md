> 값의 종류(int, long, float, double, char, string, bool)와 연산자, var, 입력(ReadLine은 항상 string), 형변환(작은 → 큰 자동, 큰 → 작은 강제 캐스팅, 문자열 ↔ 값은 Parse/ToString).
### 기본 용어
- **표현식**: 값을 만들어내는 코드 (`273`, `10 + 20 + 30 * 2`, `"C# Programming"`)
- **문장**: 표현식이 모이고 끝에 `;`이 붙은 실행 최소 단위
- **키워드**: 특별한 의미가 예약된 단어
  - 일반 키워드: `abstract, as, base, bool, break, byte, case, catch, char, class, const, continue, decimal, default, delegate, do, double, else, enum, event, …, while` → 식별자로 못 씀
  - 문맥 키워드: `async, await, var, get, set, value, from, select, where, yield, record, init …` → 특정 위치에서만 키워드
- **식별자**: 변수·메서드 등의 이름
  - 키워드 불가, 특수문자는 `_`만, 숫자로 시작 불가, 공백 불가
  - 가능: `alpha`, `alpha10`, `_alpha`, `Alpha` / 불가: `break`, `273alpha`, `has space`
  - 관례: 클래스·속성·메서드·네임스페이스는 대문자 시작(PascalCase), 변수는 소문자 시작(camelCase), 단어마다 첫 글자 대문자(`createServer`)
  - 뒤에 `()`가 붙으면 메서드(`Console.WriteLine()`), 없으면 변수·속성(`Math.PI`). 괄호 안 값은 매개변수
- **주석**: `// 한 줄`, `/* 여러 줄 */`
### 숫자
- 정수 연산자 `+ - * / %`, 곱셈·나눗셈이 먼저 (`5 + 3 * 2` = 11)
- **정수끼리 나누면 정수** (소수점 버림): `10 / 4` = 2, `1 / 2` = 0
- `%` 결과의 부호는 **왼쪽** 피연산자를 따름: `-4 % 3` = −1, `4 % -3` = 1
- 실수: `0`과 `0.0`은 다른 자료형. `1.0 / 2.0` = 0.5
- 실수에 `%`는 결과가 예측하기 어려워 비추천: `5.0 % 2.2`가 교재엔 0.6이지만 .NET 8에서 실제로는 `0.5999999999999996` (부동소수점 오차)
### 문자와 문자열
- 문자 `char`: 작은따옴표 `'A'`, `'가'`
- 문자열 `string`: 큰따옴표 `"안녕하세요"`
- 이스케이프: `\t` 탭, `\n` 줄바꿈, `\\` 역슬래시, `\"` 큰따옴표
- `+`로 연결: `"가나다" + "라마"` → `가나다라마`
- 문자 선택: `"안녕하세요"[0]` → `안`, `[1]` → `녕`. 범위를 벗어나면 `IndexOutOfRangeException`(런타임 오류)
- 문자끼리 `+`는 **숫자 덧셈**: 문자는 내부적으로 유니코드 정수 → `'가' + '힣'` = 44032 + 55203 = 99235
### 불 (bool)
- `true`, `false` (출력은 `True`, `False`)
- 비교: `==`, `!=`, `>`, `<`, `>=`, `<=`
- 논리: `!`(부정), `||`(하나라도 참이면 참), `&&`(둘 다 참이어야 참)
- `3 < number < 8`은 오류 → `3 < number && number < 8`
```csharp
// 현재 시각이 3시 이전이거나 8시 이후인가?
Console.WriteLine(DateTime.Now.Hour < 3 || 8 < DateTime.Now.Hour);
Console.WriteLine(3 < DateTime.Now.Hour && DateTime.Now.Hour < 8);
```
### 변수와 자료형
- 선언 + 할당: `double pi = 3.14159265;`
| 키워드 | 크기 | 원형 | 비고 |
|---|---|---|---|
| int | 4B | System.Int32 | −2,147,483,648 ~ 2,147,483,647 |
| long | 8B | System.Int64 | ±약 9.2 × 10¹⁸ |
| uint / ulong | 4B / 8B | | 부호 없는 정수 |
| float | 4B | System.Single | 실수, 접미사 F |
| double | 8B | System.Double | 실수 기본형 |
| char | 2B | System.Char | 유니코드 문자 |
| string | — | System.String (**클래스**) | 참조형이라 `sizeof(string)` 불가 |
| bool | 1B | System.Boolean | |
- `int a = 273, b = 52;` → `a / b` = 5, `a % b` = 13
- **오버플로**: 범위를 넘으면 반대쪽 끝으로 돌아감
```csharp
int a = 2000000000;
int b = 1000000000;
Console.WriteLine(a + b);   // -1294967296
uint ua = 2000000000, ub = 1000000000;
Console.WriteLine(ua + ub); // 3000000000
Console.WriteLine(int.MaxValue);  // 2147483647
Console.WriteLine(long.MinValue); // -9223372036854775808
```
- `sizeof(int)` = 4, `sizeof(long)` = 8, `sizeof(float)` = 4, `sizeof(double)` = 8, `sizeof(char)` = 2
- 실수 출력: `52.273 + 103.32` → `155.593`, `52.273 * 103.32` → `5400.84636`, `52.273 - 103.32` → .NET 8에선 `-51.04699999999999` (교재 그림은 `-51.047`)
### 복합 대입·증감 연산자
- `+=, -=, *=, /=, %=` (문자열엔 `+=`로 이어 붙이기)
```csharp
int output = 0;
output += 52; output += 273; output += 103;
Console.WriteLine(output);   // 428

string s = "hello ";
s += "world "; s += "!";
Console.WriteLine(s);        // hello world !
```
- `++`, `--`: 전위는 **바꾸고 나서** 값을 쓰고, 후위는 **값을 쓰고 나서** 바꿈
```csharp
int number = 10;
Console.WriteLine(number++);  // 10 (출력 후 11이 됨)
Console.WriteLine(number--);  // 11 (출력 후 10이 됨)
Console.WriteLine(++number);  // 11
Console.WriteLine(--number);  // 10
```
- 헷갈리니 증감은 따로 한 줄로 쓰는 게 안전
### 자료형 검사와 var
- `GetType()`: `(273).GetType()` → `System.Int32`, `(52.273F).GetType()` → `System.Single`, `("문자열").GetType()` → `System.String`
- 접미사: `L` → long (`522731033265L`), `F` → float. 소문자 `l`은 1과 헷갈려서 대문자 권장
- `var`: 오른쪽 값을 보고 자료형을 **컴파일 시점에** 결정
  - `var number = 100;` → int, `100L` → long, `100.0` → double, `100.0F` → float
  - **지역 변수에만**, **선언과 동시에 초기화** 필수 (`var x;` 불가)
  - 한 번 정해진 자료형은 못 바꿈 (`number = "문자열";` 컴파일 오류) — 동적 타입이 아님
### 입력
- `Console.ReadLine()`: 한 줄을 입력받음. 반환은 **항상 string**
```csharp
string input = Console.ReadLine();
Console.WriteLine("input: " + input);
```
### 자료형 변환
- **강제(명시적) 변환**: `(자료형)값`. 큰 → 작은 자료형이라 데이터 손실 가능
```csharp
long longNumber = 2147483647L + 2147483647L;
int intNumber = (int)longNumber;
Console.WriteLine(intNumber);   // -2 (손실)
Console.WriteLine((int)52273L); // 52273 (범위 안이면 손실 없음)
```
- **자동(암시적) 변환**: 손실이 없는 방향은 알아서
| 원래 | 자동 변환 가능 |
|---|---|
| int | long, float, double |
| long | float, double |
| char | int, long, float, double |
| float | double |
- **문자열 → 숫자**: `int.Parse("52")`, `long.Parse("273")`, `float.Parse("52.273")`, `double.Parse("103.32")`
  - `(int)"52"`는 컴파일 오류
  - `int.Parse("abc")`, `int.Parse("52.273")` → `FormatException` (안전하게 하려면 `int.TryParse(s, out int n)`)
- **값 → 문자열**: `ToString()` (`(52).ToString()`, `(true).ToString()` → `"True"`)
  - 자릿수: `52.273103.ToString("0.00")` → `52.27`, `"0.0"` → `52.3`
  - 문자열과 `+`하면 자동으로 문자열: `52 + 273` = 325, `"52" + 273` = `52273`, `number + ""`로 간단 변환
- **문자열 → bool**: `bool.Parse("True")`, `bool.Parse("false")` (대소문자 무관)
- int는 음수가 하나 더 많음: `-int.MinValue`는 대응하는 양수가 없어 다시 `-2147483648`
