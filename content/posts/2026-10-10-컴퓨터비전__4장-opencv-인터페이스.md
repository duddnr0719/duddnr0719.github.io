> namedWindow/imshow로 행렬을 영상으로 보고, waitKey·setMouseCallback·createTrackbar의 콜백으로 입력을 받고, line·rectangle·circle·ellipse·putText로 결과를 표시하고, imread/imwrite로 파일을 다룬다. Matplotlib은 RGB라 BGR을 변환해서 넘겨야 한다.
### 윈도우 제어
- 영상 처리는 행렬 연산 → 숫자만 봐서는 변화를 알기 어려우니 **윈도우에 띄워서 확인**. 마우스·키 이벤트도 **창이 활성화돼 있을 때만** 감지
| 함수 | 역할 |
|---|---|
| `cv2.namedWindow(winname, flags)` | 창 생성. `WINDOW_AUTOSIZE`(1, 영상 크기 고정) / `WINDOW_NORMAL`(0, 크기 조절 가능) |
| `cv2.imshow(winname, mat)` | 행렬을 영상으로 표시 (창이 없으면 생성) |
| `cv2.moveWindow(winname, x, y)` | 창 왼쪽 위를 모니터 (x, y)로 |
| `cv2.resizeWindow(winname, w, h)` | 창 크기 변경 (AUTOSIZE 창에는 효과 없음) |
| `cv2.destroyWindow(name)` / `destroyAllWindows()` | 창 닫기 |
```python
image = np.zeros((200, 400), np.uint8)
image[:] = 200
cv2.namedWindow('Position1', cv2.WINDOW_AUTOSIZE)
cv2.namedWindow('Position2')
cv2.moveWindow('Position1', 150, 150)
cv2.moveWindow('Position2', 400, 50)
cv2.imshow('Position1', image)
cv2.imshow('Position2', image)
cv2.waitKey(0)
cv2.destroyAllWindows()
```
- `WINDOW_NORMAL` 창을 키우면 영상이 늘어나 **보일 뿐**, 행렬 자체가 바뀌는 건 아님
### 이벤트와 콜백
- 이벤트: 키 입력, 마우스 이동·클릭, 타이머 등 프로그램이 감지하는 사건
- **콜백 함수**: 내가 직접 부르는 게 아니라, 이벤트가 생기면 **시스템이 내가 등록해 둔 함수를 호출**
- OpenCV 지원: 키보드, 마우스, 트랙바
### 키보드
- `cv2.waitKey(delay)`: delay(ms) 동안 키 대기 → 키 코드 반환, 시간 초과면 −1. **delay ≤ 0이면 무한 대기**
- `cv2.waitKeyEx(delay)`: 전체 키 코드 반환 → 화살표 같은 특수키 구분 가능
```python
switch_case = {
    ord('a'): "a키 입력",            # ord: 문자 → 코드
    0x41: "A키 입력",
    2424832: "왼쪽 화살표키 입력",    # 0x250000 (Windows 기준)
    2490368: "윗쪽 화살표키 입력",    # 0x260000
    2555904: "오른쪽 화살표키 입력",  # 0x270000
    2621440: "아래쪽 화살표키 입력",  # 0x280000
}
image = np.ones((200, 300), np.float64)   # 슬라이드의 np.float는 NumPy 1.24+에서 에러
cv2.imshow("Keyboard Event", image)
while True:
    key = cv2.waitKeyEx(100)
    if key == 27: break                   # ESC
    if key in switch_case:
        print(switch_case[key])
cv2.destroyAllWindows()
```
- 화살표 키 코드는 **운영체제마다 다름** (위 값은 Windows, Linux GTK에선 65361~65364 등) → 실제 값을 `print(key)`로 확인하고 쓰기
- `waitKey()`는 창을 다시 그리는 역할도 하므로 `imshow` 뒤에 꼭 필요
### 마우스
- `cv2.setMouseCallback(windowName, onMouse, param=None)` → `onMouse(event, x, y, flags, param)`
| event | 값 | flags | 값 |
|---|---|---|---|
| `EVENT_MOUSEMOVE` | 0 | `EVENT_FLAG_LBUTTON` | 1 |
| `EVENT_LBUTTONDOWN` / `RBUTTONDOWN` / `MBUTTONDOWN` | 1 / 2 / 3 | `EVENT_FLAG_RBUTTON` | 2 |
| `EVENT_LBUTTONUP` / `RBUTTONUP` / `MBUTTONUP` | 4 / 5 / 6 | `EVENT_FLAG_MBUTTON` | 4 |
| `EVENT_LBUTTONDBLCLK` / `RBUTTONDBLCLK` / `MBUTTONDBLCLK` | 7 / 8 / 9 | `EVENT_FLAG_CTRLKEY` | 8 |
| `EVENT_MOUSEWHEEL` / `MOUSEHWHEEL` | 10 / 11 | `EVENT_FLAG_SHIFTKEY` / `ALTKEY` | 16 / 32 |
- flags는 비트 합이라 `flags & cv2.EVENT_FLAG_CTRLKEY`로 검사
```python
def onMouse(event, x, y, flags, param):
    if event == cv2.EVENT_LBUTTONDOWN:     print("마우스 왼쪽 버튼 누르기")
    elif event == cv2.EVENT_RBUTTONDOWN:   print("마우스 오른쪽 버튼 누르기")
    elif event == cv2.EVENT_RBUTTONUP:     print("마우스 오른쪽 버튼 떼기")
    elif event == cv2.EVENT_LBUTTONDBLCLK: print("마우스 왼쪽 버튼 더블클릭")

image = np.full((200, 300), 255, np.uint8)
cv2.imshow("Mouse Event1", image)
cv2.imshow("Mouse Event2", image)
cv2.setMouseCallback("Mouse Event1", onMouse)   # 1번 창에서만 반응
cv2.waitKey(0)
```
### 트랙바
- 범위 안의 값을 고르는 슬라이더
- `cv2.createTrackbar(trackbarname, winname, value, count, onChange)` — 초기값 value, 최대 count(최소는 항상 0), 값이 바뀌면 `onChange(pos)` 호출
- `cv2.getTrackbarPos(name, win)`, `cv2.setTrackbarPos(name, win, pos)`
```python
def onChange(value):
    global image
    image[:] = value                  # 화면 전체를 슬라이더 값으로
    cv2.imshow(title, image)

image = np.zeros((300, 500), np.uint8)
title = 'Trackbar Event'
cv2.imshow(title, image)
cv2.createTrackbar('Brightness', title, int(image[0, 0]), 255, onChange)
cv2.waitKey(0)
```
- 슬라이드는 차이를 구해 `image = image + add_value`로 더하는데, 슬라이더를 **왼쪽으로** 움직이면 add_value가 음수가 되고, NumPy 2.x에선 `uint8` 배열 + 음수 파이썬 정수가 `OverflowError: Python integer -30 out of bounds for uint8`로 멈춤 (NumPy 2.4로 확인). 값을 그대로 대입하는 위 방식이 간단하고 안전
- 마우스와 연동: 우클릭 +10, 좌클릭 −10 하고 `cv2.setTrackbarPos()`로 슬라이더 위치도 맞춰 주면, 그 순간 onChange도 다시 불려 화면이 일관되게 갱신됨
### 그리기
- 검출 결과(얼굴 사각형, 차선 직선 등)를 영상 위에 표시할 때. 좌표는 `(x, y)` = (열, 행), 색은 **(B, G, R)** 튜플(흑백 영상이면 정수)
| 함수 | 주요 인자 |
|---|---|
| `cv2.line(img, pt1, pt2, color, thickness=1, lineType)` | 시작·끝점 |
| `cv2.rectangle(img, pt1, pt2, …)` / `(img, (x, y, w, h), …)` | 두 꼭짓점 또는 위치+크기 |
| `cv2.circle(img, center, radius, color, thickness)` | 중심, 반지름 |
| `cv2.ellipse(img, center, axes, angle, startAngle, endAngle, color, thickness)` | axes = (가로 반지름, 세로 반지름), 각도는 3시 방향 0°에서 **시계 방향** |
| `cv2.putText(img, text, org, fontFace, fontScale, color, thickness, lineType)` | org = 글자 **왼쪽 아래** 기준점 |
- `thickness = -1`(`cv2.FILLED`)이면 내부 채움
- lineType: `LINE_4`(4방향 연결), `LINE_8`(8방향, 기본), `LINE_AA`(안티앨리어싱, 부드러움)
- 슬라이드 표의 `color: (R, G, B)`는 오기, OpenCV는 **BGR** (`(0, 0, 255)`가 빨강)
```python
blue, green, red = (255, 0, 0), (0, 255, 0), (0, 0, 255)
image = np.full((400, 600, 3), 255, np.uint8)
cv2.line(image, (50, 50), (250, 350), red)
cv2.line(image, (400, 150), (500, 50), green, 3, cv2.LINE_AA)
cv2.rectangle(image, (50, 50), (250, 350), blue, 3, cv2.LINE_4)
cv2.rectangle(image, (50, 200, 200, 100), red, 3, cv2.LINE_8)    # (x, y, w, h)
cv2.rectangle(image, (400, 200, 100, 100), green, cv2.FILLED)

center = (image.shape[1] // 2, image.shape[0] // 2)   # shape은 (행, 열) → (x, y)로 뒤집기
cv2.circle(image, center, 100, blue)
cv2.ellipse(image, (180, 150), (120, 60), 0, 30, 270, (0, 165, 255), 4)   # 호
```
- 글꼴: `FONT_HERSHEY_SIMPLEX`(0, 산세리프), `PLAIN`(1, 작은 산세리프), `DUPLEX`(2), `COMPLEX`(3, 세리프), `TRIPLEX`(4), `COMPLEX_SMALL`(5), `SCRIPT_SIMPLEX`(6, 필기체), `SCRIPT_COMPLEX`(7), 기울임은 `| cv2.FONT_ITALIC`(16)
  - 세리프 = 획 끝에 장식(명조), 산세리프 = 장식 없음(고딕)
  - Hershey 글꼴은 **한글을 못 그림** (물음표로 나옴) → 한글은 PIL `ImageDraw` 등 사용
- 그림자 글씨: 같은 글자를 (+2, +2) 위치에 검정으로 먼저 쓰고 원래 위치에 색으로 덧쓰기
- 종합 예제: 좌클릭 두 번 → 두 점으로 사각형, 우클릭 두 번 → 첫 점 중심, 두 점 거리 √(dx² + dy²)를 반지름으로 원
### 영상 파일 입출력
- `cv2.imread(filename, flags)` → ndarray (실패 시 **None**, 예외 아님)
| flags | 값 | 의미 |
|---|---|---|
| `IMREAD_UNCHANGED` | −1 | 파일 그대로 (알파 채널, 16·32비트 포함) |
| `IMREAD_GRAYSCALE` | 0 | 흑백 1채널 |
| `IMREAD_COLOR` | 1 | 컬러 BGR 3채널 (기본) |
| `IMREAD_ANYDEPTH` | 2 | 16/32비트 깊이 유지 |
| `IMREAD_ANYCOLOR` | 4 | 파일의 색 형식대로 |
- 흑백 파일을 COLOR로 읽으면 3채널(세 값이 같음), 컬러 파일을 GRAYSCALE로 읽으면 1채널
- 자료형 → OpenCV 타입: `uint8` CV_8U, `int8` CV_8S, `uint16` CV_16U, `int16` CV_16S, `float32` CV_32F, `float64` CV_64F (+ 채널 수, 예: CV_8UC3)
- 자주 쓰는 함수는 `Common/utils.py` 같은 공통 모듈로 빼서 `from Common.utils import print_matInfo`
- `cv2.imwrite(filename, img, params)` — **확장자로 형식 결정**(jpg, png, bmp, tif …)
| params | 범위 (기본) | 의미 |
|---|---|---|
| `IMWRITE_JPEG_QUALITY` | 0~100 (95) | 클수록 고화질 |
| `IMWRITE_PNG_COMPRESSION` | 0~9 (3) | 클수록 작은 파일, 느린 압축 (PNG는 무손실이라 화질은 같음) |
| `IMWRITE_PXM_BINARY` | 0/1 (1) | PPM/PGM 이진 형식 |
```python
image = cv2.imread("images/read_color.jpg", cv2.IMREAD_COLOR)
if image is None: raise Exception("영상파일 읽기 에러")
cv2.imwrite("images/write_test2.jpg", image, (cv2.IMWRITE_JPEG_QUALITY, 10))
cv2.imwrite("images/write_test3.png", image, [cv2.IMWRITE_PNG_COMPRESSION, 9])
ok = cv2.imwrite("iamges/write_test4.bmp", image)   # 슬라이드의 폴더명 오타
print(ok)   # False ← 없는 폴더면 예외 없이 False만 반환 → 저장 안 된 걸 모르고 넘어가기 쉬움
```
- 16·32비트 저장: `np.uint16(image8 * (65535 / 255))`, `np.float32(image8 / 255)` → `.tif`로 저장. 32비트 실수 영상은 `imshow`에서 0~1을 0~255로 보여주므로 표시할 땐 `(img * 255).astype('uint8')`
- 동영상: `cv2.VideoCapture`(파일·카메라 열기, `read()`로 프레임, `get`/`set`으로 속성), `cv2.VideoWriter` + `cv2.VideoWriter_fourcc()`(코덱)로 저장
### Matplotlib
- 그래프 라이브러리, `pyplot`은 MATLAB 스타일. Jupyter·Colab에선 `cv2.imshow` 대신 사용
- **OpenCV = BGR, Matplotlib = RGB** → 변환 없이 띄우면 빨강·파랑이 바뀐 색으로 보임
```python
import matplotlib.pyplot as plt
image = cv2.imread("images/matplot.jpg", cv2.IMREAD_COLOR)
rgb_img = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
gray_img = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

plt.figure(figsize=(6, 4))
plt.suptitle('pyplot image display')
plt.subplot(1, 2, 1), plt.imshow(rgb_img), plt.title('rgb color'), plt.axis('off')
plt.subplot(1, 2, 2), plt.imshow(gray_img, cmap='gray'), plt.title('gray')   # 흑백은 cmap 필수 (없으면 컬러맵으로 칠해짐)
plt.tight_layout()
plt.show()
```
| 함수 | 역할 |
|---|---|
| `figure(num, figsize, dpi)` | 그림 생성 (크기는 인치) |
| `imshow(X, cmap, interpolation, alpha)` | 영상 표시 (보간: nearest, bilinear, bicubic …) |
| `plot(x, y, fmt)` | 그래프. fmt = `'[색][마커][선]'` 예: `'b--'`, `'go-'`, `'c+:'` |
| `subplot(행, 열, 번호)` / `subplots(nrows, ncols)` | 여러 칸 |
| `title`, `suptitle`, `axis`, `tight_layout`, `savefig`, `show` | 제목, 전체 제목, 축, 여백, 저장, 표시 |
```python
x = np.arange(10)
plt.plot(x, x, 'b--', linewidth=2)       # 파란 파선
plt.plot(x, x ** 2, 'go-', linewidth=3)  # 초록 원 마커 실선
plt.savefig('sample.png', dpi=300)
plt.show()
```
