> R에도 if/else, for, while, break/next가 있지만, 데이터에는 벡터 단위로 한 번에 처리하는 ifelse(), apply(), which()를 쓰는 게 R답다. 함수는 `이름 <- function(매개변수) { … return(값) }`.
### if-else
```r
job.type <- "A"
if (job.type == "B") {
  bonus <- 200
} else {
  bonus <- 100
}
print(bonus)   # 100
```
- **`else`는 앞 블록의 `}`와 같은 줄에** (`}` 다음 줄에 `else`를 쓰면 R은 if문이 끝난 줄 알고 에러)
- 비교는 `==` (`job.type = "B"`는 에러)
- else 없는 if, 다중 if
```r
score <- 85
if (score > 90) {
  grade <- "A"
} else if (score > 80) {
  grade <- "B"
} else if (score > 70) {
  grade <- "C"
} else if (score > 60) {
  grade <- "D"
} else {
  grade <- "F"
}
print(grade)   # "B"
```
- `{ }` 코드블록: 여러 명령을 하나로 묶음
- 논리 연산자: `&`(and), `|`(or)
```r
a <- 10; b <- 20
if (a > 5 & b > 5) print(a + b)    # 30
if (a > 5 | b > 30) print(a * b)   # 200
```
  - if의 조건엔 값 하나짜리를 위한 `&&`, `||`도 많이 씀 (R 4.3부터는 길이가 2 이상인 벡터를 `&&`에 넣으면 에러)
### ifelse()
- `ifelse(test, yes, no)`: 조건에 따라 둘 중 하나 (C의 `a > b ? a : b`)
```r
a <- 10; b <- 20
c <- ifelse(a > b, a, b)
print(c)   # 20
```
- 진짜 강점은 **벡터 전체에 원소별로** 적용된다는 것
```r
ifelse(c(1, 5, 10) > 3, "big", "small")   # "small" "big" "big"
```
### for
- `for (반복 변수 in 반복 범위) { … }` — 범위 벡터의 원소를 차례로 꺼냄
```r
for (i in 1:5) print("*")            # * 다섯 번
for (i in 6:10) print(i)             # 6 7 8 9 10
for (i in seq(1, 10, by = 2)) print(i)  # 1 3 5 7 9

for (i in 1:9) cat("2 *", i, "=", 2 * i, "\n")   # 구구단 2단

for (i in 1:20) {
  if (i %% 2 == 0) print(i)          # 짝수만
}

sum <- 0
for (i in 1:100) sum <- sum + i
print(sum)                           # 5050
```
- iris 꽃잎 길이로 등급 매기기
```r
norow <- nrow(iris)
mylabel <- c()                        # 빈 벡터
for (i in 1:norow) {
  if (iris$Petal.Length[i] <= 1.6) {
    mylabel[i] <- "L"
  } else if (iris$Petal.Length[i] >= 5.1) {
    mylabel[i] <- "H"
  } else {
    mylabel[i] <- "M"
  }
}
newds <- data.frame(iris$Petal.Length, mylabel)
head(newds)
#   iris.Petal.Length mylabel
# 1               1.4       L
# …
# 6               1.7       M
```
  - 결과 개수: L 44, M 64, H 42
  - 반복문 없이 한 줄로: `ifelse(iris$Petal.Length <= 1.6, "L", ifelse(iris$Petal.Length >= 5.1, "H", "M"))`
### while, break, next
```r
sum <- 0; i <- 1
while (i <= 100) {
  sum <- sum + i
  i <- i + 1
}
print(sum)   # 5050
```
- `while (TRUE)` 무한 루프는 콘솔 오른쪽 위 빨간 STOP으로 중단
- `break`: 반복문 탈출 / `next`: 이번 반복만 건너뜀 (C의 continue)
```r
sum <- 0
for (i in 1:10) {
  sum <- sum + i
  if (i >= 5) break
}
sum   # 15 (1+2+3+4+5)

sum <- 0
for (i in 1:10) {
  if (i %% 2 == 0) next
  sum <- sum + i
}
sum   # 25 (홀수 합)
```
### apply()
- 매트릭스·데이터프레임의 **행 또는 열마다** 함수를 적용 (for 대신)
- `apply(X, MARGIN, FUN)`: MARGIN 1 = 행별, 2 = 열별
```r
apply(iris[, 1:4], 1, mean)   # 150개: 2.550 2.375 2.350 …
apply(iris[, 1:4], 2, mean)
# Sepal.Length  Sepal.Width Petal.Length  Petal.Width
#     5.843333     3.057333     3.758000     1.199333
```
- 같은 결과: `rowMeans()`, `colMeans()`. 벡터·리스트에는 `sapply(1:3, function(x) x^2)` → 1 4 9, `lapply()`(리스트로 반환)
### 사용자 정의 함수
```r
mymax <- function(x, y) {
  num.max <- x
  if (y > x) num.max <- y
  return(num.max)
}
mymax(10, 15)                    # 15
a <- mymax(20, 15); b <- mymax(31, 45)
print(a + b)                     # 65
```
- 매개변수 기본값
```r
mydiv <- function(x, y = 2) {
  result <- x / y
  return(result)
}
mydiv(x = 10, y = 3)   # 3.333333
mydiv(10, 3)           # 3.333333
mydiv(10)              # 5 (y는 기본값 2)
```
- 결과가 여러 개면 **리스트**로 반환
```r
myfunc <- function(x, y) {
  val.sum <- x + y
  val.mul <- x * y
  return(list(sum = val.sum, mul = val.mul))
}
result <- myfunc(5, 8)
cat("5+8=", result$sum, "\n")   # 5+8= 13
cat("5*8=", result$mul, "\n")   # 5*8= 40
```
- `return()`을 생략하면 마지막 식의 값이 반환됨
- 다른 파일의 함수 쓰기: `source("myfunc.R")` → 그 파일을 실행해 함수가 정의됨
```r
setwd("d:/source")
source("myfunc.R")
mydiv(20, 4) + mydiv(30, 4)   # 12.5
mydiv(mydiv(20, 2), 5)        # 2
```
### which(): 조건에 맞는 위치
```r
score <- c(76, 84, 69, 50, 95, 60, 82, 71, 88, 84)
which(score == 69)    # 3
which(score >= 85)    # 5 9
which.max(score)      # 5  (최고점 95의 위치)
which.min(score)      # 4  (최저점 50의 위치)

idx <- which(score <= 60)
score[idx] <- 61      # 60 이하를 61로
score                 # 76 84 69 61 95 61 82 71 88 84
score[which(score >= 80)]   # 84 95 82 88 84
```
- 데이터프레임 행 고르기
```r
idx <- which(iris$Petal.Length > 5.0)   # 42개: 84 101 102 …
iris.big <- iris[idx, ]
```
- `arr.ind = TRUE`: 2차원에서 (행, 열) 위치로 반환
```r
idx <- which(iris[, 1:4] > 5.0, arr.ind = TRUE)   # 160행 × (row, col)
```
- 참고: `iris[iris$Petal.Length > 5.0, ]`처럼 논리 벡터로 바로 걸러도 결과는 같음. which는 **위치 번호 자체**가 필요할 때 (NA는 자동으로 빠짐)
