> 빅데이터는 5V(크기·속도·다양성·신뢰도·가치)로 설명하고, 분석은 문제 정의 → 수집 → 전처리 → 탐색(EDA) → 분석 → 보고·적용 6단계로 진행된다. 시간이 가장 많이 드는 건 전처리. 실습 도구는 R + RStudio.
### 데이터의 시대
- 정보화 시대(정보 처리의 **효율성**) → 데이터 시대(얼마나 많은 데이터를 확보하고 **분석**하느냐)
- 예: 구글 데이터센터 — 전 세계 15곳, 서버 250만여 대, 사용자 30억 명의 데이터, 최소 15EB (1EB ≈ 10억 7천만 GB)
- 대형마트: 구매 패턴 분석 → 맥주와 견과류를 함께 사는 비율이 높음 → 옆에 진열 → 동반 매출 상승 (연관 분석의 대표 사례)
- "데이터는 새로운 석유다" (클라이브 험비)
- **4차 산업혁명** (2016 다보스 세계경제포럼, 클라우스 슈밥): AI, 빅데이터, 로봇, IoT, 생명공학, 3D 프린터 → 빅데이터는 핵심 기술
  - 1차(18세기) 증기 기계 → 2차(19~20세기) 전기·대량 생산 → 3차(20세기 후반) 컴퓨터·인터넷 → 4차(21세기) 인공지능·정보통신
- AI의 두 번째 침체 원인은 **데이터 부족** → 2010년대 빅데이터 + 딥러닝으로 부활
### 빅데이터의 5V
| V | 의미 | 예 |
|---|---|---|
| Volume (크기) | 기존 DB 도구의 수집·저장·분석 역량을 넘어서는 규모 (수십 TB~PB 이상) | 환자, 금융 거래, 대중교통 이용 |
| Velocity (속도) | 빠르게 생성·소비됨 | 지하철 승하차, SNS 메시지 |
| Variety (다양성) | 정형·반정형·비정형 | 아래 표 |
| Veracity (신뢰도) | 정확성, 출처 신뢰성, 무결성, 일관성 | Garbage In, Garbage Out |
| Value (가치) | 실제 비즈니스·사회적 가치를 만들어야 진짜 빅데이터 | 맞춤 마케팅, 불량률 감소, 질병 예측 |
- 원래 3V(Volume, Velocity, Variety)에 Veracity, Value가 더해져 5V
- 속도 예: 1인당 초당 약 1.7MB × 약 80.6억 명 → **초당** 약 1.37 × 10¹⁰ MB(≈ 13,700TB). 슬라이드에는 "매일 130억 MB"로 적혀 있는데, 계산해 보면 하루가 아니라 1초 분량
| 구분 | 설명 | 예 |
|---|---|---|
| 정형 | 고정된 필드, 일정한 형식 | 관계형 DB, 엑셀 |
| 반정형 | 고정 구조는 없지만 스키마(메타데이터)로 구조 파악 가능 | XML, HTML, JSON |
| 비정형 | 고정 필드 없음 | 사진, 동영상, 메신저 대화, 위치 기록 |
- 신뢰도 낮은 데이터: SNS 허위 정보, 중복·누락·오류, 오타 → 정제, 결측값 처리, 믿을 만한 출처로 확보
- 가치의 핵심: 수익 증가, 비용 절감, 의사결정 개선, 생산성 향상, 고객 만족, 위험 감소. 데이터는 **분석해서 의미를 뽑아야** 자산
### 업무 데이터의 분류
| 구분 | 설명 | 특징 | 예 |
|---|---|---|---|
| 원천(Raw) | 가공 전 최초 기록 | 오류·중복·노이즈 포함 가능 | 클릭 로그, 진료기록 원본, 센서 초 단위 값 |
| 운영 | 서비스·업무에 직접 사용 | 실시간, **정확성·무결성** 중요, DB | 실시간 재고, 계좌 잔액, 배송 상태 |
| 분석 | 의사결정용으로 가공·정제 | 결측·중복 제거, 집계, **활용도·가치** 중요, 데이터 웨어하우스 | 월 구매금액, 질병 발생률, 고장 확률 |
- 흐름 예: 주문 기록 원본(원천) → 지역별 인기 메뉴 분석(분석) → 화면의 인기 메뉴 순위(운영)
- 금융: 계좌 잔액·거래 내역(운영) → 이력 축적·통계 → 신용점수, 연체 위험, 고객 세그먼트(분석)
### 데이터 분석 6단계
1. **문제 정의 및 계획**: 무엇으로 어떤 지식을 얻을지. 가장 중요하고 가장 어려움 ("문제 정의에 55분, 해결에 5분" — 아인슈타인)
   - 예: 고객 이탈 예측, 추천 시스템, 부정 거래 탐지, 공급망 최적화, SNS 감성 분석 (각각 활용 데이터와 비즈니스 가치를 함께 정의)
1. **데이터 수집**: 내부(DB, 파일 → 주로 정형) / 외부(인터넷 → 주로 비정형)
   - 수집 도구: Flume(서버 로그 → Hadoop), Sqoop(RDBMS ↔ Hadoop import/export), 크롤링(웹페이지 → csv·txt·xml), Open API(공공 데이터)
   - 저장: **HDFS**(여러 컴퓨터에 블록 단위로 분산·복제 저장 → 장애 시 빠른 복구), **NoSQL**(무결성 대신 가용성·확장성, 비정형·실시간에 적합)
   - 공공데이터 포털(data.go.kr), 서울 열린데이터 광장, 기상자료 개방 포털, 국가교통DB 등
1. **정제 및 전처리**: 단위 차이, 중복, 결측, 오류를 고쳐 분석 가능한 형태로. **가장 시간이 많이 드는 단계** (전처리 40% > 수집 20% > 탐색 15% > 문제 정의 10% = 모델링 10% > 배포 5%)
   - 결측치(평균·중앙값 대체, 삭제, 예측), 이상치(IQR, Z-score), 정규화(Min-Max 0~1) / 표준화(평균 0, 표준편차 1), 중복 제거, 텍스트 정제(정규식, NLP), 범주형 인코딩(원-핫, 레이블), 날짜 분해(연·월·일·요일)
1. **탐색(EDA)**: 모델링 전에 구조·패턴·이상치·분포 파악 — 기초 통계(평균, 중앙값, 표준편차), 분포(정규성), 이상치, 상관관계. 분석 결과의 70~80%가 데이터 이해 수준에 달림
   - 예: 불량률이 늘었다면 특정 시간대? 온도와 상관? 특정 설비? → 원인 후보 좁히기
1. **분석**: 통계 분석, 데이터 마이닝, 머신러닝
1. **보고 및 적용**: 핵심은 **시각화** ("구슬이 서 말이라도 꿰어야 보배"). 적용(Deployment)은 끝이 아니라 시작 — 성능 모니터링, 데이터 변화(Data Drift) 감지, 재학습, 장애 대응
### 분석 기법 분류
- **정형 데이터**
  - 기술통계: 빈도, 교차, 평균·표준편차·최빈값·왜도·사분위수
  - 추론통계: 평균 차이(t-검정), 분산분석(ANOVA), 상관, 회귀
  - 데이터 마이닝: 분류, 예측, 군집, 연관
- **비정형 데이터**: 텍스트 마이닝(주제어, 동시 출현 단어, 토픽 모델링), 오피니언 마이닝(감성 분석), 소셜 네트워크 분석
- **시각화**: 정보 시각화(도표·그래프, 예: 앤스컴 콰르텟), 과학적 시각화(3D, MRI 등), 인포그래픽
| 대분류 | 세부 | 기법 |
|---|---|---|
| 통계(가설검정) | 차이검정 | t-검정, ANOVA |
| | 관계검정(설명) | 교차분석(카이제곱), 상관분석 |
| | 관계검정(예측) | 회귀, 로지스틱 회귀, 시계열(평활법) |
| 데이터마이닝 | 지도학습 – 수치 예측 | 결정나무, 회귀, 신경망, k-NN |
| | 지도학습 – 범주 분류 | 분류나무, 로지스틱 회귀, 판별분석 |
| | 비지도학습 | 연관규칙, 군집분석 |
| 기계학습 | 지도 / 비지도 / 강화 / 딥러닝 | 분류·회귀 / 군집·변환·연관 / Model-free·Model-based RL / DNN, CNN |
- **지도학습**: 문제와 정답을 함께 학습 → 새 문제의 답 예측 (장미 사진 + 품종 → 새 사진의 품종)
- **비지도학습**: 정답 없이 패턴·구조를 스스로 찾음
- **강화학습**: 에이전트가 상태를 보고 행동해 **보상**이 최대가 되도록 학습 (시행착오)
### R과 RStudio
- R: 데이터 분석 전용 언어 (응용 소프트웨어 제작용은 아님), 인터프리터, 풍부한 패키지, 뛰어난 시각화. Python은 범용 프로그래밍 성격이 더 강함
- 설치: r-project.org에서 R → posit.co에서 RStudio Desktop
  - 주의: 윈도우 계정 이름·설치 경로에 **한글 금지**, OneDrive·구글 드라이브 연동 폴더 피하기
- RStudio 화면: 편집(Script) 창, 콘솔(Console) 창, 환경(Environment) 창, 파일 창(Files, Plots, Packages, Help, Viewer 탭)
```r
5 + 8          # [1] 13
3 + (4 * 5)    # [1] 23
a <- 10        # 대입은 <-
print(a)       # [1] 10
```
