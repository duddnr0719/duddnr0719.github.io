> OpenCV 행렬 함수는 원소별(per-element)로 동작하고 결과를 자료형 범위에 맞춰 포화(saturate)시킨다. 뒤집기·반복·전치, 채널 split/merge, add·subtract·divide·addWeighted(마스크 가능), 비트 연산으로 합성, absdiff·min/max·minMaxLoc, 합·평균·정렬·reduce, gemm·invert·solve까지.
### 배열, 벡터, 행렬
- OpenCV-Python의 행렬 = NumPy `ndarray`. 1차원 = 벡터, 2차원 = 행렬, 통틀어 배열
- 벡터는 n×1(열벡터) 또는 1×n(행벡터) 행렬. NumPy에선 `shape (3,)`(1차원), `(3, 1)`(열벡터), `(1, 3)`(행벡터)가 서로 다름
- 행렬 × 벡터 = 선형변환(크기·방향을 바꿈)
### 기본 배열 처리
| 함수 | 동작 |
|---|---|
| `cv2.flip(src, flipCode)` | 0: 상하(x축 기준), 1: 좌우(y축 기준), −1: 둘 다 |
| `cv2.repeat(src, ny, nx)` | 세로 ny번, 가로 nx번 반복해 이어 붙임 |
| `cv2.transpose(src)` | 전치 (행↔열, 영상이 대각선 기준으로 뒤집힘) |
| `cv2.hconcat([A, B])` / `cv2.vconcat([A, B])` | 가로 / 세로로 붙이기 (`np.hstack`, `np.vstack`과 같음) |
```python
image = cv2.imread("images/flip_test.jpg", cv2.IMREAD_COLOR)
x_axis  = cv2.flip(image, 0)          # = image[::-1, :]
y_axis  = cv2.flip(image, 1)          # = image[:, ::-1]
xy_axis = cv2.flip(image, -1)         # = 180도 회전
rep_image = cv2.repeat(image, 1, 2)   # 가로로 2번
trans_image = cv2.transpose(image)    # = np.transpose(image, (1, 0, 2))
for title in ['image', 'x_axis', 'y_axis', 'xy_axis', 'rep_image', 'trans_image']:
    cv2.imshow(title, eval(title))    # eval: 문자열을 변수 이름으로 평가
cv2.waitKey(0)
```
### 채널
- 영상 = 너비 × 높이 × 채널. 3채널이면 컬러(**B, G, R 순서**), 1채널이면 흑백
- `cv2.split(m)` → 단일 채널 배열들 / `cv2.merge([c0, c1, c2])` → 다채널 (크기·자료형이 같아야 함)
```python
ch0 = np.zeros((2, 4), np.uint8) + 10
ch1 = np.ones((2, 4), np.uint8) * 20
ch2 = np.full((2, 4), 30, np.uint8)
merge_bgr = cv2.merge([ch0, ch1, ch2])
split_bgr = cv2.split(merge_bgr)
merge_bgr.shape             # (2, 4, 3)  ← 채널이 마지막 축
np.array(split_bgr).shape   # (3, 2, 4)
merge_bgr[0, 0]             # [10 20 30]  한 화소의 B, G, R
```
- 컬러 영상 분리: `b, g, r = cv2.split(image)` 또는 `image[:, :, 0]`(Blue). 각 채널을 흑백으로 띄우면 **그 색 성분이 많은 곳이 밝게** 보임
  - `split`은 복사본을 만들고, 슬라이싱 `image[:, :, 0]`은 뷰(복사 없음)라 더 빠름
### 사칙 연산
- 두 행렬의 **같은 위치 원소끼리** 계산, 결과는 **saturate**(uint8이면 0~255로 잘림)
| 함수 | 식 |
|---|---|
| `cv2.add(a, b, mask)` | saturate(a + b), mask가 0이 아닌 곳만 |
| `cv2.subtract(a, b, mask)` | saturate(a − b) |
| `cv2.multiply(a, b, scale)` | saturate(scale · a · b) |
| `cv2.divide(a, b, scale)` / `divide(scale, b)` | saturate(scale · a / b) |
| `cv2.addWeighted(a, α, b, β, γ)` | saturate(a·α + b·β + γ) — 두 영상 블렌딩 |
```python
m1 = np.full((3, 6), 10, np.uint8)
m2 = np.full((3, 6), 50, np.uint8)
m_mask = np.zeros(m1.shape, np.uint8)
m_mask[:, 3:] = 1                          # 0이 아니기만 하면 됨

cv2.add(m1, m2)                            # 전부 60
cv2.add(m1, m2, mask=m_mask)               # [[0 0 0 60 60 60] …]  마스크 밖은 0
cv2.divide(m1, m2)                         # 전부 0   (10/50 = 0.2 → 정수)
cv2.divide(m1.astype(np.float32), m2.astype(np.float32))   # 전부 0.2
```
- uint8 나눗셈은 소수점을 **버리는 게 아니라 반올림**함: 10/50 = 0.2 → 0이지만, 30/50 = 0.6 → **1** (OpenCV 4.13으로 확인). 정밀도가 필요하면 float로 바꿔서 계산
- NumPy `+`는 포화가 아니라 **넘침**(200 + 100 → 44), `cv2.add`는 255 → 영상 밝기 조절엔 cv2 함수
### 지수, 로그, 극좌표
| 함수 | 식 |
|---|---|
| `cv2.exp`, `cv2.log`, `cv2.sqrt`, `cv2.pow(src, p)` | eˣ, ln\|x\|, √x, xᵖ |
| `cv2.magnitude(x, y)` | √(x² + y²) |
| `cv2.phase(x, y, angleInDegrees)` | atan2(y, x) (라디안 / 도) |
| `cv2.cartToPolar(x, y)` → (크기, 각도) | 직교 → 극좌표 |
| `cv2.polarToCart(mag, ang)` → (x, y) | 극 → 직교 |
- 입력은 float32/64 ndarray. **1차원 `(3,)`을 넣어도 결과는 `(3, 1)` 열벡터**로 나옴 → 한 줄로 보려면 `.T`, `np.ravel()`, `.flatten()`
```python
v1 = np.array([1, 2, 3], np.float32)
cv2.exp(v1).shape                 # (3, 1)
cv2.log(v1).T                     # [[0. 0.6931472 1.0986123]]
cv2.pow(v1, 3).flatten()          # [ 1.  8. 27.]

x = np.array([1, 2, 3, 5, 10], np.float32)
y = np.array([2, 5, 7, 2, 9], np.float32)
cv2.magnitude(x, y).ravel()       # [ 2.236  5.385  7.616  5.385 13.454]
cv2.phase(x, y).ravel()           # [1.107  1.190  1.166  0.381  0.733] (라디안)
mag, ang = cv2.cartToPolar(x, y)
x2, y2 = cv2.polarToCart(mag, ang)   # 원래 x, y로 복원 (약간의 오차: 1.00007 …)
```
  - cartToPolar의 각도는 빠른 근사 계산이라 polarToCart로 되돌리면 소수 셋째 자리쯤 오차가 남음
### 비트 연산과 합성
- `cv2.bitwise_and / or / xor(a, b, mask)`, `cv2.bitwise_not(a)` — 0과 255로 된 마스크 영상이면 사실상 **집합 연산**(교집합, 합집합, 대칭차, 여집합)
```python
image1 = np.zeros((300, 300), np.uint8)
image2 = image1.copy()
cx, cy = 150, 150
cv2.circle(image1, (cx, cy), 100, 255, -1)          # 가운데 흰 원
cv2.rectangle(image2, (0, 0, cx, 300), 255, -1)     # 왼쪽 절반 흰색
cv2.bitwise_or(image1, image2)    # 원 ∪ 왼쪽 절반
cv2.bitwise_and(image1, image2)   # 원의 왼쪽 반
cv2.bitwise_xor(image1, image2)   # 둘 중 한쪽에만 있는 부분
cv2.bitwise_not(image1)           # 반전
```
- 로고 합성: 로고를 이진화해 전경 마스크와 배경 마스크(`bitwise_not`)를 만든 뒤
```python
masks = cv2.split(cv2.threshold(logo, 220, 255, cv2.THRESH_BINARY)[1])
fg_pass_mask = cv2.bitwise_or(cv2.bitwise_or(masks[0], masks[1]), masks[2])
bg_pass_mask = cv2.bitwise_not(fg_pass_mask)

(H, W), (h, w) = image.shape[:2], logo.shape[:2]
x, y = (W - w) // 2, (H - h) // 2
roi = image[y:y + h, x:x + w]                                  # 가운데 영역 (뷰)
foreground = cv2.bitwise_and(logo, logo, mask=fg_pass_mask)    # 로고 글자만
background = cv2.bitwise_and(roi, roi, mask=bg_pass_mask)      # 원본에서 글자 자리만 비움
image[y:y + h, x:x + w] = cv2.add(background, foreground)
```
  - 흰 배경 로고를 220 기준으로 이진화했으므로 "220 이상(흰색)인 부분"이 fg 마스크가 됨 → 로고의 밝은 부분을 남기는 구조. 어두운 글자를 남기려면 `THRESH_BINARY_INV`
### 절댓값, 최소·최대
- `cv2.absdiff(a, b)`: |a − b| (포화 없이 정확한 차이, 두 영상의 변화 감지)
- `cv2.convertScaleAbs(src, alpha, beta)`: |src·α + β| → uint8 (밝기·대비 조절, 엣지 결과 표시용)
```python
dif_img1 = cv2.subtract(image1, image2)                       # uint8: 음수는 0으로 잘림
dif_img2 = cv2.subtract(np.int16(image1), np.int16(image2))   # int16: −100, −106 … 보존
abs_dif1 = np.absolute(dif_img2).astype('uint8')
abs_dif2 = cv2.absdiff(image1, image2)                        # abs_dif1과 같음
```
- `cv2.min(a, b)`, `cv2.max(a, b)` (스칼라와도 가능), `cv2.minMaxLoc(src)` → (최솟값, 최댓값, 최솟값 위치, 최댓값 위치)
```python
m1 = np.array([10, 200, 5, 7, 9,
               15, 35, 60, 80, 170,
               100, 2, 55, 37, 70]).reshape(3, 5)
cv2.min(m1, 30)    # 30보다 큰 값은 30으로
cv2.max(m1, np.full((3, 5), 50))   # 50보다 작은 값은 50으로
cv2.minMaxLoc(m1.astype(np.float32))
# (2.0, 200.0, (1, 2), (1, 0))  ← 위치가 (x, y) = (열, 행)! 최솟값 2는 2행 1열
```
- 대비 늘리기(스트레칭): 새 값 = (화소 − min) × 255 / (max − min) → 13~107 범위였던 영상이 0~255로 (13 → 0, 60 → 128, 107 → 255)
```python
min_val, max_val, _, _ = cv2.minMaxLoc(image)
dst = np.round((image - min_val) * (255 / (max_val - min_val))).astype('uint8')
```
### 통계와 정렬
| 함수 | 반환 |
|---|---|
| `cv2.sumElems(src)` | 채널별 합, 4원소 튜플 (없는 채널은 0) |
| `cv2.mean(src, mask)` | 채널별 평균, 4원소 튜플 |
| `cv2.meanStdDev(src, mask)` | (평균, 표준편차) ndarray (float64) |
| `cv2.countNonZero(src)` | 0이 아닌 원소 수 (1채널만) |
| `cv2.reduce(src, dim, rtype)` | dim 0: 열마다 계산해 1행으로, 1: 행마다 계산해 1열로 / `REDUCE_SUM`(0), `AVG`(1), `MAX`(2), `MIN`(3) |
| `cv2.sort(src, flags)` | `SORT_EVERY_ROW`(0, 가로) / `SORT_EVERY_COLUMN`(1, 세로) + `SORT_DESCENDING`(16) |
| `cv2.sortIdx(src, flags)` | 정렬 결과의 **원래 인덱스** (`np.argsort`) |
```python
mask = np.zeros(image.shape[:2], np.uint8)
mask[60:160, 20:120] = 255
cv2.sumElems(image)       # (15865577.0, 15880547.0, 16470875.0, 0.0)
cv2.mean(image)           # (132.21, 132.34, 137.26, 0.0)
cv2.mean(image, mask)     # 마스크 영역만: (80.27, 81.60, 90.32, 0.0)
mean, stddev = cv2.meanStdDev(image)    # [132.2 132.3 137.3], [73.4 68.8 64.0]

m = np.array([[41, 16, 59, 33, 38], [34, 59, 23, 32, 64], [14, 79, 86, 76, 84]], np.float32)
cv2.reduce(m, 0, cv2.REDUCE_SUM).flatten()   # [ 89. 154. 168. 141. 186.]
cv2.reduce(m, 1, cv2.REDUCE_AVG).flatten()   # [37.4 42.4 67.8]
cv2.reduce(m, 0, cv2.REDUCE_MAX).flatten()   # [41. 79. 86. 76. 84.]
cv2.reduce(m, 1, cv2.REDUCE_MIN).flatten()   # [16. 23. 14.]
```
  - 슬라이드 표의 `REDUCE_MAX = 3`, `REDUCE_MIN = 4`는 오기, 실제 상수는 MAX 2, MIN 3. 숫자 대신 상수 이름을 쓰면 안전
- sortIdx 활용: 무작위 사각형 5개의 넓이를 계산하고 `idx = cv2.sortIdx(areas, cv2.SORT_EVERY_COLUMN).flatten()` → `rects[idx]`로 넓이 순 정렬 (`cv2.randn(arr, 평균, 표준편차)`로 정규분포 난수 채우기)
### 행렬 연산 (선형대수)
- `cv2.gemm(src1, src2, alpha, src3, beta, flags)` = α · src1 · src2 + β · src3 (float만). flags: `GEMM_1_T`(1, src1 전치), `GEMM_2_T`(2), `GEMM_3_T`(4)
```python
src1 = np.array([1, 2, 3, 1, 2, 3], np.float32).reshape(2, 3)
src2 = np.array([1, 2, 3, 4, 5, 6], np.float32).reshape(2, 3)
src3 = np.array([1, 2, 1, 2, 1, 2], np.float32).reshape(3, 2)
cv2.gemm(src1, src2, 1, None, 1, flags=cv2.GEMM_1_T)   # src1ᵀ·src2 → [[5 7 9] [10 14 18] [15 21 27]]
cv2.gemm(src1, src2, 1, None, 1, flags=cv2.GEMM_2_T)   # src1·src2ᵀ → [[14 32] [14 32]]
cv2.gemm(src1, src3, 1, None, 1)                       # → [[6 12] [6 12]]   (= src1 @ src3)
```
- 회전 변환: 회전 행렬 R = [[cos θ, −sin θ], [sin θ, cos θ]], 좌표들을 행으로 쌓은 P에 대해 **P · Rᵀ**
```python
theta = np.radians(20)
rot_mat = np.array([[np.cos(theta), -np.sin(theta)],
                    [np.sin(theta),  np.cos(theta)]], np.float32)
pts1 = np.array([(250, 30), (400, 70), (350, 250), (150, 200)], np.float32)
pts2 = cv2.gemm(pts1, rot_mat, 1, None, 1, flags=cv2.GEMM_2_T)
# (250, 30) → (224.66, 113.70), (400, 70) → (351.94, 202.59), …
cv2.polylines(image, [np.int32(pts1)], True, (0, 255, 0), 2)
cv2.polylines(image, [np.int32(pts2)], True, (255, 0, 0), 3)
```
  - 원점이 왼쪽 위이고 y가 **아래로** 증가하는 영상 좌표라서, 수학적으로 반시계 20°인 이 행렬이 화면에선 **시계 방향**으로 돌아 보임
- 투영 변환 `cv2.perspectiveTransform(pts, M)`: (x', y', w') = M · (x, y, 1) 후 (x'/w', y'/w')
- 역행렬·연립방정식: `cv2.invert(src, flags)` → (ret, inv), `cv2.solve(A, b, flags)` → (ret, x)
  - flags: `DECOMP_LU`(0, 가우스 소거, 정방·가역), `DECOMP_SVD`(1, 비정방이면 의사역행렬·최소제곱), `DECOMP_CHOLESKY`(3, 대칭 양정치)
```python
# 3x₁ + 6x₃ = 36,  −3x₁ + 4x₂ + 2x₃ = 10,  −5x₁ − x₂ + 9x₃ = 28
m1 = np.array([3, 0, 6, -3, 4, 2, -5, -1, 9], np.float32).reshape(3, 3)
m2 = np.array([36, 10, 28], np.float32)
ret, inv = cv2.invert(m1, cv2.DECOMP_LU)
if ret:                                   # 0이면 역행렬 없음 (특이행렬)
    dst1 = inv.dot(m2)                    # [2.5238 2.0238 4.7381]
    dst2 = cv2.gemm(inv, m2, 1, None, 1)
    _, dst3 = cv2.solve(m1, m2, cv2.DECOMP_LU)
```
  - 검산: 3 × 2.5238 + 6 × 4.7381 = 36 ✓ (NumPy `np.linalg.solve`도 같은 해)
  - 실전에선 역행렬을 구해 곱하는 것보다 `solve`가 더 빠르고 수치적으로 안정적
