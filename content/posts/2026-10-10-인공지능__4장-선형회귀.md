> 선형 회귀 = 데이터를 가장 잘 설명하는 직선 f(x) = Wx + b 찾기. '잘 설명'은 MSE 손실로 재고, 최소화는 최소 제곱법(닫힌 해) 또는 경사 하강법(반복)으로 한다.
### 회귀란
- 데이터를 2차원에 찍고 이를 가장 잘 설명하는 직선·곡선을 찾는 문제. 입력·출력이 모두 실수인 y = f(x)를 예측
- 종류: 양의 선형, 음의 선형, 비선형 회귀
- 예: 부모 키 ↔ 자녀 키, 면적 → 집값, 연령 → 실업률, 공부 시간 ↔ 학점, CPU 속도 → 실행 시간
- 기본식 **f(x) = Wx + b**: 기울기 → **가중치(W)**, 절편 → **바이어스(b)**
- 단순 선형 회귀: 독립 변수 하나. w, b가 학습할 매개변수
- 다중 선형 회귀: f(x, y, z) = w₀ + w₁x + w₂y + w₃z
- 예: 키 174/152/138/128/186cm, 몸무게 71/55/46/38/88kg → 키 165cm면?
### 손실 함수
- 어떤 직선이 좋은가? 실제 데이터와 직선 사이 간격이 좁을수록 좋음
- 간격을 제곱해 평균낸 것 = 손실 함수(비용 함수), 즉 **MSE**
  - **Loss(W, b) = (1/n) Σ ((Wxᵢ + b) − yᵢ)²**
- 목표: **argmin_{W,b} Loss(W, b)**
- 최소화 방법: 최소 제곱법(OLS), 경사 하강법
### 최소 제곱법 (OLS)
- Loss = (1/n) Σ (yᵢ − wxᵢ − b)² 를 w, b로 각각 편미분해서 0이 되는 점
  - ∂Loss/∂w = −(2/n) Σ xᵢ(yᵢ − wxᵢ − b) = 0 → Σ xᵢ(yᵢ − wxᵢ − b) = 0
  - ∂Loss/∂b = −(2/n) Σ (yᵢ − wxᵢ − b) = 0 → Σ (yᵢ − wxᵢ − b) = 0
- b 먼저: Σyᵢ − wΣxᵢ − nb = 0 → **b = ȳ − w x̄** (전체 합을 n으로 나누면 평균)
- w: Σxᵢyᵢ = wΣxᵢ² + bΣxᵢ 에 b와 Σxᵢ = n x̄ 대입
  - Σxᵢyᵢ − n x̄ȳ = w(Σxᵢ² − n x̄²)
  - **w = (Σxᵢyᵢ − n x̄ȳ) / (Σxᵢ² − n x̄²) = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)² = Cov(x, y) / Var(x)**
  - 두 표현이 같은 이유: 분자를 전개하면 Σxᵢyᵢ − ȳΣxᵢ − x̄Σyᵢ + n x̄ȳ = Σxᵢyᵢ − n x̄ȳ, 분모도 Σxᵢ² − 2x̄Σxᵢ + n x̄² = Σxᵢ² − n x̄²
- 손으로 풀어보기: (1, 2), (2, 4), (3, 5), (4, 6), (5, 8)
  - x̄ = 3, ȳ = 5
  - Σ(x − x̄)(y − ȳ) = 6 + 1 + 0 + 1 + 6 = 14, Σ(x − x̄)² = 10
  - w = 1.4, b = 5 − 1.4 × 3 = 0.8 → **ŷ = 1.4x + 0.8**
- 입력이 2개(ŷ = w₁x₁ + w₂x₂ + b)일 때 슬라이드 식: w₁ = Cov(x₁, y)/Var(x₁), w₂ = Cov(x₂, y)/Var(x₂), b = ȳ − w₁x̄₁ − w₂x̄₂
  - 단, 이 식은 x₁과 x₂가 서로 상관이 없을 때만 정확함. 일반적으로는 정규방정식 w = (XᵀX)⁻¹Xᵀy로 풂
### 경사 하강법
- 산을 내려오듯, 현재 위치의 기울기(gradient)를 구해 **반대 방향**으로 조금씩 이동
  - 기울기가 양수면 W를 줄이고, 음수면 W를 늘림
- 학습률(learning rate): 한 번에 얼마나 움직일지. 너무 작으면 느리고, 너무 크면 발산
- 선형 회귀의 그래디언트
  - ∂Loss/∂W = (2/n) Σ xᵢ((Wxᵢ + b) − yᵢ)
  - ∂Loss/∂b = (2/n) Σ ((Wxᵢ + b) − yᵢ)
  - **W ← W − η·∂Loss/∂W, b ← b − η·∂Loss/∂b** (η = 0.01)
```python
import numpy as np
import matplotlib.pyplot as plt

X = np.array([0.0, 1.0, 2.0])
y = np.array([3.0, 3.5, 5.5])
W, b = 0, 0          # 기울기, 절편
lrate = 0.01         # 학습률
epochs = 1000
n = float(len(X))

for i in range(epochs):
    y_pred = W * X + b
    dW = (2 / n) * sum(X * (y_pred - y))
    db = (2 / n) * sum(y_pred - y)
    W = W - lrate * dW
    b = b - lrate * db

print(W, b)          # 1.2532... 2.7455... (OLS 정답 1.25, 2.75에 수렴 중)
y_pred = W * X + b
plt.scatter(X, y)
plt.plot([min(X), max(X)], [min(y_pred), max(y_pred)], color='red')
plt.show()
```
### sklearn으로 구현
- 입력 X는 열이 하나여도 **반드시 2차원** (리스트의 리스트)
```python
from sklearn import linear_model
reg = linear_model.LinearRegression()
X = [[0], [1], [2]]
y = [3, 3.5, 5.5]
reg.fit(X, y)

reg.coef_          # array([1.25])   기울기
reg.intercept_     # 2.75            절편
reg.score(X, y)    # 0.8928...       결정계수 R²
reg.predict([[5]]) # array([9.])     1.25×5 + 2.75
```
- 강의 슬라이드엔 `predict([[5]])` 결과가 8로 적혀 있지만, 직접 돌려보면 9가 나옴 (계산상으로도 9)
- 키-몸무게 실습
```python
reg = linear_model.LinearRegression()
X = [[174], [152], [138], [128], [186]]
y = [71, 55, 46, 38, 88]
reg.fit(X, y)
print(reg.predict([[165]]))   # [67.30998637]
```
### 과잉 적합 vs 과소 적합
- 과잉 적합(overfitting): 학습 데이터에선 뛰어나지만 새 데이터(일반화)에선 성능이 안 나옴
- 과소 적합(underfitting): 학습 데이터에서도 성능이 나쁨 → 모델 자체가 안 맞는 경우가 많으니 더 나은 모델을 찾아야 함
- 다항 회귀 예 (sklearn 문서): 차수 1 → MSE 4.08e-01(과소), 차수 4 → 4.32e-02(적절), 차수 15 → 1.83e-08(학습 데이터엔 거의 완벽하지만 과잉)
### 당뇨병 데이터 실습
- sklearn 내장, 442개 샘플, 특징 10개(age, sex, bmi, bp, s1~s6)
```python
import numpy as np
from sklearn import datasets, linear_model
from sklearn.model_selection import train_test_split

diabetes_X, diabetes_y = datasets.load_diabetes(return_X_y=True)
diabetes_X_new = diabetes_X[:, np.newaxis, 2]    # 3번째 특징(bmi)만, 2차원 유지
X_train, X_test, y_train, y_test = train_test_split(
    diabetes_X_new, diabetes_y, test_size=0.1, random_state=0)

regr = linear_model.LinearRegression().fit(X_train, y_train)
y_pred = regr.predict(X_test)
```
- `np.newaxis`로 (442,) → (442, 1) 2차원을 만드는 게 포인트
- Open Lab: 아파트 면적 → 가격. 둘 다 실수라서 선형 회귀
