> 심층 신경망(DNN)은 다층 퍼셉트론(MLP)에서 은닉층 개수를 늘려 입력 데이터의 특징을 스스로 추출하는 신경망 구조다. 은닉층이 깊어질수록 그래디언트 소멸 · 과잉 적합 · 계산 시간 과다 문제가 나타난다. 이를 다루기 위해 ReLU 활성화 함수와 교차 엔트로피 손실 함수 · 가중치 초기화 기법 · 미니 배치 학습 · 과잉 적합 처리 방법을 함께 사용한다.

### 심층 신경망(DNN)과 딥러닝의 개념
- **학습 목표**
  - **DNN(deep neural networks)** 구조 및 은닉층 역할 이해
  - 새롭게 등장한 여러 활성화 함수 이해
  - 그래디언트 소멸 문제의 원인과 대응 이해
- **DNN과 딥러닝 정의**
  - **DNN** = 다층 퍼셉트론(MLP)에서 은닉층 개수를 늘린 신경망 (`deep` = 은닉층이 깊다는 뜻)
  - **딥러닝** = DNN에서 사용하는 학습 알고리즘
  - **적용 분야**: 컴퓨터 시각 · 음성 인식 · 자연어 처리 · 소셜 네트워크 필터링 · 기계 번역 등에서 인간 전문가 수준에 필적하는 결과를 냄
- **은닉층의 핵심 역할**
  - 입력 데이터로부터 **특징을 스스로 추출함**
- **2012년 ImageNet과 GPU 기술**
  - **AlexNet(2012)**: Krizhevsky 등이 개발한 딥러닝 시스템 → 기존 기계 학습 기법들을 큰 격차로 제치고 ImageNet 경진대회 우승
  - **GPU(Graphic Processor) 활용**: DNN 학습은 속도가 느리고 계산 집약적이라 시간과 자원이 많이 소모됨 → GPU 기술로 학습 연산 처리
- **은닉층 증가에 따른 문제점**
  - **그래디언트 소멸(gradient vanishing)**: 은닉층 수 증가 → 출력층 그래디언트가 역전파되는 과정에서 값이 점점 작아져 결국 사라짐
  - **과잉 적합(over fitting)**: 훈련 데이터 분류는 잘 수행하나 새로운 데이터 입력 시 분류가 잘되지 않는 현상
  - **계산 시간 과다**: 은닉층이 많아질수록 전체 학습 계산 시간이 과도하게 늘어남

### 그래디언트 소멸 문제와 활성화 함수
- **그래디언트 소멸 (gradient vanishing)**
  - 은닉층 다수 추가 → 손실 함수의 그래디언트가 `0`에 가까워짐 → 학습이 진행되지 않는 현상
- **원인: 시그모이드(sigmoid) 활성화 함수**
  - 함수식: `σ(x) = 1 / (1 + e^(−x))`
  - 도함수: `σ'(x) = σ(x) · (1 − σ(x))`
  - 특성: 아주 큰 양수 또는 아주 큰 음수 입력 → 출력이 포화되어 도함수와 함께 기울기 전달 값이 거의 `0`이 됨 → 역전파 시 그래디언트가 급격히 작아져 학습이 멈춤
- **대안 활성화 함수: ReLU**
  - 그래디언트 소멸 문제를 완화하기 위해 DNN 은닉층 활성화 함수로 **ReLU** 함수를 주로 사용함

### 손실 함수 전환: MSE에서 교차 엔트로피로
- **기존 MSE 손실 함수의 한계**
  - 기존 손실 함수 = 제곱 오차 함수(**MSE: Mean Squared Error**)
  - 이진 분류 문제에서 노드 활성화 함수로 시그모이드(sigmoid) 사용 → MSE가 **저속 수렴 문제(slow convergence)**를 겪음
- **소프트맥스(Softmax) 활성화 함수**
  - 여러 클래스의 점수를 각각의 확률값으로 변환하는 출력층 활성화 함수
  - **변환 단계**:
    - 1단계: 각 클래스 점수에 지수를 취해 양수로 변환함
    - 2단계: 각 지수 값을 전체 클래스 지수 값의 합으로 나눔
  - **성질**: 점수가 높은 클래스에 더 높은 확률 배정 · 전체 클래스 확률 총합 = `1`
  - 출력층 노드에 소프트맥스 함수를 두고 손실 함수로 **교차 엔트로피**를 주로 사용함
- **교차 엔트로피(cross entropy) 손실 함수**
  - 두 확률 분포 `p`와 `q` 사이의 거리를 측정하는 지표
  - **값의 의미**:
    - 교차 엔트로피 값이 큼 → 두 확률 분포의 차이가 큼
    - 교차 엔트로피 값이 작음 → 두 확률 분포가 거의 일치함
  - Softmax와 교차 엔트로피 식 결합 후 미분 결과: `q(x) − p(x)`
- **원-핫 인코딩**
  - 범주형 데이터(카테고리)를 숫자 벡터로 변환하는 표현 방식
  - 카테고리마다 별도 차원을 할당한 뒤 해당 인덱스만 `1`, 나머지 차원은 모두 `0`으로 설정함
- **Lab: 교차 엔트로피 계산 과정**
  - 3개 분류 샘플에 대해 예측 확률과 원-핫 정답으로 개별 오차 계산:
    - 첫 번째 샘플: `−(log(0.1) · 0 + log(0.3) · 0 + log(0.6) · 1) = −(0 + 0 − 0.51) = 0.51`
    - 두 번째 샘플: `−(log(0.2) · 0 + log(0.6) · 1 + log(0.2) · 0) = −(0 − 0.51 + 0) = 0.51`
    - 세 번째 샘플: `−(log(0.3) · 1 + log(0.4) · 0 + log(0.3) · 0) = −(−1.2 + 0 + 0) = 1.20`
  - 3개 샘플 평균 교차 엔트로피 오류: `(0.51 + 0.51 + 1.20) / 3 = 0.74`
- **문제 유형별 손실 함수 선택**
| 손실 함수 | 적용 문제 | 특징 |
|---|---|---|
| BinaryCrossentropy (BCE) | 이진 분류 | 분류 부류가 두 가지뿐일 때 사용 (예: `'강아지'` / `'아님'`) |
| Crossentropy | 다중 분류 | 분류 부류가 셋 이상일 때 사용 · 정답 레이블은 원-핫 인코딩으로 제공 |
| MeanSquaredError | 회귀 | 예측값과 실제값 사이의 평균 제곱 오차 계산에 사용하는 클래스 |

### 가중치 초기화 문제와 초기화 방법
- **0으로 초기화할 때의 문제**
  - 출력층 오차는 연결된 가중치 값이 곱해져(가중치 값에 비례해) 역전파됨
  - 모든 가중치가 `0` → 역전파가 정상적으로 이루어지지 않음
- **동일한 값으로 초기화할 때의 문제 (대칭성)**
  - 예: 가중치 `w1`~`w4`와 `w5`~`w8`을 모두 같은 값(`0.2`)으로 설정 → 노드 `E`와 노드 `G`가 완전히 동일한 일을 수행함
  - 이를 막기 위해 **균형 깨뜨리기(breaking the symmetry)**가 필요함
- **작은 난수 초기화와 그래디언트 폭발**
  - 역전파 정상 동작과 대칭성 해소를 위해 가중치 초기값은 **작은 난수**로 설정해야 함
  - 가중치 초기값이 지나치게 큼 → **그래디언트 폭발(exploding gradients)** 발생 → 학습이 수렴하지 않고 발산함
- **단순 무작위 초기화의 한계**
  - 균등 분포: 선택된 범위 설정에 민감함
  - 정규 분포: 편차 설정에 민감함
- **Xavier (Glorot) 가중치 초기화**
  - 입력과 출력층의 분산을 유지하기 위해 **입력 노드 수와 출력 노드 수**를 함께 반영해 초기화 수행
  - **Sigmoid / Tanh** 활성화 함수에 사용함
- **(Kaimin) He 가중치 초기화**
  - **입력 노드 수**를 반영해 초기화 수행
  - **ReLU** 활성화 함수와 함께 사용함
  - ReLU가 음수를 `0`으로 매핑하므로 더 큰 분산을 갖도록 설정하는 편이 유리함

### 미니 배치 · 데이터 전처리 · 학습 하이퍼파라미터
- **경사 하강법 학습 단위 비교**
  - **확률적 경사 하강법 (SGD: Stochastic Gradient Descent)** = 샘플 `1`개가 주어질 때마다 오차를 계산해 가중치를 즉시 변경하는 온라인 학습 방식
  - **배치 학습 (batch learning)** = 전체 샘플을 모두 제시한 뒤 개별 샘플 그래디언트를 전부 합산해 가중치를 한 번에 변경하는 방식
  - **미니 배치 (mini batch)** = 온라인 학습과 배치 학습의 중간 방식으로 훈련 데이터를 작은 배치로 분할해 배치 `1`개가 끝날 때마다 학습을 수행함
    - 배치 크기 조건: `1 < size(미니 배치) < size(훈련 데이터)`
- **데이터 정규화와 인코딩**
  - **데이터 정규화**: 신경망 입력값은 `[0, 1]` 범위 안의 값이어야 함
  - **데이터 인코딩 변환 예시**: 4개 샘플(`[0]`~`[3]`)의 수치 · 범주형 입력 변환 결과
    - 1번째 수치 열(`30 · 36 · 52 · 42`) → `-1.23 · -0.49 · 1.48 · 0.25`로 변환
    - 2번째 범주 열(`male · female`) → `-1.0 · 1.0`으로 변환
    - 3번째 수치 열(`3800 · 4200 · 4000 · 4400`) → `-1.34 · 0.45 · -0.45 · 1.34`로 변환
    - 4번째 범주 열(`SUV · SEDAN`) → `(1.0, 0.0)` · `(0.0, 1.0)`으로 변환
| 인덱스 | 원본 속성 1 | 원본 속성 2 | 원본 속성 3 | 원본 속성 4 | 변환 값 1 | 변환 값 2 | 변환 값 3 | 변환 값 4 |
|---|---|---|---|---|---|---|---|---|
| 0 | 30 | male | 3800 | SUV | -1.23 | -1.0 | -1.34 | (1.0, 0.0) |
| 1 | 36 | female | 4200 | SEDAN | -0.49 | 1.0 | 0.45 | (0.0, 1.0) |
| 2 | 52 | male | 4000 | SUV | 1.48 | -1.0 | -0.45 | (1.0, 0.0) |
| 3 | 42 | female | 4400 | SEDAN | 0.25 | 1.0 | 1.34 | (0.0, 1.0) |
- **학습률과 모멘텀**
  - **학습률** = 한 번의 갱신에서 가중치를 얼마나 변경할지 결정하는 값
    - 학습률을 너무 크게 설정 → **오버슈팅** 발생
  - **모멘텀(momentum)** = 학습 속도를 가속시킬 목적으로 사용하는 기법

### 과잉 적합(over fitting)과 처리 방법
- **과잉 적합 (over fitting)**
  - 학습 데이터에 지나치게 특화되어 실제 적용 시 좋지 못한 결과가 나오는 현상
- **과잉 적합 탐지**
  - 훈련 중 신경망이 보지 못한 **검증 데이터셋**으로 검증함
  - 훈련이 이어져도 검증 데이터의 손실값이 감소하지 않으면 과잉 적합이 발생한 것으로 판단함
- **과잉 적합 처리 방법**
  - **조기 종료 (Early Stopping)**: 검증 손실이 더 이상 감소하지 않거나 증가하는 경향을 보이면 훈련을 조기에 중단함
  - **가중치 규제**: 복잡한 모델에서 가중치 값이 너무 커지면 판단 경계선이 복잡해져 과잉 적합 발생 → 가중치 절대값을 제한해 작은 값을 유지하도록 신경망 복잡도에 제약을 가함
  - **데이터 증강**: 소량의 훈련 데이터로부터 많은 훈련 데이터를 생성해 데이터를 늘리는 방식
  - **드롭 아웃**: 학습 과정에서 일부 노드(뉴런)를 랜덤하게 제외해 쉬게 하는 방식
    - **앙상블 효과**: 노드를 무작위로 쉬게 하며 학습 → 동일한 특징을 검출하는 전문가가 다수 형성됨

### 핵심 요약
- **DNN과 딥러닝**: DNN은 MLP에서 은닉층 개수를 늘린 구조, 딥러닝은 DNN에서 사용하는 학습 알고리즘임
- **그래디언트 소멸과 ReLU**: 은닉층 증가 → 손실 함수 그래디언트가 `0`에 가까워져 학습이 되지 않음 → 해결을 위해 활성화 함수로 ReLU를 주로 사용함
- **교차 엔트로피**: 두 확률 분포 사이의 거리를 측정하는 지표로 손실 함수로 많이 사용함
- **가중치 초기화**: 대칭성 해소와 안정적 역전파를 위해 가중치 초기값은 작은 난수로 결정해야 함
