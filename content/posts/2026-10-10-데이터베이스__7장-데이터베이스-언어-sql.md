> SQL = 관계 DB 표준 비절차적 언어. DDL(CREATE/ALTER/DROP), DML(SELECT/INSERT/UPDATE/DELETE), 뷰, 프로그램 안에 넣는 삽입 SQL까지.
### SQL 소개
- 관계 DB를 위한 표준 질의어, 비절차적(무엇을 원하는지만 기술)
- SEQUEL(Structured English QUEry Language, "영어 문장처럼 쉽게 질의하자")에서 출발 → 연구용 RDBMS **System R**의 언어 → 상표권 문제로 SQL로 개명 → 기능이 계속 발전해 표준 언어가 됨
- 사용 방식: 대화식 SQL(DBMS에 직접 입력·실행) / 삽입 SQL(C#, C++, Java 프로그램 안에 넣어 사용)
- 이름에 Query가 있지만 조회만 하는 게 아니라 정의·조작·제어를 모두 포함
- ANSI·ISO가 표준을 정하지만, DBMS마다 자체 확장이 있어 문법이 조금씩 다름
| 분류 | 명령 |
|---|---|
| DDL | CREATE TABLE, ALTER TABLE, DROP TABLE, CREATE VIEW, DROP VIEW |
| DML | SELECT, INSERT, UPDATE, DELETE |
| DCL | 권한 부여·취소, 트랜잭션 제어 (11장) |
### CREATE TABLE
- 속성: 데이터 타입 + `NOT NULL`(널 불허) + `DEFAULT`(기본값, 예: `적립금 INT DEFAULT 0`)
- 문자열·날짜는 작은따옴표. 따옴표 안의 문자열은 대소문자 구분
| 타입 | 의미 |
|---|---|
| INT / INTEGER, SMALLINT | 정수 |
| CHAR(n) | 길이 n 고정 길이 문자열 |
| VARCHAR(n) | 최대 n 가변 길이 문자열 |
| NUMERIC(p, s) / DECIMAL(p, s) | 고정 소수점 (p 전체 자릿수, s 소수점 이하) |
| FLOAT(n), REAL | 부동 소수점 |
| DATETIME / DATE | 날짜 |
| TIME | 시간 |
- 키
  - `PRIMARY KEY` = UNIQUE + NOT NULL. 단순 `PRIMARY KEY(고객아이디)`, 복합 `PRIMARY KEY(주문고객, 주문제품)`
  - `UNIQUE`: 대체키. 유일해야 하지만 **널은 허용**
  - `FOREIGN KEY(소속부서) REFERENCES 부서(부서번호)`
- `CHECK`: 값 범위 제약. `CONSTRAINT 이름`으로 이름 부여 가능
- 참조되는 투플을 삭제·수정할 때 옵션 (`ON DELETE` / `ON UPDATE`)
| 옵션 | 동작 |
|---|---|
| NO ACTION | 삭제 거부 |
| CASCADE | 참조하는 투플도 같이 삭제 |
| SET NULL | 참조하는 속성을 NULL로 |
| SET DEFAULT | 참조하는 속성을 기본값으로 |
```sql
CREATE TABLE 고객 (
  고객아이디 VARCHAR(20) NOT NULL,
  고객이름   VARCHAR(10) NOT NULL,
  나이       INT,
  등급       VARCHAR(10) NOT NULL,
  직업       VARCHAR(20),
  적립금     INT DEFAULT 0,
  PRIMARY KEY (고객아이디)
);

CREATE TABLE 제품 (
  제품번호 CHAR(3) NOT NULL,
  제품명   VARCHAR(20),
  재고량   INT,
  단가     INT,
  제조업체 VARCHAR(20),
  PRIMARY KEY (제품번호),
  CHECK (재고량 >= 0 AND 재고량 <= 10000)
);

CREATE TABLE 주문 (
  주문번호 CHAR(3) NOT NULL,
  주문고객 VARCHAR(20),
  주문제품 CHAR(3),
  수량     INT,
  배송지   VARCHAR(30),
  주문일자 DATETIME,          -- Oracle에서는 DATE
  PRIMARY KEY (주문번호),
  FOREIGN KEY (주문고객) REFERENCES 고객(고객아이디),
  FOREIGN KEY (주문제품) REFERENCES 제품(제품번호)
);
```
- 기본키는 NOT NULL을 생략해도 자동 적용되지만, 명시해 두는 편이 읽기 좋음
### ALTER TABLE / DROP TABLE
```sql
ALTER TABLE 고객 ADD 가입날짜 DATETIME;                    -- 속성 추가
ALTER TABLE 고객 DROP 등급 CASCADE;                        -- 관련 제약·참조 속성까지 삭제
ALTER TABLE 고객 ADD CONSTRAINT CHK_AGE CHECK (나이 >= 20); -- 제약조건 추가
ALTER TABLE 고객 DROP CONSTRAINT CHK_AGE;                  -- 제약조건 삭제
DROP TABLE 고객 RESTRICT;                                  -- 참조하는 테이블이 있으면 거부
```
- `CASCADE`: 관련된 것까지 같이 삭제 / `RESTRICT`: 관련된 게 있으면 거부
### SELECT 기본
```sql
SELECT [ALL | DISTINCT] 속성_리스트
FROM 테이블_리스트
[WHERE 조건]
[GROUP BY 속성_리스트 [HAVING 조건]]
[ORDER BY 속성_리스트 [ASC | DESC]];
```
- `ALL`(기본, 중복 허용) / `DISTINCT`(중복 제거), `*`은 모든 속성
- 조건: 비교 연산자 `= <> < > <= >=`, 논리 연산자 `AND OR NOT`
```sql
SELECT 제품명, 재고량, 단가 FROM 제품 WHERE 제조업체 = '한빛제과';
SELECT 주문제품, 수량, 주문일자 FROM 주문 WHERE 주문고객 = 'apple' AND 수량 >= 15;
SELECT 주문제품, 수량, 주문일자, 주문고객 FROM 주문 WHERE 주문고객 = 'apple' OR 수량 >= 15;
```
### LIKE, NULL, 정렬
- `%` = 0개 이상 임의 문자열, `_` = 임의 문자 1개
| 패턴 | 의미 |
|---|---|
| '데이터%' | '데이터'로 시작 |
| '%데이터' | '데이터'로 끝남 |
| '%데이터%' | '데이터' 포함 |
| '데이터___' | '데이터'로 시작하는 6글자 |
| '__한%' | 세 번째 글자가 '한' |
```sql
SELECT 고객이름, 나이, 등급, 적립금 FROM 고객 WHERE 고객이름 LIKE '김%';
SELECT 고객아이디, 고객이름, 등급 FROM 고객 WHERE 고객아이디 LIKE '_____';  -- 5글자
```
- 널은 `IS NULL` / `IS NOT NULL`로만 비교. `= NULL` 같은 비교는 결과가 항상 거짓
```sql
SELECT 고객이름 FROM 고객 WHERE 나이 IS NULL;      -- 오형준
```
- `ORDER BY`: 기본 ASC. 널은 오름차순에선 맨 뒤, 내림차순에선 맨 앞 (예시 DBMS 기준). 여러 기준은 차례로 나열
```sql
SELECT 고객이름, 등급, 나이 FROM 고객 ORDER BY 나이 DESC;
SELECT 주문고객, 주문제품, 수량, 주문일자 FROM 주문
WHERE 수량 >= 10 ORDER BY 주문제품 ASC, 수량 DESC;
```
### 집계 함수와 그룹
| 함수 | 의미 | 대상 |
|---|---|---|
| COUNT | 개수 | 모든 타입 |
| MAX / MIN | 최댓값 / 최솟값 | 모든 타입 |
| SUM / AVG | 합계 / 평균 | 숫자 |
- 집계 함수는 WHERE 절에 쓸 수 없음 (그룹 조건은 HAVING)
- 널은 빼고 계산
```sql
SELECT AVG(단가) FROM 제품;                                          -- 2764
SELECT SUM(재고량) AS 재고량합계 FROM 제품 WHERE 제조업체 = '한빛제과'; -- 6500
SELECT COUNT(고객아이디) FROM 고객;  -- 7
SELECT COUNT(나이) FROM 고객;        -- 6 (나이가 NULL인 오형준 제외)
SELECT COUNT(*) FROM 고객;           -- 7 (투플 수를 정확히 셀 땐 *)
```
```sql
-- 그룹별 집계 + 그룹 조건
SELECT 주문제품, SUM(수량) AS 총주문수량
FROM 주문
GROUP BY 주문제품
HAVING SUM(수량) >= 10;
```
### 조인 검색
- FROM에 테이블을 나열하고 WHERE에 조인 조건. 이름이 겹치면 `테이블.속성`, 길면 `AS` 별명
```sql
SELECT 제품.제품명
FROM 제품, 주문
WHERE 주문.주문고객 = 'banana' AND 제품.제품번호 = 주문.주문제품;

SELECT o.주문제품, o.주문일자
FROM 고객 AS c, 주문 AS o
WHERE c.나이 >= 30 AND c.고객아이디 = o.주문고객;

SELECT 제품.제품명                          -- 3개 테이블
FROM 고객, 제품, 주문
WHERE 고객.고객이름 = '고명석'
  AND 고객.고객아이디 = 주문.주문고객
  AND 제품.제품번호 = 주문.주문제품;
```
### 부속 질의문
- SELECT 안의 SELECT. 단일 행이면 `=` 같은 비교 연산자, 다중 행이면 아래 연산자
| 연산자 | 참이 되는 경우 |
|---|---|
| IN / NOT IN | 결과 중 일치하는 값이 있음 / 없음 |
| EXISTS / NOT EXISTS | 결과가 하나라도 있음 / 하나도 없음 |
| ALL | 결과 전부와 비교해 참 (비교 연산자와 함께) |
| ANY, SOME | 결과 중 하나라도 비교해 참 |
```sql
SELECT 제품명, 단가 FROM 제품
WHERE 제조업체 = (SELECT 제조업체 FROM 제품 WHERE 제품명 = '달콤비스켓');

SELECT 고객이름, 적립금 FROM 고객
WHERE 적립금 = (SELECT MAX(적립금) FROM 고객);
```
### INSERT / UPDATE / DELETE
```sql
INSERT INTO 고객(고객아이디, 고객이름, 나이, 등급, 직업, 적립금)
VALUES ('strawberry', '최유경', 30, 'vip', '공무원', 100);

UPDATE 주문 SET 수량 = 5
WHERE 주문고객 IN (SELECT 고객아이디 FROM 고객 WHERE 고객이름 = '정소화');

DELETE FROM 주문 WHERE 주문일자 = '2013-05-22';
DELETE FROM 주문;   -- WHERE 생략 시 모든 투플 삭제 (테이블은 남음)
```
- UPDATE도 WHERE를 빼면 전체 투플이 수정됨
### 뷰
- 기본 테이블에서 유도한 **가상 테이블**. 데이터가 아니라 정의(질의문)만 저장
```sql
CREATE VIEW 우수고객(고객아이디, 고객이름, 나이)
AS SELECT 고객아이디, 고객이름, 나이
   FROM 고객
   WHERE 등급 = 'vip'
WITH CHECK OPTION;

DROP VIEW 우수고객 RESTRICT;   -- 이 뷰를 쓰는 다른 뷰가 있으면 거부
```
- 정의 안에서 `ORDER BY` 사용 불가
- `WITH CHECK OPTION`: 뷰 조건을 벗어나는 삽입·수정 거부 (vip가 아닌 고객을 우수고객 뷰로 넣을 수 없음)
- 뷰에 대한 INSERT/UPDATE/DELETE는 실제로 기본 테이블에 반영됨
  - 기본키를 포함하지 않는 뷰(제품2)에 삽입하면 기본키가 NULL이 되어 실패
- 장점: 복잡한 조인·집계를 숨겨 질의가 쉬워짐, 뷰 단위 권한으로 보안, 관련 없는 변경을 신경 쓸 필요 없음
- 뷰를 삭제해도 기본 테이블은 영향 없음
### 삽입 SQL (Embedded SQL)
- 호스트 언어 프로그램 안에 넣는 SQL. 일반 명령문이 올 수 있는 곳이면 어디든 가능
- 앞에 `EXEC SQL`을 붙여 구분, 프로그램 변수는 `:변수`로 사용
- 결과가 한 행이면 커서 없이 `SELECT ... INTO :변수` (문자열 변수는 널 문자 때문에 속성 크기 + 1바이트)
- 결과가 여러 행이면 **커서**(결과 행을 하나씩 가리키는 포인터) 사용
```c
EXEC SQL DECLARE product_cursor CURSOR FOR
    SELECT 제품명, 단가 FROM 제품;      /* 1. 선언 */
EXEC SQL OPEN product_cursor;           /* 2. 질의 실행 */
for (;;) {
    EXEC SQL FETCH product_cursor INTO :p_name, :price;  /* 3. 한 행씩 */
    if (sqlca.sqlcode != 0) break;
    printf("%s %d\n", p_name, price);
}
EXEC SQL CLOSE product_cursor;          /* 4. 종료 */
```
