### 클래스와 소스 파일 이름
→ 자바에서 소스 파일 이름은 항상 public이 붙은 클래스의 이름과 동일해야 한다.(public이 없는 경우 실행자가 파일을 실행할 수 없다.)
<callout>
💡자바에서는 소스 파일 이름과 클래스 이름이 상당한 관련이 있다. 일단 하나의 소스 파일 안에는 하나의 클래스만이 있는 것이 바람직하지만 하나의 소스 파일 안에 여러 개의 클래스가 들어 있을 수 있다.<br><br>- 소스 안에 public 클래스가 하나 있다면 반드시 소스 파일의 이름은 public 클래스의 이름과 일치해야 한다. 다른 클래스는 public 클래스가 아니어야 한다.<br>- 만약 하나의 소스 파일 안에 public 클래스가 없다면, 소스 파일 안에 포함된 어떤 클래스의 이름으로 하여도 상관없다.<br>- 하나의 소스 파일 안에 public 클래스가 2개 이상 있다면 컴파일 오류가 발생한다.
</callout>

## 변수와 자료형

### 변수
- 데이터를 담아두는 상자.
<callout>
- 알파벳 문자와 숫자, 밑줄 문자(_)로 이루어진다. 한글 이름도 가능하다.<br>- 첫 번째 문제는 반드시 알파벳 또는 밑줄 문자(_)로 시작해야 한다. 숫자로 시작할 수 없다.<br>- ‘%’, ‘&’, ‘#’와 같은 특수 문자는 사용할 수 없다. 단 ‘\$’와 ‘_’는 가능하다.<br>- 대문자와 소문자를 구별하여 서로 다른 것으로 취급한다. 따라서 index, Index, INDEX는 모두 서로 다른 변수이다.<br>자바 언어 키워드(if, while, true, false, null, …) 와 같은 이름은 허용되니 않는다.
</callout>

### 자료형
- 변수에 저장되는 데이터의 타입.

### 기본 자료형 vs 참조 자료형
<columns>
<column>
### 기본 자료형 (Primitive Data Types)
- 단순한 값을 저장하는 데이터 타입
- 변수에 실제 값이 직접 저장됨
- 종류: boolean, byte, char, short, int, long, float, double
- 스택(Stack) 메모리에 저장됨
- null 값을 가질 수 없음
</column>
<column>
### 참조 자료형 (Reference Data Types)
- 객체의 주소를 저장하는 데이터 타입
- 변수에는 객체의 메모리 주소(참조)가 저장됨
- 종류: 클래스, 인터페이스, 배열 등
- 힙(Heap) 메모리에 객체가 저장됨
- null 값을 가질 수 있음
</column>
</columns>
<callout>
💡 기본 자료형은 메모리에 값 자체가 저장되지만, 참조 자료형은 객체의 주소값이 저장됩니다. 따라서 참조 자료형 변수를 다른 변수에 할당하면 같은 객체를 가리키게 됩니다.
</callout>

### 조건 연산자
