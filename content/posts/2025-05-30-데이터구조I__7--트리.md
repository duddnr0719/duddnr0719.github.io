<column ratio="100"># 트리 ? 
→ 계증적인 구조를 나타내는 자료구조
→ 리스트, 스택, 큐는 선형 구조
→ 부모-자식 관계의 노드들로 이루어짐
### 용어 정리
- 노드 : 트리의 구성 요소
- 루트 : 부모가 없는 노드
- 서브트리 : 하나의 노드와 그 노드들의 자손들로 이루어진 트리
- 단말노드 : 자식이 없는 노드
- 비단말노드 : 적어도 하나의 자식을 가지는 노드
- 레벨 : 트리 각층의 번호
- 높이 : 트리의 최대 레벨
- 차수 : 노드가 가지고 있는 자식 노드의 개수</column>

## 이진 트리의 순회
- 순회 (traversal) : 트리의 노드들을 체계적으로 방문하는 것
<columns>
<column ratio="100">### 전위순회 (preorder traversal) → VLR
: 자손노드보다 루트노드를 번저 방문한다.
1. 루트 노드를 방문한다.
1. 왼쪽 서브트리를 방문한다.
1. 오른쪽 서브트리를 방문한다.
### 중위순회 (inorder traversal) → LVR
: 왼쪽 자손, 루트, 오른쪽 자손 순으로 방문한다.
1. 왼쪽 서브트리를 방문한다.
1. 루트 노드를 방문한다.
1. 오른쪽 서브트리를 방문한다.
### 후위순회 (postorder traversal) → LRV
: 루트노드보다 자손을 먼저 방문한다.
1. 왼쪽 서브트리를 방문한다.
1. 오른쪽 서브트리를 방문한다.
1. 루트 노드를 방문한다.</column>
<column ratio="100">![](/images/ef09d1271d15d04c.png)</column>
</columns>

## 스레드 이진 트리
<columns>
<column ratio="100">: 이진 트리의 NULL 링크를 이용하여 순환 호출 없이도 트리의 노드들을 순회
→ NULL 링크에 중위 순휘 시에 후속 노드인 중위 후속자(inorder successor)를 저장시켜 놓은 트리
→ 단말 노드의 오른쪽 자식 노드를 중위 후속자(부모 노드)를 가리키게 한다.
→ 스레드는 미리 정해둔다.(메인에서)
```
typedef struct TreeNode {
	int data;
	struct TreeNde *left, *right;
	int is_thread; // 단말노드와 비단말노드의 구별을 위한 변수
	// 오른쪽 링크가 스레드이면 TRUE(1)
} TreeNode;
```</column>
<column ratio="100">![](/images/c3f1bfc09fdd148e.png)</column>
</columns>
### 스레드 이진 트리의 구현
```
TreeNode *find_successor(TreeNode *p) {
	TreeNode *q = p->right; // q는 p의 오른쪽 포인터
	if (q == NULL || p->is_thread == TRUE) return q; // 만약 오른쪽 포인터가 NULL이거나 스레드이면 오른쪽 포인터를 반환
	while(q->left != NULL) q = q->left; // 만약 오른쪽 자식이면 다시 가장 왼쪽 노드로 이동
	return q;
}
// 스레드 이진 트리 중위 순회 함수
void thread_inorder(TreeNode *t) {
	TreeNode *q;
	q = t;
	while (q->left) q = q->left; // 가장 왼쪽 노드로 이동
	do {
		printf("%c->", q->data); // 데이터값 출력 
		q = find_successor(q); // 후속자 함수 호출 
	}while(q); // NULL이 아닌 경우
```

## 이진 탐색 트리
<columns>
<column ratio="100">: 탐색 작업을 효율적으로 하기 위한 자료구조
→ key(왼쪽 서브 트리) ≤ key(루트 노드) ≤ key(오른쪽 서브 트리)
→ 이진 탐색을 중위 순회하면 오름차순으로 정렬된 값을 얻을 수 있다.</column>
<column ratio="100">![](/images/fa4906a091eaed8c.png)</column>
</columns>
<columns>
<column ratio="100">### 이진 탐색 트리에서의 탐색 연산
- 비교한 결과가 같으면 탐색이 성공적으로 끝난다.
- 비교한 결과가, 주어진 키 값이 루트 노드의 키 값보다 작으면 탐색은 이 루트 노드의 왼쪽 자식을 기준으로 다시 시작한다.
- 비교한 결과가, 주어진 키 값이 루트 노드의 키 값보다 크면 탐색은 이 루트 노드의 오른쪽 자식을 기준으로 다시 시작한다.
```
search(root, key):
	if root == NULL
		then return NULL;
	if key == KEY(root)
		then return root;
		else if key < KEY(root)
			then return search(LEFT(root), key);
			else return search(RIGHT(root), key);
// key -> 찾고자 하는 값, KEY -> 노드의 데이터를 가져오는 함수
```</column>
<column ratio="100">![](/images/2b5c1c5951294c1c.png)</column>
</columns>

TreeNode *search(TreeNode *node, int key) {

		else if (key < node->key) node = node->left;

	}

}
```</column>

<column ratio="100">## 이진 탐색 트리에서의 삽입 연산
: 이진 탐색 트리에 원소를 삽입하기 위해서는 먼저 탐색을 수행하는 것이 필요 (정렬되어 있는 트리이기 때문)
→ 탐색에 실패한 위치가 바로 새로운 노드를 삽입하는 위치
```
insert(root, n):
	if KEY(n) == KEY(root) then return; // root와 키가 같으면
	else if KEY(n) < KEY(root) // root보다 키가 작으면
		then if LEFT(root) == NULL // root의 왼쪽 자식
			then LEFT(root) <- n; // NULL인 경우 n이 왼쪽 자식
			else insert(LEFT(root), n); // 있으면 순환 호출(왼쪽으로)
	else
		if RIGHT(root) == NULL
			then RIGHT(root)<-n;
			else insert(RIGHT(root), n);
```</column>

<column ratio="100">```
// 오른쪽 서브 트리에서 제일 작은 값을 찾는 함수
TreeNode *min_value_node(TreeNode *node) {
	TreeNode *current = node;
	
	// 맨 왼쪽 단말 노드를 찾으러 내려감
	while (current->left != NULL) current = current->left;
	return current;
}

// 왼쪽 서브 트리에서 제일 작은 값을 찾는 함수
TreeNode *max_value_node(TreeNode *node) {
	TreeNode *current = node;
	
	// 맨 오른쪽 단말 노드를 찾으러 내려감
	while (current->right != NULL) current = current->right;
	return current;
}
```
```
// 이진 탐색 트르와 키가 주어지면 키가 저장된 노드를 삭제하고 새로운 루트 노드를 반환한다.
TreeNode *delete_node(TreeNode *root, int key) {
		if (root == NULL) return root;
		
		// 키가 루트보다 작은 경우 -> 왼쪽 서브 트리에 있는 것
		if (key < root->key) root->left = delete_node(root->left,key); 
		// 키가 루트보다 큰 경우 -> 오른쪽 서브 트리에 있는 것
		else if (key > root->key) root->right = delete_node(root->right, key);
		// 키가 루트와 같은 경우 -> 해당 노드를 삭제
		else {
			// 첫 번째나 두 번째 경우
			if (root->left == NULL) {
				TreeNode *temp = root->right;
				free(root);
				return temp;
			}
			else if (root->right == NULL) {
				TreeNode *temp = root->left;
				free(root);
				return temp;
			}
			// 세 번째 경우
			TreeNode *temp = min_value_node(root->right);
			
			root->key = temp->key; // 중위 순회 시 후계 노드를 복사한다.
			root->right = delete_node(root->right, temp->key); // 중위 순회 시 후계 노드를 삭제한다.
															// max_value_node 함수를 사용할 경우 root->left로 변경해야 함.
		}
		return root;
	}
