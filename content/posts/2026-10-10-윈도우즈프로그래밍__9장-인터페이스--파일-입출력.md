> 인터페이스 = 구현을 강제하는 규약. 클래스는 하나만 상속하지만 인터페이스는 여러 개 구현할 수 있고, 각 인터페이스 타입으로 다형성이 된다. StreamWriter/StreamReader는 IDisposable이라 using으로 감싸 쓴다.
### 인터페이스 만들고 구현하기
- 실수로 규칙을 빼먹지 않도록 **강제**하는 수단. 이름은 `I` + 대문자로 시작하는 관례
- 안에 넣을 수 있는 것: **인스턴스 메서드, 속성**(이벤트, 인덱서)의 선언. 필드(변수)는 불가
```csharp
interface IBasic
{
    int TestInstanceMethod();          // 본문 없이 선언만
    int TestProperty { get; set; }
}

class TestClass : IBasic
{
    // 클래스 이름 옆 IBasic에서 Ctrl + . → [인터페이스 구현]으로 자동 생성
    public int TestInstanceMethod()
    {
        throw new NotImplementedException();   // 나중에 채울 자리
    }
    public int TestProperty
    {
        get => throw new NotImplementedException();
        set => throw new NotImplementedException();
    }
}
```
- 구현한 클래스는 인터페이스 타입으로 다룰 수 있음 (다형성): `IBasic basic = new TestClass();`
- 교재 규칙은 "인터페이스 메서드는 본문을 가질 수 없다"지만, **C# 8.0부터는 기본 구현(default interface method)** 이 허용됨
```csharp
interface IExample
{
    void Method1();
    void Method2() { Console.WriteLine("Method2"); }   // C# 8+ 에서는 OK (.NET 8로 확인)
}
```
  - 연습문제 "잘못된 부분은?"의 답은 교재 기준 "Method2에 본문이 있음"
### 다중 상속
- C++의 클래스 다중 상속은 부모 멤버 이름이 겹치는 모호함, 복잡한 내부 구조로 인한 성능 문제가 있었음
- C#·Java: 클래스는 **하나만**, 인터페이스는 **여러 개**
```csharp
class Parent { }

class Child : Parent, IDisposable, IComparable     // 클래스는 맨 앞에 하나
{
    public void Dispose() { }
    public int CompareTo(object obj) { return 0; }
}

Child child = new Child();
Parent asParent = new Child();
IDisposable asDisposable = new Child();
IComparable asComparable = new Child();   // 네 가지 타입으로 다룰 수 있음
```
- 두 인터페이스의 메서드 이름이 겹치면 **명시적 구현**: `void IA.Run() { … }`, `void IB.Run() { … }` (해당 인터페이스 타입으로 볼 때만 호출됨)
- 협업할 때 규약을 정해 안정성을 높임. 디자인 패턴 대부분이 인터페이스 기반
| | 클래스 | 인터페이스 |
|---|---|---|
| 키워드 | class | interface |
| 상속 개수 | 하나 | 여러 개 |
| 구현 강제 | 재정의 안 해도 됨 | 선언된 멤버를 반드시 구현 |
| 필드 | 가능 | 불가 |
| 인스턴스 생성 | 가능 | 불가 |
| 다형성 | 가능 | **가능** |
### 파일 한 번에 쓰고 읽기
```csharp
File.WriteAllText(@"c:\test\test.txt", "문자열을 파일에 씁니다.");
Console.WriteLine(File.ReadAllText(@"c:\test\test.txt"));
```
- `@"..."` (축자 문자열): 이스케이프를 처리하지 않음 → 경로의 `\`를 `\\`로 안 써도 됨. 따옴표는 `""`로
- 덧붙이기는 `File.AppendAllText`, 줄 단위는 `File.ReadAllLines`
### 스트림으로 쓰고 읽기
- 큰 파일을 통째로 메모리에 올리면 부담 → 한 줄씩 흘려보내는 **스트림**
- `StreamWriter`, `StreamReader`는 `IDisposable` → `using`이 블록을 벗어날 때 `Dispose()`로 파일을 닫아줌. 중간에 예외가 나도 닫힘(내부적으로 try/finally)
```csharp
using (StreamWriter writer = new StreamWriter(@"c:\test\test.txt"))
{
    writer.WriteLine("안녕하세요.");
    writer.WriteLine("StreamWriter 클래스를 사용해");
    writer.WriteLine("글자를 여러 줄 입력해봅니다.");
    for (int i = 0; i < 10; i++)
        writer.WriteLine("반복문 - " + i);
}

using (StreamReader reader = new StreamReader(@"c:\test\test.txt"))
{
    string line;
    while ((line = reader.ReadLine()) != null)   // 끝에 도달하면 null
        Console.WriteLine(line);
}
```
- 연습문제(이전 입력 보여주고 새 입력 추가하기) 예시 풀이
```csharp
string path = "memo.txt";
if (File.Exists(path) && File.ReadAllText(path).Length > 0)
    Console.WriteLine("이전에 입력한 내용: " + string.Join(", ", File.ReadAllLines(path)));
else
    Console.WriteLine("파일에 아무 내용도 없습니다.");

Console.Write("저장할 문자열을 입력해주세요: ");
File.AppendAllText(path, Console.ReadLine() + Environment.NewLine);
Console.WriteLine("저장했습니다.");
```
### 윈도 폼 컨트롤
| 이름 | 클래스 | 주요 속성 |
|---|---|---|
| 레이블 | Label | Text |
| 링크 레이블 | LinkLabel | 밑줄·파란 글자, Click |
| 체크 박스 | CheckBox | Checked (여러 개 선택) |
| 라디오 버튼 | RadioButton | Checked (그룹에서 하나만) |
| 그룹 박스 | GroupBox | Controls (라디오 그룹 나누기) |
- 코드로 생성 + 객체 이니셜라이저 + 이벤트 연결(`+=`)
```csharp
LinkLabel linkLabel = new LinkLabel()
{
    Text = "글자",
    Location = new Point(10, 50),
    Height = 23
};
linkLabel.Click += LabelClick;
Controls.Add(linkLabel);

private void LabelClick(object? sender, EventArgs e)
{
    // .NET Core/5+ 에서 URL을 열려면 UseShellExecute = true 필요
    System.Diagnostics.Process.Start(new System.Diagnostics.ProcessStartInfo("https://hanbit.co.kr") { UseShellExecute = true });
    // 프로그램 실행: Process.Start("notepad.exe");
}
```
  - 교재처럼 `Process.Start("https://...")`만 쓰면 .NET Framework에선 되지만 .NET 5 이후엔 예외가 남
- 체크된 체크 박스 모으기 (`is`로 타입 확인)
```csharp
private void ButtonClick(object? sender, EventArgs e)
{
    List<string> list = new List<string>();
    foreach (var item in Controls)
    {
        if (item is CheckBox)
        {
            CheckBox checkBox = (CheckBox)item;
            if (checkBox.Checked) list.Add(checkBox.Text);
        }
    }
    MessageBox.Show(string.Join(",", list));   // 감자, 토마토 체크 → "감자,토마토"
}
```
- 라디오 버튼은 **같은 부모 컨트롤 안에서** 하나만 선택됨 → 그룹을 나누려면 GroupBox에 따로 넣기
```csharp
groupBox1.Controls.Add(radioButton1);   // 식물: 감자, 고구마
groupBox1.Controls.Add(radioButton2);
groupBox2.Controls.Add(radioButton3);   // 물고기: 광어, 우럭
groupBox2.Controls.Add(radioButton4);
Controls.Add(groupBox1);
Controls.Add(groupBox2);

// 그룹마다 선택된 것 찾기 (as 사용)
foreach (var outer in Controls)
{
    if (outer is GroupBox)
    {
        foreach (var inner in ((GroupBox)outer).Controls)
        {
            RadioButton rb = inner as RadioButton;
            if (rb != null && rb.Checked) MessageBox.Show(rb.Text);   // "감자", "우럭"
        }
    }
}
```
### 연습문제 포인트
- 인터페이스는 속성·인스턴스 메서드 O, 필드·클래스(static) 메서드 X (교재 기준. C# 11부턴 static abstract 멤버도 가능)
- 인터페이스도 다형성 O
- `@` 문자열은 이스케이프 문자를 쓸 수 없게 됨
- IDisposable과 함께 쓰는 구문은 `using`
