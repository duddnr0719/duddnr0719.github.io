> 텍스트는 형태소 분석으로 명사를 뽑아 빈도를 세고 워드클라우드로 그린다. 장바구니 데이터는 지지도(얼마나 자주) → 신뢰도(X를 샀을 때 Y도 살 확률) → 향상도(우연보다 몇 배인가) 순으로 걸러 연관규칙을 찾고, Apriori는 드문 조합을 미리 잘라 계산을 줄인다.
### 텍스트마이닝
- 자연어 처리(NLP)로 **비정형 텍스트**에서 알려지지 않은 관계·패턴을 찾아 유용한 정보로 만드는 과정 (데이터마이닝과 목적은 같고 대상이 비정형)
| 기법 | 내용 |
|---|---|
| 주제어 분석 | 자주 나오는 단어 = 주제어 (워드클라우드) |
| 동시 출현 단어 분석 | 함께 자주 나오는 단어 쌍 |
| 토픽 모델링 | 대량 문서에서 주제(토픽) 추출 |
| 감성 분석 | 글쓴이의 의견·감정 (오피니언 마이닝) |
- 과정: 데이터 취득(웹, SNS, 블로그) → 전처리(형태소 분석, 정제·변환) → 마이닝(패턴 추출) → 해석·평가
### 워드클라우드
- 단어 출현 빈도를 세어 **자주 나올수록 크게** 그림 (빈도 = 중요도·관심도)
- 흐름: 텍스트 → 형태소 분석·정제 → 단어 목록 → 빈도표(예: 전체 291개 중 국민 11, 오늘 6, 외교 6 …) → 시각화
```r
library(wordcloud)
library(RColorBrewer)
word_text <- read.csv("fruit_vegetable.csv", header = TRUE, encoding = "UTF-8")   # 단어, 빈도 두 열
names(word_text) <- c("title", "count")
wordcloud(words = word_text$title,
          freq = word_text$count,
          min.freq = 1,          # 최소 빈도
          max.words = 105,       # 최대 단어 수
          random.order = FALSE,  # 빈도 높은 단어를 가운데에
          rot.per = 0.1,         # 세로로 돌릴 단어 비율 10%
          scale = c(4, 0.3),     # 글자 크기 범위 (최대, 최소)
          colors = brewer.pal(8, "Dark2"))
```
### 한글 문서 워드클라우드
- 주제어를 뽑으려면 **형태소 분석**(특히 명사 추출)이 필요 → 한글은 `KoNLP` (CRAN에서 내려가 별도 설치 절차 필요)
- 파일 준비: 마지막 문장 뒤에 **줄바꿈**, 인코딩 **UTF-8**, 파일명·경로는 **영문**
```r
library(KoNLP)
text <- readLines("mis_document.txt", encoding = "UTF-8")
buildDictionary(ext_dic = "woorimalsam")          # '우리말씀' 사전
pal2 <- brewer.pal(8, "Dark2")
noun <- sapply(text, extractNoun, USE.NAMES = FALSE)   # 줄마다 명사 추출 → 리스트

noun2 <- unlist(noun)                             # 하나로 합치기
wordcount <- table(noun2)
temp <- sort(wordcount, decreasing = TRUE)[1:10]
# (공백) 42, 등 27, 불법 27, 여성 24, 한 23, 촬영 21, 수사 18, 할 12, 경찰 11, 성범죄 11
temp <- temp[-1]                                  # 공백 제거
barplot(temp, names.arg = names(temp), col = "lightblue", main = "빈도수 높은 단어", ylab = "단어 빈도수")

wordcloud(names(wordcount), freq = wordcount,
          scale = c(6, 0.7), min.freq = 3,        # 3번 이상 나온 단어만
          random.order = FALSE, rot.per = 0.1, colors = pal2)
```
- 다듬기: "등", "한", "할"처럼 의미 없는 단어가 상위권 → 정제 필요
```r
buildDictionary(ext_dic = "woorimalsam",
                user_dic = data.frame("정치", "ncn"),   # 사전에 없는 단어를 명사로 추가
                replace_usr_dic = TRUE)
noun2 <- unlist(sapply(text, extractNoun, USE.NAMES = FALSE))
noun2 <- noun2[nchar(noun2) > 1]     # 한 글자 단어 제거
noun2 <- gsub("하지", "", noun2)      # 불용어 제거
noun2 <- gsub("때문", "", noun2)
wordcount <- table(noun2)
```
  - `gsub`으로 지우면 빈 문자열 `""`이 남아 집계에 끼므로 `noun2 <- noun2[!noun2 %in% c("하지", "때문")]`처럼 걸러내는 편이 깔끔
### 데이터마이닝
- **KDD**(대용량 DB에서의 지식 발견): 대량의 데이터에서 이전에 몰랐던, 잠재적으로 유용한 정보를 찾는 작업. 통계·수학 기법, 신경망 등 패턴 인식 기술 사용
- 분석 유형: **분류**(신규 고객 등급), **예측**(수요, 대출 심사), **연관**(장바구니에 함께 담기는 상품), **군집**(고객 세분화)
| | 목적 | 기법 |
|---|---|---|
| 기술적(descriptive) 모델링 | 데이터를 설명하는 패턴 찾기 | 연관규칙, 군집화, 시각화 |
| 예측(predictive) 모델링 | 모형으로 새 데이터 예측 | 분류, 회귀, 시계열 |
- 목표 변수가 있으면 **지도학습**(회귀, 의사결정나무, 신경망), 없으면 **비지도학습**(연관규칙, k-means)
### 연관규칙 (장바구니 분석)
- 거래 데이터에서 함께 사는 상품 패턴: {맥주} → {땅콩}, {분유} → {기저귀}. 계산대 옆 껌·건전지 진열도 이런 분석의 결과
- 예제 거래 5건: ① 맥주, 땅콩 ② 맥주, 오징어 ③ 맥주, 라면, 땅콩 ④ 초콜릿, 껌 ⑤ 초콜릿, 생수, 껌
| 척도 | 정의 | {맥주} → {땅콩} |
|---|---|---|
| 지지도 support | X와 Y를 함께 산 거래 / 전체 거래 | 2/5 = 0.4 |
| 신뢰도 confidence | X와 Y를 함께 산 거래 / X를 산 거래 = P(Y \| X) | 2/3 ≈ 0.67 |
| 향상도 lift | 신뢰도 / Y의 지지도 = P(Y \| X) / P(Y) | 0.67 / 0.4 = 1.67 |
- {땅콩} → {맥주}의 신뢰도는 2/2 = 1.0: 방향에 따라 신뢰도가 다름 (땅콩을 산 사람은 "반드시" 맥주를 삼)
- 향상도 해석: > 1 양의 관계(X가 Y 구매를 늘림), < 1 음의 관계, ≈ 1 서로 무관(우연)
  - 맥주를 산 사람은 일반 고객보다 땅콩을 살 가능성이 1.67배
- 생성 과정: ① **최소 지지도**로 빈발 아이템 세트 추리기 → ② **최소 신뢰도**로 후보 규칙 → ③ **향상도**로 의미 있는 규칙 선별
### Apriori 알고리즘
- Agrawal & Srikant (1994). 모든 조합을 다 세면 너무 많음 → **어떤 아이템 세트가 드물면, 그걸 포함하는 더 큰 세트도 반드시 드물다** → 1개짜리부터 시작해 최소 지지도를 못 넘는 건 버리고, 살아남은 것끼리만 다음 크기 후보를 만듦
- 예: 거래 101 {A, C, D}, 102 {B, C, E}, 103 {A, B, C, E}, 104 {B, E}, 최소 지지도(건수) 2
  - C1: A 2, B 3, C 3, D 1, E 4 → L1: D 탈락
  - C2: AB 1, AC 2, AE 1, BC 2, BE 3, CE 2 → L2: AC, BC, BE, CE
  - C3: L2로 만들 수 있으면서 **모든 부분집합이 L2에 있는** 것만 → {B, C, E} (ABC는 AB가, ACE는 AE가 탈락이라 계산조차 안 함) → 지지도 2로 통과
- 예: 표지판 색 10건 (Red 6, White 7, Blue 6, Orange 2, Green 2, Yellow 1), 최소 지지도 0.2, 최소 신뢰도 0.7
  - Yellow 탈락 → 2개 세트: {Red, White} 4, {Red, Blue} 4, {Red, Green} 2, {White, Blue} 4, {White, Orange} 2, {White, Green} 2 ({Red, Orange} 1 탈락) → 3개 세트: {Red, White, Blue} 2, {Red, White, Green} 2
  - {Red, White} → {Green}: 2/4 = 0.5 < 0.7 탈락
  - 남은 규칙 5개 (모두 지지도 0.2, 신뢰도 1.0): {Orange} → {White}, {Green} → {Red}, {Green} → {White}, {Red, Green} → {White}, {White, Green} → {Red}
  - {Green} → {Red}의 향상도 = 1.0 / 0.6 = 1.67 → Green을 산 사람이 Red를 살 가능성은 평소의 1.67배
### R 실습: 제과점 거래
- `arules`(Apriori), `arulesViz`(시각화), Kaggle BreadBasket_DMS.csv (Date, Time, Transaction, Item 21,293행)
- 데이터 형식: **basket**(한 줄 = 한 거래의 모든 상품) / **single**(한 줄 = 상품 하나, 거래가 여러 줄) ← 이 데이터
```r
library(arules)
library(arulesViz)
ds <- read.csv("BreadBasket_DMS.csv")
ds.new <- subset(ds, Item != "NONE")                  # 'NONE' 항목 제거
write.csv(ds.new, "BreadBasket_DMS_upd.csv", row.names = FALSE)

trans <- read.transactions("BreadBasket_DMS_upd.csv",
                           format = "single", header = TRUE,
                           cols = c(3, 4),            # 3열 거래ID, 4열 상품명
                           sep = ",", rm.duplicates = TRUE)
trans                       # 9465 transactions, 94 items
inspect(head(trans, 10))    # {Bread}, {Medialuna, Scandinavian}, …

itemFrequencyPlot(trans, topN = 10, type = "absolute")   # Coffee ≫ Bread > Tea > Cake > Pastry …
rules <- apriori(trans, parameter = list(supp = 0.001, conf = 0.7))   # 14개 규칙
rules.sort <- sort(rules, by = "confidence", decreasing = TRUE)
inspect(rules.sort[1:10])
```
| 규칙 | support | confidence | lift | count |
|---|---|---|---|---|
| {Extra Salami or Feta, Salad} → {Coffee} | 0.0015 | 0.88 | 1.83 | 14 |
| {Pastry, Toast} → {Coffee} | 0.0014 | 0.87 | 1.81 | 13 |
| {Hearty & Seasonal, Sandwich} → {Coffee} | 0.0013 | 0.86 | 1.79 | 12 |
| {Salad, Sandwich} → {Coffee} | 0.0016 | 0.83 | 1.74 | 15 |
| {Keeping It Local} → {Coffee} | 0.0054 | 0.81 | 1.69 | 51 |
| {Toast} → {Coffee} | 0.0237 | 0.70 | 1.46 | 224 |
- 14개 규칙의 결과가 **모두 Coffee**: 커피가 워낙 많이 팔려서(전체 거래의 약 48%) 신뢰도가 쉽게 높아짐. 그래서 신뢰도만 보지 말고 향상도로 "우연보다 얼마나 더한가"를 함께 봐야 함
- `coverage` = 조건(X)의 지지도
- 시각화
```r
plot(rules.sort, measure = c("support", "lift"), shading = "confidence")   # 산점도
plot(rules.sort, method = "graph")      # 상품 → 규칙 → 상품 네트워크
plot(rules.sort, method = "grouped")    # LHS 그룹 × RHS 행렬 (원 크기 = 지지도, 색 = 향상도)
write(rules.sort, file = "BreadBasket_rules.csv", sep = ",", quote = TRUE, row.names = FALSE)
```
