# 정적 크롤링과 동적 크롤링의 차이를 알아보자

## 정적 크롤링
→ 정적인 데이터를 수집하는 것.
- 정적인 데이터 ?
→ 변하지 않는 데이터. 한 페이지 안에서 원하는 정보가 모두 드러날 때가 정적 데이터라고 할 수 있다.
ex) 로또 당첨 번호 페이지에 나와있는 로또 당첨 번호 7개
→ 정적 크롤링은 한 페이지 내에서 모든 작업이 이루어지기 때문에 속도가 굉장히 빠름.
💡 대표적인 라이브러리로 beautifulsoup, requests 가 있음.
## 동적 크롤링
→ 동적인 데이터를 수집하는 것.
- 동적인 데이터 ?
→ 입력, 클릭, 로그인 등과 같이 페이지 이동이 있어야 보이는 데이터를 뜻함.
ex) 로그인 과정을 거쳐야 하는 메일함 페이지
→ 정적 크롤링보다 수집하는 속도가 느리지만, 더 많은 정보를 수집할 수 있음.(여러 개의 페이지에서 원하는 정보를 다 가져올 수 있다.)
💡 대표적인 라이브러리로 selenium, chromedriver 가 있음.
