# 인터넷 개요, 네트워크 가장자리와 코어
### 인터넷이란 무엇인가.
- 구성 요소 관점: 호스트(= 종단 시스템, 가장자리에서 응용 실행), 패킷 스위치(라우터·스위치, 패킷 전달), 통신 링크(광섬유·동축·전파·위성, 전송속도=대역폭), 네트워크(장치·라우터·링크 집합, ISP가 관리).
- 프로토콜이 송수신 제어(HTTP, TCP, IP, WIFI, 4G/5G, Ethernet). 표준은 IETF가 RFC로 발행.
- 서비스 관점: 애플리케이션(웹, 스트리밍, 이메일, 게임 등)에 서비스를 인프라이자, 분산 애플리케이션에 프로그래밍 인터페이스 제공(API)
- 프로토콜 정의: 통신 개체 간 교환되는 메시지의 형식과 순서, 그리고 메시지 송수신·이벤트에서 취하는 행동을 정의한 것.

### 네트워크 가장자리
- 호스트 = 클라이언트와 서버. 접속 네트워크는 종단 시스템을 가장자리 라우터에 연결.
- 접속 네트워크 종류: 가정, 기관, 무선
- 물리 매체: 유도 매체와 비유도 매체.
- 무선 종류: WiFI, 4G, Bluetooth, 지상 마이크로파, 위성

### 네트워크 코어
- 코어 = 상호 연결된 라우터들의 mesh. 호스트는 메시지를 패킷으로 나눠 경로 상 라우터를 거쳐 전달.
- 핵심 기능 2가지
- 라우팅: 출발지 → 목적지 경로 결정, 라우팅 알고리즘
- 포워딩: 라우터 입력 → 적절한 출력으로 이동, 스위칭
- 패킷 전송 지연 = L/R
- 저장 후 전달: 패킷 전체가 도착해야 다음 링크로 전송
- 큐잉과 손실: 입력 도착 속도 \> 출력 전송률 일 경우 큐에 쌓이고, 큐가 차면 패킷 손실.

### 회선 교환 vs 패킷 스위칭
- 회선 교환: 세션 동안 자원 예약, 공유 없음, 전송률 보장(전화망). 다중화 방식은 FDM, TDM
- 패킷 스위칭은 버스티 데이터에 적합하고 호 설정이 없지만, 과도한 혼잡 시 지연·손실 발생 → 신뢰 전송·혼잡 제어 프로토콜 필요

### 인터넷 구조: 네트워크의 네트워크
1. 종단 시스템은 접속 ISP를 통해 연결.
2. 모든 접속 ISP를 서로 직접 연결하는 것은 비현실적 → 글로벌 통과 ISP에 연결
3. 글로벌 ISP가 여럿 생겨 경쟁하고, 서로 상호 연결
4. 지역 ISP가 접속 ISP를 묶음. 콘텐츠 제공자 네트워크는 자체망으로 Tier-1·지역 ISP를 우회하기도 함
5. Tier-1 ISP가 국가·국가 간 담당.
- 망 사용료: 트래픽을 더 많이 발생시킨 쪽이 적은 쪽에 지불(Tier3→Tier2→Tier1) 비슷하면 서로 내지 않음
