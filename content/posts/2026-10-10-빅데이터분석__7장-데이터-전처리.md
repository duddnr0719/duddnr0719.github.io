> 분석 시간의 대부분을 먹는 단계. NA는 is.na()로 찾아 na.rm/na.omit/대체로 처리, 이상치는 boxplot.stats()$out으로 찾아 제거, 그다음 order·subset·split·sample·aggregate·merge로 원하는 모양을 만든다.
### 전처리와 자료형 변환
- 수집한 원자료는 단위 차이, 중복, 결측, 오류 때문에 바로 못 씀 → 분석 가능한 형태로 정돈
- "데이터 분석의 80%는 데이터 정제에 쓰이고, 나머지 20%는 그걸 불평하는 데 쓰인다" (Kaggle 창립자 Anthony Goldbloom)
- 확인: `str()`, `class()`, `is.numeric()`, `is.character()` … / 변환: `as.*()` (안 되면 NA + 경고)
| 분류 | 함수 |
|---|---|
| 기본형 | `as.numeric`, `as.integer`, `as.double`, `as.character`, `as.logical`, `as.complex` |
| 구조 | `as.vector`, `as.matrix`, `as.array`, `as.data.frame`, `as.list`, `as.table`, `as.factor`, `as.ordered` |
| 날짜·시간 | `as.Date`, `as.POSIXct`(초 단위), `as.POSIXlt`(리스트형), `as.difftime` |
### 결측값 (NA)
- 값을 얻지 못한 경우 (설문 무응답, airquality의 NA)
- NA가 하나라도 있으면 합계·평균이 NA → **제거하거나**, **추정값으로 대체**
```r
z <- c(1, 2, 3, NA, 5, NA, 8)
sum(z)                 # NA
is.na(z)               # FALSE FALSE FALSE TRUE FALSE TRUE FALSE
sum(is.na(z))          # 2  (NA 개수)
sum(z, na.rm = TRUE)   # 19 (NA 빼고 계산)

z1 <- c(1, 2, 3, NA, 5, NA, 8)
z1[is.na(z1)] <- 0     # NA → 0 으로 대체: 1 2 3 0 5 0 8
z2 <- c(5, 8, 1, NA, 3, NA, 7)
as.vector(na.omit(z2)) # NA 제거: 5 8 1 3 7
```
- 데이터프레임
```r
x <- iris
x[1, 2] <- NA; x[1, 3] <- NA
x[2, 3] <- NA; x[3, 4] <- NA

sum(is.na(x))              # 4
colSums(is.na(x))          # 열별: 0 1 2 1 0
rowSums(is.na(x))          # 행별: 2 1 1 0 0 …
sum(rowSums(is.na(x)) > 0) # NA가 있는 행 수: 3

x[!complete.cases(x), ]    # NA가 있는 행들 (1~3행)
y <- x[complete.cases(x), ]   # NA 없는 행만 → 147행
y2 <- na.omit(x)              # 같은 결과, 더 간단
```
- 열별 개수는 for문이나 `apply(x, 2, function(y) sum(is.na(y)))`로도 (apply: 1 = 행, 2 = 열; 변형으로 sapply, tapply, mapply)
### 특이값 (Outlier)
- 정상 분포 범위 밖의 값 (이상치). 입력 오류일 수도, 진짜 특이한 값일 수도 (일반인 몸무게 속 씨름선수)
- 평균 등을 왜곡하므로 보통 분석에서 제외. 반대로 불량품 선별, 사기 거래 탐지에선 특이값 자체가 목표
- 찾는 법: 논리적으로 불가능한 값(1~5 척도에 7, 음수 몸무게), 상식 밖의 값(나이 120세 이상), 상자그림
```r
st <- data.frame(state.x77)
boxplot(st$Income)
boxplot.stats(st$Income)$out            # 6315 (Alaska)

out.val <- boxplot.stats(st$Income)$out
st$Income[st$Income %in% out.val] <- NA # 이상치 → NA
newdata <- st[complete.cases(st), ]     # NA 행 제거 → Alaska 빠짐
```
### 정렬
```r
v1 <- c(1, 7, 6, 8, 4, 2, 3)
order(v1)                     # 1 6 7 5 3 2 4  ← 작은 값의 "위치" 순서
v1[order(v1)]                 # 1 2 3 4 6 7 8
sort(v1)                      # 1 2 3 4 6 7 8
sort(v1, decreasing = TRUE)   # 8 7 6 4 3 2 1
```
- 데이터프레임은 `sort()` 불가 → **`order()`로 행 순서를 구해 인덱싱**
```r
iris[order(iris$Sepal.Length), ]                     # 오름차순 (14번 행 4.3부터)
iris[order(iris$Sepal.Length, decreasing = TRUE), ]  # 내림차순
iris[order(iris$Species, -iris$Petal.Length), ]      # 기준 2개: 품종 오름차순, 그 안에서 꽃잎 길이 내림차순
```
- plyr(또는 dplyr)의 `arrange()`: `arrange(iris, Sepal.Length)`, `arrange(iris, desc(Sepal.Length))` (열 이름만 써도 됨)
### 분리와 선택
```r
sp <- split(iris, iris$Species)   # 품종별 데이터프레임 3개를 담은 리스트
summary(sp)                       # setosa / versicolor / virginica 각각 data.frame
sp$setosa

subset(iris, Species == "setosa")
subset(iris, Sepal.Length > 7.5)                          # 106 118 119 123 132 136행
subset(iris, Sepal.Length > 5.1 & Sepal.Width > 3.9)      # 15 16 33 34행
subset(iris, Sepal.Length > 7.6, select = c(Petal.Length, Petal.Width))   # 원하는 열만
```
### 샘플링과 조합
- 데이터가 너무 클 때 일부만 뽑아 미리 확인
- **복원추출**(뽑은 걸 다시 넣음, `replace = TRUE`) / **비복원추출**(안 넣음, `replace = FALSE`)
```r
sample(1:100, size = 10, replace = FALSE)

idx <- sample(1:nrow(iris), size = 50, replace = FALSE)
iris.50 <- iris[idx, ]
dim(iris.50)        # 50 5

set.seed(100)       # 난수 시드 고정 → 매번 같은 결과
sample(1:20, size = 5)
```
- 주의: 같은 `set.seed(100)`이라도 **R 버전에 따라 결과가 다름**. 슬라이드의 `7 5 10 1 8`은 R 3.5 이전 방식이고, R 3.6부터 샘플링 알고리즘이 바뀌어 R 4.3에서는 `10 6 16 14 12`가 나옴 (옛 결과를 재현하려면 `RNGkind(sample.kind = "Rounding")`)
- 조합: `combn(1:5, 3)` → 5C3 = 10가지
```r
com <- combn(c("red", "green", "blue", "black", "white"), 2)   # 5C2 = 10가지
for (i in 1:ncol(com)) cat(com[, i], "\n")   # red green / red blue / …
```
### 집계 (aggregate)
- 그룹별 합계·평균 등
```r
aggregate(iris[, -5], by = list(iris$Species), FUN = mean)
#      Group.1 Sepal.Length Sepal.Width Petal.Length Petal.Width
# 1     setosa        5.006       3.428        1.462       0.246
# 2 versicolor        5.936       2.770        4.260       1.326
# 3  virginica        6.588       2.974        5.552       2.026

aggregate(iris[, -5], by = list(표준편차 = iris$Species), FUN = sd)   # 그룹 열 이름 지정
aggregate(mtcars, by = list(cyl = mtcars$cyl, vs = mtcars$vs), FUN = max)   # 기준 2개
```
### 병합 (merge)
- 공통 열을 기준으로 합치기 (DB의 JOIN)
```r
x <- data.frame(name = c("a", "b", "c"), math = c(90, 80, 40))
y <- data.frame(name = c("a", "b", "d"), korean = c(75, 60, 90))

merge(x, y, by = c("name"))   # 내부 조인: a, b만
merge(x, y, all.x = TRUE)     # 왼쪽 외부 조인: a, b, c (c의 korean = NA)
merge(x, y, all.y = TRUE)     # 오른쪽 외부 조인: a, b, d (d의 math = NA)
merge(x, y, all = TRUE)       # 완전 외부 조인: a, b, c, d
```
| 조인 | 옵션 | 결과 |
|---|---|---|
| Inner | `all = FALSE` (기본) | 교집합 |
| Left outer | `all.x = TRUE` | x 전부 |
| Right outer | `all.y = TRUE` | y 전부 |
| Full outer | `all = TRUE` | 합집합 |
- 기준 열 이름이 다르면: `merge(x, y, by.x = "name", by.y = "sname")`
### 범주형 변수
- 성별, 음주 여부처럼 제한된 값만 갖는 변수. 입력 편의상 0/1 숫자로 저장된 경우가 많아 **factor로 바꿔야** 분석에서 범주로 취급
  - 명목 척도: 순서 없음 (성별) / 순서 척도: 순서 있음 (암 병기, 월, 상·중·하)
```r
df <- read.csv("health.csv")      # 1000행 26열, SEX·SMOK 등이 int
df$SEX  <- as.factor(df$SEX)      # Factor w/ 2 levels "0","1"
df$SMOK <- as.factor(df$SMOK)     # Factor w/ 3 levels "0","1","2"
# ALCOHOL, RESID, TWIN, RH, HTN, TRANSPORT도 같은 방식
```
- 순서 지정: `factor(c(1, 2, 3), levels = c(3, 2, 1))` → Levels: 3 2 1
- 예: Orange 데이터의 Tree는 순서형 팩터라 레벨 순서가 `3 1 5 2 4`(둘레 크기순) → 1~5 순서로 그리려면
```r
TreeOrder <- factor(Orange$Tree, levels = levels(Orange$Tree)[c(2, 4, 1, 5, 3)])   # "1" "2" "3" "4" "5"
boxplot(circumference ~ TreeOrder, data = Orange, main = "그룹별 둘레")
```
