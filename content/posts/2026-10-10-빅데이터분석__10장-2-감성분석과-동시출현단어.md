> 사전 기반 감성분석은 토큰화 → 감성 사전과 inner join → 점수 합산. 사전마다 성격이 다르다(NRC 감정 10종, AFINN −5~+5, Bing 긍/부정, SentiWordNet 의미 기반). 동시출현 분석은 단어 쌍이 같은 문맥에 함께 나오는 빈도를 센다.
### 감성분석이란
- 텍스트에서 감정(긍정·부정·중립)을 자동으로 뽑아내는 NLP 분야
- 활용: 상품 리뷰, SNS 여론, 고객 피드백, 금융 시장 심리
- 장점: 자동화, 대량 처리 / 한계: 문맥 이해 부족, **풍자·비꼼**에 약함 → 데이터 품질이 중요, 최신은 딥러닝
| 방법 | 원리 | 특징 |
|---|---|---|
| 사전 기반 (lexicon) | 단어별 감정 점수 사전 | 간단, 문맥 반영 어려움 |
| 머신러닝 | 라벨 데이터로 학습 (Naive Bayes, SVM) | 특징(feature) 추출 필요 |
| 딥러닝 | RNN, LSTM, Transformer | 문맥 이해 우수, 데이터 많이 필요 |
### 사전 기반 감성분석 순서
1. **토큰화**: 문장 → 단어 (`"I love data science"` → I, love, data, science)
1. **감성 사전과 inner join**: 공통 열 `word`로 결합 → 사전에 있는 단어만 남음
1. **점수 계산**: 단순 합, 가중치, 빈도 기반, 정규화
1. **전체 감성 판정**
```r
library(tidytext)
library(dplyr)
text <- data.frame(line = 1, text = "I love this movie")
text %>%
  unnest_tokens(word, text) %>%                 # 토큰화 (소문자 변환, 구두점 제거 포함)
  inner_join(get_sentiments("nrc"))             # 사전과 조인
```
- 왜 inner join: 감정이 없는 단어(I, data, science)를 자동으로 버려 계산량↓, 정확도↑. left join이면 모든 단어가 남고 감정 열은 NA
- 점수 예: "I love this movie but the ending is bad" → love +1, bad −1 → 합 0, **중립**
- **부정어 처리**: "not good"은 good(+)이 있어도 부정 → 부정어 근처 단어의 극성을 뒤집어야 함 (단어 단위 사전의 대표적 약점)
- 사전 이름은 소문자 `"nrc"`, `"afinn"`, `"bing"` (슬라이드의 `'NRC'`처럼 대문자로 쓰면 인자 오류). nrc와 afinn은 라이선스 때문에 처음 쓸 때 `textdata` 패키지가 다운로드 동의를 묻고 받아옴
### NRC 예제
```r
sentence <- data.frame(line = 1, text = "i love data science")
token <- unnest_tokens(sentence, word, text)
#   line    word
#      1       i
#      1    love
#      1    data
#      1 science
result <- inner_join(token, get_sentiments("nrc"))
#   line word sentiment
#      1 love       joy
#      1 love  positive
```
- 한 단어가 여러 감정을 가질 수 있어 love가 두 줄로 나옴
### 감성 사전 비교
| 사전 | 형태 | 특징 | 용도 |
|---|---|---|---|
| NRC (캐나다 국립연구위원회) | 단어 → 감정 범주 | 긍정·부정 + 8감정(분노, 기대, 혐오, 공포, 기쁨, 슬픔, 놀람, 신뢰) = 10개 | 어떤 감정이 강한지까지 |
| AFINN | 단어 → −5 ~ +5 | 감정의 **강도** | 수치 분석 |
| Bing (Liu) | 단어 → positive / negative | 가장 단순하고 빠름 | 빠른 분류 |
| SentiWordNet | WordNet 동의어 집합 → 긍정·부정·객관 점수 | 의미 기반 정밀 분석 | 정교한 분석 |
- 간단히: Bing, AFINN / 정교하게: NRC, SentiWordNet
### 한국어 감성분석
- NRC는 영어 사전이라 그대로 못 씀
  - 가장 쉬운 길: 한국어 → 영어 번역 → NRC 적용
  - 직접 구축: NRC 단어를 번역(Google API 등)해 한국어 사전 만들기
  - 기존 한국어 사전: **KNU 감성사전**, **KOSAC**
### 동시출현단어 분석
- 단어들이 같은 문맥(문장, 문서, 윈도우) 안에서 함께 등장하는 패턴
| 계열 | 기법 |
|---|---|
| 단순 | 빈도, n-gram |
| 통계 | PMI, χ², Dice 계수 |
| 구조 | 네트워크 분석 |
| 의미 | Word2Vec, GloVe |
- **단순 동시출현 빈도**: 단어 쌍이 같은 문장·문서에 몇 번 함께 나왔나 → 동시출현 행렬
  - 직관적이지만 "흔한 단어라서 우연히 같이 나온 것"을 못 거름 → 통계 기반(PMI 등)으로 보정
  - `anti_join(tokens, stop_words)`: 겹치는 행을 **빼는** 조인 → 불용어(the, is, …) 제거에 필수
  - `widyr::pairwise_count(df, word, doc)`: 같은 문서(문맥)에 함께 나온 단어 쌍의 수
```r
library(widyr)
tokens %>%
  anti_join(stop_words, by = "word") %>%          # 불용어 제거
  pairwise_count(word, line, sort = TRUE)         # line(문장) 단위로 함께 나온 쌍 세기
```
- **윈도우 기반**: 각 단어 앞뒤 N개 안에 함께 나오면 동시출현
  - 예: "데이터 과학은 재미있다", 윈도우 크기 2 → (데이터, 과학), (과학, 재미있다)
  - 문장 단위보다 촘촘한 관계를 잡음. Word2Vec 같은 단어 임베딩의 기반 아이디어
