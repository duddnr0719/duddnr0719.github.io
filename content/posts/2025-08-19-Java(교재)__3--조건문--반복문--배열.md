## switch 문
<columns>
<column ratio="50">
- if-else 문과 비슷하지만 좀 더 일정한 형식이 있는 구조
- case 문 내부에 break는 해당 case 문을 실행한 뒤 switch 문을 빠져나가기 위한 것이다.
→ break 문이 없다면 그 다음의 case 문에 속한 문장들이 실행된다.
</column>
<column ratio="50">
![](/images/409d56618fe269cd.png)
</column>
</columns>

### 향상된 switch 문
```java
public class Test { 
public static void main(String args[]) {
var day = "SAT";
var today = "";
switch(day) {
case "SAT", "SUN" -> today = "주말";
case "MON", "TUE", "WED", "THU", "FRI" -> today = "평일";
default -> System.out.println("Error");
}
}
}
```

## while 문
<columns>
<column ratio="50">
- 조건문이 참인 동안 while 문이 수행할 문장들을 반복하여 수행한다.
- while 문을 사용하여 무한 루프를 생성할 수 있는데, while(true)를 이용하면 된다.
→ 조건식이 항상 true(참)이므로 무한 루프 안에 break 문처럼 빠져나올 수 있는 문장이 있는 경우를 제외하고는 무한 루프의 굴레에 빠지게 된다.

→ while 문 안의 문장을 수행할 때 어떤 조건을 검사해서 참이 아닌 경우 반복문을 벗어나는 것이 아닌 조건문으로 돌아간다.

## 배열
<columns>
<column ratio="50">
- 여러 개의 변수를 하나로 묶어 넣은 것

### 배열의 선언


## 반복문과 배열
- 배열의 각각의 요소는 인덱스(index)를 통하여 접근할 수 있다.
- 반복문의 초기식, 조건식, 증감식을 잘 다루어 사용하면 배열의 모든 요소에 접근할 수 있다.
```java
public class ArrayTest {
public static void main(String args[]) {
int[] s = new int[10];
// 배열 값 초기화
for(int i = 0; i < s.length; i++) { // .length -> 배열의 크기를 가져옴
s[i] = i;
}
// 배열 값 참조
for(int i = 0; i < s.length; i++) {
System.out.print(s[i] + " ");
}
}
}
```

## 래그드 배열
<columns>
<column ratio="50">
- 각 행의 길이가 달라도 되는 배열.
→ 첫 번째 차원은 고정되지만 두 번째 차원은 각각 다를 수 있음.
### 특징
1. 메모리 효율성
→ 꼭 필요한 크기만 할당 가능하다. ⇒ 메모리 공간을 절약할 수 있다.
2. 유연성
→ 한 차원은 고정된 길이지만 다른 차원은 자유롭게, 다르게 설정 가능하다.
3. 1차원 배열의 배열
→ 자바에서 2차원 배열은 1차원 배열의 배열로 구현되는데 래그드 배열은 이 구조를 활용한다. ⇒ 각 행에 서로 다른 길이의 1차원 배열을 할당하기 때문에 각 행의 크기가 다를 수 있다.
</column>
