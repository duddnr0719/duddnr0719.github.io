## 스윙 패키지
- Java.awt → GUI 컴포넌트를 위한 부모 클래스들을 제공하고 추가로 Color, Point와 같은 유틸리티 타입의 클래스들을 포함한다.
- Java.awt.event → GUI 컴포넌트로부터 발생되는 이벤트를 처리하기 위한 클래스와 인터페이스를 가지고 있다.
- javax.swing → 버튼이나 텍스트 필드, 프레임, 패널과 같은 GUI 컴포넌트들을 가지고 있다.

## 컴포넌트(Component)
- 기본 컴포넌트
- JButton, JLabel, JCheckBox, JChoice, JList, JTextField, JTextArea 등이 여기에 속한다.
- 컨테이너 컴포넌트
- 다른 컴포넌틀 안에 포함할 수 있는 컴포넌트.
- JFrame, JDialog, JPanel 등이 여기에 속한다.

### 컨테이너
- 최상위 컨테이너 
- 절대 다른 컨테이너 안에 포함될 수 없는 컨테이너.
- JFrame, JDialog, JApplet 등이 여기에 속한다.
- 일반 컨테이너
- 다른 컨테이너 안에 포함될 수 있는 컨테이너.
- JPanel, JScrollPane 등이 여기에 속한다.

## GUI 작성 절차
```java
1. 프레임 생성

1-1. 프레임 생성 방법 (1)

import javax.swing.*;

public class FrameTest {
public static void main(String[] args) {
JFrame f = new JFrame("Frame Test");
f.setTitle("MyFrame");
f.setSize(300, 200);
f.setVisible(true);
f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
}
}

1-2. 프레임 생성 방법 (2)

import javax.swing.*;

public class MyFrame extends JFrame {
public MyFrame() {
setSize(300,200);
setTitle("MyFrame");
setVisible(true);
setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
}
public static void main(String[] args) {
MyFrame f = new MyFrame();
}
}

2. 프레임에 버튼 추가하기

import javax.swing.*;
import java.awt.*;

public class MyFrame extends JFrame {
public MyFrame() {
setSize(300,200);
setTitle("MyFrame");

setLayout(new FlowLayout());
JButton button = new JButton("Button");
add(button);
setVisible(true);
setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
}
public static void main(String[] args) {
MyFrame f = new MyFrame();
}
}
```
