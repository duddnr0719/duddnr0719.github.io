## iframe
- 웹페이지 안에서 프레임을 만들고 여기에 다른 웹페이지를 표시하고자 할 때 사용한다.
- <iframe> 태그를 사용하여 정의
- <iframe src=”a.html” width=”300” height=”200”></iframe>
  → a.html 페이지 안에 너비 300, 높이 200짜리 iframe을 생성한다.
-  <iframe src="about:blank" name="iframe1" width="600" height="400"></iframe><p><a href="[https://www.google.co.kr](https://www.google.co.kr/)" target="iframe1">구글</a></p>
  → 하이퍼링크 된 링크를 클릭하면 target이 가리키는 곳(iframe1) 안에서 홈페이지가 열린다.

- <div> 태그를 사용하여 정의

## HTML 입력 양식
- 사용자가 입력한 내용을 서버로 보낼 때 사용
- <form> 요소를 사용하여 정의
- <form action=”…” method=”…”> … </form>
  → action 뒤에 입력을 처리하는 서버 스크립트의 주소를 적는다.
  → method 뒤에 입력 데이터가 서버로 보내지는 방법을 기술한다. (GET OR POST)
  - GET : URL 뒤에 파라미터를 붙여 서버로 전송하는 방식 → 정보보안에 취약하다.
  - POST : HTTP Request 헤더에 포함시켜 서버로 전송하는 방식 → 정보보안에 강하다.
## 입력 요소
- input : 아주 다양하게 사용되는 입력 요소, type 속성에 따라 입력의 형태가 달라진다.
- label : 입력 요소에 대한 레이블을 정의한다. → <input> 요소를 위한 레이블을 정의한다.
- select : 드롭다운 리스트를 정의한다. → 메뉴를 표시하고 사용자에게 하나를 선택하도록 한다.
- textarea : 다중 라인 입력 필드
- button : 클릭 가능한 버튼을 생성한다.
- fieldset : 데이터를 그룹핑할 때 사용한다. → 다양한 입력 요소들을 넣을 수 있으며 그룹의 경계에 선을 그린다.
- datalist : 미리 정의된 옵션 목록을 지정한다. → 선택 항목들을 지정하여 사용자가 선택하도록 한다.
- option : 선택될 수 있는 항목을 정의한다.
→ <input type=”…” value=”…” name=”…”>
⇒ type : 입력 필드의 종류 결정 (button …)
⇒ value : 버튼에 나타내는 텍스트
⇒ name : 서버로 전달되는 이름
- type 속성 값
  - text : 텍스트를 입력할 수 있는 한 줄짜리 필드 생성
  - password : 비밀번호를 입력할 수 있는 한 줄짜리 필드 생성
  - radio : 라디오 버튼 생성 (중복 선택 불가)
  - checkbox : 체크 박스 생성 (중복 선택 가능)
  - file : 파일 이름을 입력하는 필드 생성
  - reset : 초기화 버튼 생성 → 버튼을 누르면 모든 입력 필드가 초기화된다.
  - image : 이미지를 전송 버튼으로 만든다.
  - hidden : 사용자에게는 보이지 않지만 서버로 전송한다.
  - submit : 제출 버튼 생성
