> 횟수가 정해져 있으면 for, 조건(시간·입력 등)으로 끝나면 while, 최소 한 번은 해야 하면 do while, 컬렉션을 훑으면 foreach. break는 탈출, continue는 다음 바퀴로.
### 배열 기초
- 여러 자료를 한꺼번에 다루는 자료형. 각 자료 = **요소**, 대괄호 안 번호 = **인덱스**(0부터)
```csharp
int[] intArray = { 52, 273, 32, 65, 103 };
string[] stringArray = { "윤인성", "연하진", "윤아린" };

intArray[0] = 0;                      // 요소 변경
Console.WriteLine(intArray[0]);       // 0
Console.WriteLine(intArray[1]);       // 273
Console.WriteLine(intArray.Length);   // 5 (List는 Count)
```
- 범위 밖(`intArray[5]`, `intArray[-1]`) → `IndexOutOfRangeException`
- 크기만 정해서 만들기: `int[] array = new int[10];` → 숫자는 0, bool은 false, string 같은 참조형은 **null**로 채워짐
- 잘못된 생성: `int[] array = int[] { 1, 2, 3 };` (✗) → `new int[] { 1, 2, 3 }` 또는 `{ 1, 2, 3 }`
### while
- 조건이 참인 동안 반복. 조건을 거짓으로 만드는 문장이 없으면 무한 루프
```csharp
int i = 0;
int[] intArray = { 52, 273, 32, 65, 103 };
while (i < intArray.Length)
{
    Console.WriteLine(i + "번째 출력:" + intArray[i]);
    i++;
}
// 0번째 출력:52 … 4번째 출력:103
```
- 시간 같은 **외부 요인**으로 끝날 때 적합
```csharp
long start = DateTime.Now.Ticks;   // Ticks = 0001-01-01 이후 100ns 단위
long count = 0;
while (start + 10000000 > DateTime.Now.Ticks)   // 10,000,000 tick = 1초
{
    count++;
}
Console.WriteLine(count + "만큼 반복했습니다.");
```
### do while
- 조건을 나중에 검사 → **최소 한 번** 실행
```csharp
string input;
do
{
    Console.Write("입력(exit을 입력하면 종료): ");
    input = Console.ReadLine();
} while (input != "exit");
```
- 대부분은 while, do while은 "일단 한 번은 해야 할 때"만
### for
- 순서: 초기식 → 조건식 검사(거짓이면 끝) → 본문 → 종결식(`i++`) → 다시 조건식
```csharp
int output = 0;
for (int i = 0; i <= 100; i++)
    output += i;
Console.WriteLine(output);   // 5050

long fact = 1;               // 곱셈은 1에서 시작, int 범위를 넘으니 long
for (int i = 1; i <= 20; i++)
    fact *= i;
Console.WriteLine(fact);     // 2432902008176640000
```
- 한글 전부 출력: 문자는 정수라서 범위 반복 가능 → `가`부터 `힣`까지 **11,172자**
```csharp
for (int i = '가'; i <= '힣'; i++)
    Console.Write((char)i);
```
- 역 for: 뒤에서부터
```csharp
int[] intArray = { 1, 2, 3, 4, 5, 6 };
for (int i = intArray.Length - 1; i >= 0; i--)
    Console.WriteLine(intArray[i]);   // 6 5 4 3 2 1
```
- VS 코드 조각: `for` 입력 후 Tab 두 번 → for 틀 자동 생성 (`forr`은 역 for)
### foreach
- 컬렉션의 요소를 처음부터 끝까지 하나씩
```csharp
string[] array = { "사과", "배", "포도", "딸기", "바나나" };
foreach (var item in array)     // 보통 var 사용
{
    Console.WriteLine(item);
}
```
- `for (int i = 0; i < array.Length; i++) { var item = array[i]; … }`와 같은 의미. 단, foreach의 반복 변수에는 대입할 수 없음(읽기 전용)
### 중첩 반복문
```csharp
// 오른쪽 정렬 별 피라미드
for (int i = 0; i < 10; i++)
{
    for (int j = 0; j < 10 - i; j++) Console.Write(' ');
    for (int j = 0; j < i + 1; j++)  Console.Write('*');
    Console.Write('\n');
}
```
### break, continue, goto
- `break`: 가장 가까운 반복문(또는 switch)을 즉시 탈출. 무한 루프 + 탈출 조건 패턴
```csharp
while (true)
{
    Console.Write("숫자를 입력해주세요(짝수를 입력하면 종료): ");
    int input = int.Parse(Console.ReadLine());
    if (input % 2 == 0) break;
}
```
- 중첩 반복문을 한꺼번에 빠져나갈 땐 `goto 레이블;`도 가능하지만 흐름을 어지럽혀 지양 (플래그 변수나 메서드로 분리 후 return 권장)
- `continue`: 이번 바퀴의 나머지를 건너뛰고 다음 바퀴로
```csharp
for (int i = 1; i < 10; i++)
{
    if (i % 2 == 0) continue;
    Console.WriteLine(i);       // 1 3 5 7 9
}
```
  - 같은 결과를 `if (i % 2 != 0) Console.WriteLine(i);`로도 쓸 수 있지만, 조건이 많을 땐 '조기 continue'로 중첩을 줄이는 데 유용
### 문자열 처리
| 메서드 | 설명 |
|---|---|
| `ToUpper()` / `ToLower()` | 전부 대문자 / 소문자로 |
| `Split()` | 구분자로 잘라 배열로 |
| `Trim()` / `TrimStart()` / `TrimEnd()` | 양옆 / 앞 / 뒤 공백 제거 |
| `string.Join(구분자, 배열)` | 배열 요소를 이어 하나의 문자열로 |
```csharp
string input = "Potato Tomato";
Console.WriteLine(input.ToUpper());   // POTATO TOMATO
Console.WriteLine(input.ToLower());   // potato tomato

string[] inputs = "감자 고구마 토마토".Split(new char[] { ' ' });
// 빈 항목 제거: Split(new string[] { " " }, StringSplitOptions.RemoveEmptyEntries)

Console.WriteLine("::" + "  test  \n".Trim() + "::");   // ::test::
Console.WriteLine(string.Join(",", new[] { "감자", "고구마", "토마토", "가지" }));   // 감자,고구마,토마토,가지
```
- C# 문자열 메서드는 **비파괴적**: 원본은 그대로 두고 새 문자열을 반환 (`input.ToUpper();`만 쓰면 아무 변화 없음)
### 이동하는 달팽이
- `Console.Clear()` 화면 지우기, `Console.SetCursorPosition(x, y)` 커서 이동, `Thread.Sleep(ms)` 멈춤 (`using System.Threading;`)
```csharp
int x = 1;
while (x < 50)
{
    Console.Clear();
    Console.SetCursorPosition(x, 5);
    if (x % 3 == 0)      Console.WriteLine(" __@");
    else if (x % 3 == 1) Console.WriteLine("^__@");
    else                 Console.WriteLine("^_@");
    Thread.Sleep(100);
    x++;
}
```
- `while (i-- > 0)`은 `(i--) > 0`: 비교 후 감소. 헷갈리니 괄호·띄어쓰기로 의도를 드러내기
