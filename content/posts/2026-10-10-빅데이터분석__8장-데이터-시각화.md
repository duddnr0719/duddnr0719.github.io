### 트리맵
- 계층 데이터(부모-자식)를 **중첩된 사각형**으로. 타일 **크기**와 **색**으로 두 가지 수치를 표현 (계층이 없어도 가능)
- 예: Forbes 2022 — 크기는 매출, 색은 직원당 수익 → 소규모 제약사의 직원당 수익이 가장 높고, 중간 규모 컴퓨터 회사는 음수
```r
install.packages("treemap")
library(treemap)
data(GNI2014)        # iso3, country, continent, population, GNI
treemap(GNI2014,
        index = c("continent", "iso3"),   # 계층: 대륙 안에 국가
        vSize = "population",             # 타일 크기
        vColor = "GNI",                   # 타일 색
        type = "value",                   # vColor 값 크기대로 색칠
        title = "World's GNI")
```
- 미국 주별 면적(크기)과 소득(색)
```r
st <- data.frame(state.x77)
st <- data.frame(st, stname = rownames(st))   # 주 이름 열 추가
treemap(st, index = c("stname"), vSize = "Area", vColor = "Income",
        type = "value", title = "USA states area and income")
```
### 버블차트
- 산점도(변수 2개) + 원 크기(변수 1개) = 변수 3개
```r
st <- data.frame(state.x77)
symbols(st$Illiteracy, st$Murder,        # x: 문맹률, y: 살인율
        circles = st$Population,         # 원 반지름: 인구
        inches = 0.3,                    # 가장 큰 원의 크기 (인치)
        fg = "white", bg = "lightgray", lwd = 1.5,
        xlab = "rate of Illiteracy", ylab = "crime(murder) rate",
        main = "Illiteracy and Crime")
text(st$Illiteracy, st$Murder, rownames(st), cex = 0.6, col = "brown")   # 원 위에 주 이름
```
- 문맹률이 높을수록 범죄율이 높고, 인구 많은 주가 대체로 범죄율도 높음. 최저는 North Dakota
- 참고: `circles`는 **반지름**이라 면적은 값의 제곱에 비례해 커 보임 → 면적을 값에 비례시키려면 `circles = sqrt(st$Population)`
### 모자이크 플롯
- 범주형 변수들의 그룹별 비율을 **면적**으로. 카이제곱 독립성 검정과 함께 자주 사용
- UCBAdmissions (버클리 대학원 지원·합격)
  - 남성 지원자 2,691명, 여성 1,835명 → 약 1.5배
  - 합격률: 남성 44.5%, 여성 30.4% → 전체 합격률은 50% 미만, 여성이 눈에 띄게 낮아 보임
  - 함정(**심슨의 역설**): 학과별로 나눠 보면 대부분 학과에서 여성 합격률이 오히려 비슷하거나 높음. 여성이 경쟁률 높은 학과에 더 많이 지원해서 합쳐 놓으면 낮아 보이는 것 → 집계만 보고 결론 내리면 안 됨
```r
mosaicplot(~ gear + vs, data = mtcars, color = TRUE, main = "Gear and Vs")   # ~ 첫 변수는 가로, 둘째는 세로로 분할
mosaicplot(~ gear + vs, data = mtcars, color = c("green", "blue"), main = "Gear and Vs")
```
- Titanic: 슬라이드는 `mosaicplot(~ Class + Sex, data = Titanic, …)`의 결과로 "여성·1등석 생존율이 높고 승무원은 낮다"고 해석하는데, 이 코드에는 **생존 여부(Survived)가 없어서** 등급별 남녀 구성비만 나옴. 생존율을 보려면 생존 변수를 넣어야 함
```r
mosaicplot(~ Class + Survived, data = Titanic, main = "타이타닉 생존현황",
           color = c("red", "green"), off = 2)          # off: 블록 간격
# 등급별 생존 (No / Yes): 1st 122/203, 2nd 167/118, 3rd 528/178, Crew 673/212
mosaicplot(~ Sex + Survived, data = Titanic, color = c("red", "green"))   # 성별 생존
```

### ggplot2 기본 구조
- Grammar of Graphics (Hadley Wickham). `ggplot()` 하나에 `geom_xx()`들을 `+`로 연결
  - **data**: 무엇을
  - **aes**(미적 매핑): 어떤 열을 x, y, color, fill, size, shape, alpha에 연결할지
  - **geom**: 무엇으로 (점, 선, 막대 …)
```r
ggplot(data = sleep, aes(x = ID, y = extra)) + geom_bar(stat = "identity")
```
| 함수 | 그래프 |
|---|---|
| `geom_bar` / `geom_col` | 막대 (+ `coord_polar()`면 파이) |
| `geom_histogram`, `geom_density` | 히스토그램, 밀도 |
| `geom_boxplot` | 상자그림 |
| `geom_point` | 산점도 |
| `geom_line`, `geom_area` | 선, 영역 |
| `geom_text` | 텍스트 |
- 막대 배치: 기본은 **누적**, `position = "dodge"`는 나란히, `position = "fill"`은 100% 비율, `coord_flip()`은 가로, `coord_polar()`는 원형
```r
ggplot(diamonds, aes(clarity, fill = cut)) + geom_bar()                      # 누적
ggplot(diamonds, aes(clarity, fill = cut)) + geom_bar(position = "dodge")    # 그룹
ggplot(diamonds, aes(color, fill = cut)) + geom_bar(position = "fill")       # 비율
ggplot(diamonds, aes(color, fill = cut)) + geom_bar() + coord_polar(theta = "y")   # 파이 형태
```
### ggplot2 그래프들
```r
# 막대: 값 그대로 높이로 쓰려면 stat = "identity"
df <- data.frame(month = 1:6, rain = c(55, 50, 45, 50, 60, 70))
ggplot(df, aes(x = month, y = rain)) +
  geom_bar(stat = "identity", width = 0.7, fill = "steelblue") +
  ggtitle("월별 강수량") +
  theme(plot.title = element_text(size = 25, face = "bold", colour = "steelblue")) +
  labs(x = "월", y = "강수량") +
  coord_flip()

# 히스토그램 (그룹별 나란히)
ggplot(iris, aes(x = Petal.Length)) + geom_histogram(binwidth = 0.5)
ggplot(iris, aes(x = Sepal.Width, fill = Species, color = Species)) +
  geom_histogram(binwidth = 0.5, position = "dodge") +
  theme(legend.position = "top")

# 산점도 (그룹별 색)
ggplot(iris, aes(x = Petal.Length, y = Petal.Width, color = Species)) +
  geom_point(size = 3) +
  ggtitle("꽃잎의 길이와 폭")

# 상자그림
ggplot(iris, aes(y = Petal.Length)) + geom_boxplot(fill = "yellow")
ggplot(iris, aes(y = Petal.Length, fill = Species)) + geom_boxplot()

# 선그래프: 1937~1960 미국 항공 여객 마일
df <- data.frame(year = 1937:1960, cnt = as.vector(airmiles))
ggplot(df, aes(x = year, y = cnt)) + geom_line(col = "red")
```
- `stat = "identity"`가 없으면 geom_bar는 **개수**를 세서 높이로 씀 (값을 그대로 쓰는 `geom_col()`과 같은 효과)
### ggpairs
- 상관계수: −1 ~ +1, 부호는 방향, 절댓값이 클수록 관계가 강함
- GGally의 `ggpairs()`: pairs()보다 풍부하게 — 대각선엔 밀도, 아래엔 산점도, 위엔 상관계수(유의성 별표: `***` p < 0.001, `**` < 0.01, `*` < 0.05, `.` < 0.1)
```r
library(GGally)
ggpairs(iris, columns = 1:4)
# Sepal.L–Sepal.W −0.118, Sepal.L–Petal.L 0.872***, Petal.L–Petal.W 0.963***
ggpairs(iris, columns = 1:4, aes(color = Species))   # 품종별로도
```
- 품종별로 나누면 그림이 달라짐: 꽃받침 길이-폭은 전체로는 −0.118(거의 무관)이지만 setosa 0.743, versicolor 0.526, virginica 0.457로 **품종 안에서는 모두 양의 상관** → 그룹을 섞으면 관계가 가려질 수 있음 (심슨의 역설과 같은 맥락)
### 차원 축소
- 고차원 데이터를 구조·패턴은 최대한 보존하며 낮은 차원으로. 정보 손실은 생김 (JPEG 같은 손실 압축처럼)
- 필요성: 2·3차원으로 **시각화**, **차원의 저주**(차원이 늘수록 계산량 급증, 거리 개념 불안정) 완화, 불필요한 변수 제거로 **과적합 방지**, **속도 향상**
- 비유: 짐이 잔뜩인데 기내용 가방 하나만 → 꼭 필요한 것만 남기고(노트북, 여권) 비슷한 건 합침(샴푸 + 린스 + 바디워시 → 올인원)
| 기법 | 특징 |
|---|---|
| PCA | 선형, **분산이 가장 큰 방향**으로 축을 다시 잡음 |
| t-SNE | 비선형, 가까운 점끼리의 **이웃 관계** 보존, 군집 시각화에 강함 |
| UMAP | 비선형, t-SNE보다 빠르고 전체 구조 보존이 좋음 |
| LDA | 지도학습, 클래스 간 분산 최대·클래스 내 분산 최소인 축 |
| Autoencoder | 신경망, 압축했다 복원하는 구조의 가운데 층을 저차원 표현으로 |
- 3차원 물체에 빛을 비추면 2차원 그림자가 생기는 것처럼 축소
```r
library(Rtsne)
library(ggplot2)
ds <- iris[, -5]
dup <- which(duplicated(ds))   # 143 (102번 행과 완전히 같음) → Rtsne는 중복이 있으면 오류
ds <- ds[-dup, ]
ds.y <- iris$Species[-dup]

tsne <- Rtsne(ds, dims = 2, perplexity = 10)   # perplexity는 대략 (행 수 − 1) / 3 미만이어야 함
df.tsne <- data.frame(tsne$Y)
ggplot(df.tsne, aes(x = X1, y = X2, color = ds.y)) + geom_point(size = 2)
```
- 3차원: `Rtsne(ds, dims = 3, perplexity = 10)` 후 car 패키지의 `scatter3d(x, y, z, point.col = color[as.integer(ds.y)], surface = FALSE)` (회전 가능한 3D 산점도, `surface = FALSE`는 회귀면 숨김)
- t-SNE는 실행할 때마다 배치가 달라지므로 재현하려면 `set.seed()`. 축의 값이나 군집 사이 거리 자체에는 의미가 없고 "가까운 것끼리 모였는가"만 봄
