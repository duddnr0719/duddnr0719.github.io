> 에지 점들이 (ρ, θ) 공간에 투표해 직선을 찾는 허프 변환, 모든 방향으로 밝기가 변하는 점을 R = det(M) − k·trace(M)²로 찾는 해리스 코너, 가까운 k개의 다수결로 숫자를 맞히는 k-NN, 체스보드로 렌즈 왜곡을 펴는 카메라 캘리브레이션.
### 허프 변환
- 영상 속 직선 찾기 (차선 인식, 문서 스캔 앱의 네 모서리 등)
- y = ax + b로는 **수직선의 기울기가 무한대** → 극좌표 **ρ = x cos θ + y sin θ** (ρ: 원점에서 직선까지 수직 거리, θ: 그 수선과 x축의 각도)
  - 영상의 **직선 하나 = (ρ, θ) 공간의 점 하나**
  - 영상의 **점 하나 = (ρ, θ) 공간의 사인 곡선 하나** (그 점을 지나는 모든 직선)
  - 같은 직선 위의 점들의 곡선은 **한 점에서 만남** → 그 (ρ, θ)에 표가 몰림
- 누적 행렬: ρ는 −ρmax ~ ρmax (대각선 길이 이상, 예: 512×512면 약 724), θ는 0 ~ π(180° 이상은 대칭이라 생략), 간격 Δρ, Δθ
1. (ρ, θ) 누적 행렬을 0으로
1. 에지 화소마다
1. 모든 θ에 대해 ρ를 계산해 해당 칸에 +1 (**투표**)
1. 주변보다 큰 **지역 최댓값**만 남김 (비슷한 직선이 여러 개 잡히는 것 방지)
1. 임계값 이상을 누적값 내림차순으로 정렬 → 직선
```python
# 벡터화된 투표: [sin θ, cos θ] (θ개 × 2) · [y; x] (2 × 점 개수) = 각 θ에서의 ρ
sin_cos = [(np.sin(t * theta), np.cos(t * theta)) for t in range(cols)]
pts = np.where(image > 0)                                   # (ys, xs)
polars = np.dot(sin_cos, pts).T                             # ρ = y sin θ + x cos θ
polars = (polars / rho + rows / 2).astype('int')            # 음수 ρ를 위해 rows/2만큼 밀어 인덱스로
```
```python
blur = cv2.GaussianBlur(image, (5, 5), 2, 2)
canny = cv2.Canny(blur, 100, 200, 5)
lines = cv2.HoughLines(canny, 1, np.pi / 180, 80)          # ρ 간격 1, θ 간격 1°, 임계 80표
# shape (N, 1, 2), 각 원소 [ρ, θ]
for rho_, theta_ in lines[:7, 0]:
    a, b = np.cos(theta_), np.sin(theta_)
    x0, y0 = a * rho_, b * rho_                              # 직선 위 한 점 (원점에서 내린 수선의 발)
    pt1 = (int(x0 - 1000 * b), int(y0 + 1000 * a))           # 직선 방향 (−b, a)으로 ±1000

    cv2.line(dst, pt1, pt2, (0, 255, 0), 2, cv2.LINE_AA)
```

### 코너 검출
- 에지는 강도와 방향만 있어 **영상 매칭**에는 정보가 부족 → 코너(꼭짓점) = **모든 방향**으로 밝기 변화가 큰 점 (평탄한 곳은 어느 방향도, 에지는 한 방향만 변함)
- **모라벡**: 창을 (u, v)만큼 옮겼을 때 변화량 E(u, v) = Σ w(x, y)·[I(x + u, y + v) − I(x, y)]² 를 4방향(→, ↘, ↓, ↙)만 계산
  - 0/1 사각 창이라 잡음에 약하고, 45° 간격 방향만 봄
- **해리스**: 가우시안 가중치 + 테일러 1차 근사로 **모든 방향**을 한 번에
  - I(x + u, y + v) ≈ I + u·dx + v·dy → E(u, v) ≈ [u v] M [u v]ᵀ
  - **M = Σ G·[[dx², dx·dy], [dx·dy, dy²]] = [[a, c], [c, b]]** — 주변 기울기의 분포
  - M의 고유값 λ₁, λ₂: 둘 다 작음 → 평탄, 하나만 큼 → 에지, **둘 다 큼 → 코너**
  - 고유값 계산 대신 **R = det(M) − k·trace(M)² = (ab − c²) − k(a + b)²**, k ≈ 0.04~0.06 → R이 크면 코너
  - 이동·회전에 불변, 어파인·조명 변화에도 어느 정도 강함 (크기 변화엔 약함 → SIFT 등)
1. Sobel로 dx, dy → 2. dx², dy², dx·dy → 3. 각각 가우시안 블러 → 4. R 계산 → 5. 비최대 억제(3×3 이웃 중 최대인 점만)
```python
def cornerHarris(image, ksize, k):
    dx = cv2.Sobel(image, cv2.CV_32F, 1, 0, ksize=ksize)
    dy = cv2.Sobel(image, cv2.CV_32F, 0, 1, ksize=ksize)
    a = cv2.GaussianBlur(dx * dx, (5, 5), 0)
    b = cv2.GaussianBlur(dy * dy, (5, 5), 0)
    c = cv2.GaussianBlur(dx * dy, (5, 5), 0)
    return (a * b - c ** 2) - k * (a + b) ** 2

corner = cv2.cornerHarris(gray, blockSize=4, ksize=3, k=0.04)   # OpenCV
```
  - 확인: 흰 정사각형 (30~70)에 적용하면 응답이 큰 곳은 정확히 네 꼭짓점 근처뿐 (직접 확인)
  - 정규화는 `cv2.normalize(corner, None, 0, 100, cv2.NORM_MINMAX)` (출력 자리를 비워 둬야 함)
### k-최근접 이웃 분류기
- 학습 단계 없이(데이터를 저장만) 새 샘플과 모든 학습 샘플의 거리(유클리드, 해밍, 차분 절댓값)를 재서 가까운 **k개의 다수결**
  - k = 3: A 2, B 1 → A / k = 5: A 2, B 3 → B → **k에 따라 결과가 바뀜**. k = 1이면 잡음·이상치 하나에 그대로 휘둘림
  - 장점: 간단, 직관적 / 단점: 차원이 높으면 성능 저하(차원의 저주), 예측마다 전체 거리 계산, 이상치에 민감
```python
knn = cv2.ml.KNearest_create()
knn.train(traindata, cv2.ml.ROW_SAMPLE, label)          # float32, 행 하나가 샘플 하나
ret, resp, neig, dist = knn.findNearest(samples, k=7)   # resp: 예측 레이블, neig: 이웃 레이블, dist: 거리
```
- 2D 예: 평균 150(σ 30)과 평균 250(σ 60) 두 무리 50개씩(`cv2.randn`) → 400×400 모든 좌표를 분류해 색칠하면 결정 경계가 보임. k = 15가 k = 7보다 경계가 매끄러움
- **MNIST**: 28×28 손글씨 숫자, 784차원 벡터. train 50,000 / valid 10,000 / test 10,000
  - k = 5, 테스트 100개 → 정확도 98% (슬라이드)
  - 슬라이드의 다운로드 주소(deeplearning.net)는 현재 접속되지 않음 → `keras.datasets.mnist`, `sklearn.datasets.fetch_openml('mnist_784')` 등으로 받기 (형식이 달라 reshape·정규화 필요)
### k-NN 숫자 인식 응용
- 학습: 숫자 10종 × 20개를 쓴 영상 → 이진화 → `np.vsplit`(10행) + `np.hsplit`(20열)로 40×40 셀 200개 → 셀마다 숫자 영역만 잘라내기 → 정사각형 가운데 배치 → 크기 정규화 → 1차원 벡터(1600) → `knn.train`
- 숫자 영역 찾기 ① **투영 히스토그램**: `cv2.reduce(img, 0 or 1, cv2.REDUCE_AVG)`로 세로·가로 방향 평균 → 흰 배경(255)보다 어두운(< 250) 첫·마지막 위치
- 숫자 영역 찾기 ② **외곽선**: `cv2.findContours(~part, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE)` → `cv2.boundingRect`들을 합친 범위
```python
results = cv2.findContours(~part, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
contours = results[0] if len(results) == 2 else results[1]   # 4.x: (contours, hierarchy), 3.x: (img, contours, hierarchy)
```
  - 슬라이드의 버전 분기 `int(cv2.__version__) >= 4`는 `cv2.__version__`이 "4.13.0" 같은 문자열이라 `ValueError`가 남 (직접 확인). 위처럼 반환 개수로 나누거나 `int(cv2.__version__.split('.')[0])`
- 가운데 배치: big = max(h, w)인 흰 정사각형에 dx = (big − w)/2, dy = (big − h)/2 위치로 붙임 → 위치·비율이 통일돼 거리 비교가 공정해짐
```python
def place_middle(number, new_size):
    h, w = number.shape[:2]
    big = max(h, w)
    square = np.full((big, big), 255, np.float32)
    dx, dy = np.subtract(big, (w, h)) // 2
    square[dy:dy + h, dx:dx + w] = number
    return cv2.resize(square, new_size).flatten()      # (40, 40) → 1600차원

cells = [np.hsplit(row, 20) for row in np.vsplit(train_image, 10)]   # (10, 20, 40, 40) → 200개
trainData = np.array([place_middle(find_number(c), (40, 40)) for c in np.reshape(cells, (-1, 40, 40))])
labels = np.array([i for i in range(10) for j in range(20)], np.float32)
knn.train(trainData, cv2.ml.ROW_SAMPLE, labels)
_, [[resp]], _, _ = knn.findNearest(data.reshape(1, -1), 15)
```
### 영상 워핑과 모핑
- **워핑**: 비선형 규칙으로 화소를 재추출해 형태를 바꿈 (크기 변화가 영상 전체에 균일하지 않음). NASA가 위성 영상의 왜곡 복원에 처음 사용
- **모핑**: 한 영상이 다른 형체로 서서히 바뀌는 효과 (ILM이 개발, metamorphosis에서 유래)
- 카메라 영상의 왜곡
  - 외부 요인: 3D → 2D 투영에 따른 원근 왜곡
  - 내부 요인: 렌즈(방사 왜곡: 술통형·실패형), 초점거리, 렌즈와 센서의 기울기
### 카메라 캘리브레이션
- 핀홀 모델: **s·[u, v, 1]ᵀ = A · [R | t] · [X, Y, Z, 1]ᵀ**
  - **A(내부 파라미터)** = [[fx, 0, cx], [0, fy, cy], [0, 0, 1]] — 초점거리(픽셀 단위, 센서 가로세로 셀 크기가 달라 둘), 주점(렌즈 중심에서 센서에 내린 수선의 발, 영상 중심과는 다를 수 있음)
  - **[R | t](외부 파라미터)**: 월드 좌표 → 카메라 좌표 (회전 3×3 + 이동 3×1)
  - 여기에 렌즈 왜곡 계수(k₁, k₂, p₁, p₂, k₃)가 추가됨
- 체스보드로 구하기: 실제 좌표는 (0, 0, 0), (1, 0, 0), …처럼 알고 있고(z = 0 평면), 영상 좌표는 코너 검출로 얻음 → 여러 각도의 사진으로 A와 왜곡 계수 추정
```python
bSize = (8, 7)                                            # 내부 코너 개수 (가로, 세로)
points = np.array([(x, y, 0) for y in range(bSize[1]) for x in range(bSize[0])], np.float32)

gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
ret, corners = cv2.findChessboardCorners(gray, bSize)
if ret:
    criteria = (cv2.TERM_CRITERIA_MAX_ITER + cv2.TERM_CRITERIA_EPS, 30, 0.1)
    cv2.cornerSubPix(gray, corners, (11, 11), (-1, -1), criteria)   # 서브픽셀 정밀도로 보정

rms, K, dist, rvecs, tvecs = cv2.calibrateCamera(objectPoints, imagePoints, (w, h), None, None)
newK, roi = cv2.getOptimalNewCameraMatrix(K, dist, (w, h), 1)
undistorted = cv2.undistort(image, K, dist, None, newK)
x, y, w2, h2 = roi
cropped = undistorted[y:y + h2, x:x + w2]                 # 보정 후 유효 영역만
```
  - 반환값 첫 번째는 "성공 여부"가 아니라 **재투영 오차(RMS, 픽셀)** → 작을수록(보통 1 이하) 잘 맞은 것. 슬라이드 메모의 ret[3] = R, ret[4] = T도 실제로는 ret[3] = **rvecs**, ret[4] = **tvecs**라서, 슬라이드 코드의 `print("rvecs", ret[4])`는 tvecs를 출력함
