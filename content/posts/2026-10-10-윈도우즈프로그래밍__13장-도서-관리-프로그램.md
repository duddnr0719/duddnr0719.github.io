> 지금까지 배운 것(모델 클래스, static, 예외 처리, LINQ, LINQ to XML, 람다 이벤트, DataGridView, 메뉴, 모달 폼)을 묶어 DB 대신 XML 파일에 저장하는 도서 대여·반납 프로그램을 만든다.
### 동작
- 메인 화면: 도서 현황(전체 도서 수, 사용자 수, 대출 중, 연체 중) + 도서 그리드 + 사용자 그리드
- 도서와 사용자를 선택하면 [대여/반납] 그룹 박스에 정보가 채워짐
  - [대여] → `"Nature of Code"이/가 "윤인성"님께 대여되었습니다.` / 이미 빌려간 책이면 `이미 대여 중인 도서입니다.`
  - [반납] → `"Nature of Code"이/가 반납되었습니다.`
  - 그리드에 `IsBorrowed`, `BorrowedAt`, `UserId`, `UserName`이 갱신됨
- 메뉴 1: 도서 관리(추가·수정·삭제), 메뉴 2: 사용자 관리

### 모델 클래스
```csharp
class Book
{
    public string Isbn { get; set; }
    public string Name { get; set; }
    public string Publisher { get; set; }
    public int Page { get; set; }

    public int UserId { get; set; }
```

### DataManager: static 저장소
- `static List`라서 어느 폼에서든 `DataManager.Books`로 같은 데이터에 접근
- **정적 생성자**에서 `Load()` → 클래스를 처음 쓰는 순간 한 번 XML을 읽어옴
```csharp
class DataManager
{
    public static List<Book> Books = new List<Book>();
    public static List<User> Users = new List<User>();

    static DataManager()
    {
        Load();
    }

    public static void Load()
    {
        try
        {
            string booksOutput = File.ReadAllText(@"./Books.xml");
            XElement booksXElement = XElement.Parse(booksOutput);
            Books = (from item in booksXElement.Descendants("book")
                     select new Book()
                     {
                         Isbn = item.Element("isbn").Value,
                         Name = item.Element("name").Value,
                         Publisher = item.Element("publisher").Value,
                         Page = int.Parse(item.Element("page").Value),
                         BorrowedAt = DateTime.Parse(item.Element("borrowedAt").Value),
                         isBorrowed = item.Element("isBorrowed").Value != "0" ? true : false,
                         UserId = int.Parse(item.Element("userId").Value),
                         UserName = item.Element("userName").Value
                     }).ToList<Book>();

            string usersOutput = File.ReadAllText(@"./Users.xml");
            XElement usersXElement = XElement.Parse(usersOutput);
            Users = (from item in usersXElement.Descendants("user")
                     select new User()
                     {
                         Id = int.Parse(item.Element("id").Value),
                         Name = item.Element("name").Value
                     }).ToList<User>();
        }
        catch (FileNotFoundException exception)
        {
            Save();   // 첫 실행이라 파일이 없으면 빈 XML 두 개를 만들어 둠
        }
    }

    public static void Save()
    {
        string booksOutput = "<books>\n";
        foreach (var item in Books)
        {
            booksOutput += "  <book>\n";
            booksOutput += "    <isbn>" + item.Isbn + "</isbn>\n";
            booksOutput += "    <name>" + item.Name + "</name>\n";
            booksOutput += "    <publisher>" + item.Publisher + "</publisher>\n";
            booksOutput += "    <page>" + item.Page + "</page>\n";
            booksOutput += "    <borrowedAt>" + item.BorrowedAt.ToLongDateString() + "</borrowedAt>\n";
            booksOutput += "    <isBorrowed>" + (item.isBorrowed ? 1 : 0) + "</isBorrowed>\n";
            booksOutput += "    <userId>" + item.UserId + "</userId>\n";
            booksOutput += "    <userName>" + item.UserName + "</userName>\n";
            booksOutput += "  </book>\n";
        }
        booksOutput += "</books>";

        string usersOutput = "<users>\n";
        foreach (var item in Users)
        {
            usersOutput += "  <user>\n";
            usersOutput += "    <id>" + item.Id + "</id>\n";
            usersOutput += "    <name>" + item.Name + "</name>\n";
            usersOutput += "  </user>\n";
        }
        usersOutput += "</users>";

        File.WriteAllText(@"./Books.xml", booksOutput);
        File.WriteAllText(@"./Users.xml", usersOutput);
    }
}
```
- 저장 형태: `<books><book><isbn>9791156641452</isbn><name>IT CookBook 실전에 강한 PLC</name>…<borrowedAt>0001년 1월 1일 월요일</borrowedAt><isBorrowed>0</isBorrowed>…</book></books>`
- bool ↔ "0"/"1" 변환은 조건 연산자로
- 짚어둘 점
  - 문자열을 이어 붙여 XML을 만들기 때문에 책 이름에 `&`나 `<`가 들어가면 XML이 깨짐 → `new XElement("book", new XElement("name", item.Name), …).Save(path)`로 만들면 자동 이스케이프
  - `ToLongDateString()`("0001년 1월 1일 월요일")을 `DateTime.Parse`로 다시 읽으므로 **한국어 OS 설정**에 의존. 시각도 날짜만 남아 잘림 → `ToString("o")` 같은 고정 형식이 안전
### 메인 폼 (Form1)
```csharp
public Form1()
{
    InitializeComponent();
    Text = "도서관 관리";

    // 현황 레이블: LINQ 메서드 구문 + 람다
    label5.Text = DataManager.Books.Count.ToString();
    label6.Text = DataManager.Users.Count.ToString();
    label7.Text = DataManager.Books.Where((x) => x.isBorrowed).Count().ToString();
    label8.Text = DataManager.Books.Where((x) =>
    {
        return x.isBorrowed && x.BorrowedAt.AddDays(7) < DateTime.Now;   // 7일 넘으면 연체
    }).Count().ToString();

    dataGridView1.DataSource = DataManager.Books;
    dataGridView2.DataSource = DataManager.Users;
    dataGridView1.CurrentCellChanged += DataGridView1_CurrentCellChanged;
    dataGridView2.CurrentCellChanged += DataGridView2_CurrentCellChanged;

    button1.Click += Button1_Click;   // 대여
    button2.Click += Button2_Click;   // 반납
}

private void DataGridView1_CurrentCellChanged(object? sender, EventArgs e)
{
    try
    {
        Book book = dataGridView1.CurrentRow.DataBoundItem as Book;   // 선택한 행의 원본 객체
        textBox1.Text = book.Isbn;
        textBox2.Text = book.Name;
    }
    catch (Exception exception) { }   // 선택이 없을 때(null) 무시
}
```
- **대여**
```csharp
private void Button1_Click(object? sender, EventArgs e)
{
    if (textBox1.Text.Trim() == "") MessageBox.Show("Isbn을 입력해주세요");
    else if (textBox3.Text.Trim() == "") MessageBox.Show("사용자 ID를 입력해주세요");
    else
    {
        try
        {
            Book book = DataManager.Books.Single((x) => x.Isbn == textBox1.Text);
            if (book.isBorrowed)
            {
                MessageBox.Show("이미 대여 중인 도서입니다.");
            }
            else
            {
                User user = DataManager.Users.Single((x) => x.Id.ToString() == textBox3.Text);
                book.UserId = user.Id;
                book.UserName = user.Name;
                book.isBorrowed = true;
                book.BorrowedAt = DateTime.Now;

                dataGridView1.DataSource = null;              // 다시 연결해야 그리드가 갱신됨
                dataGridView1.DataSource = DataManager.Books;
                DataManager.Save();

                MessageBox.Show("\"" + book.Name + "\"이/가 \"" + user.Name + "\"님께 대여되었습니다.");
            }
        }
        catch (Exception exception)
        {
            MessageBox.Show("존재하지 않는 도서 또는 사용자입니다.");   // Single이 못 찾으면 예외
        }
    }
}
```
- `Single(조건)`: 조건에 맞는 게 **정확히 하나**일 때 반환, 0개거나 여러 개면 예외 (없을 때 null을 원하면 `SingleOrDefault`/`FirstOrDefault`)
- `DataSource = null` 후 재지정: `List<T>`는 변경 알림이 없어서 다시 연결해 화면을 새로 그림 (`BindingList<T>`를 쓰면 자동 갱신)
- **반납**
```csharp
Book book = DataManager.Books.Single((x) => x.Isbn == textBox1.Text);
if (book.isBorrowed)
{
    book.UserId = 0;
    book.UserName = "";
    book.isBorrowed = false;
    book.BorrowedAt = new DateTime();   // ← 여기서 대여일을 지움
    // … 그리드 갱신, Save()

    if (book.BorrowedAt.AddDays(7) > DateTime.Now)
        MessageBox.Show("\"" + book.Name + "\"이/가 연체 상태로 반납되었습니다.");
    else
        MessageBox.Show("\"" + book.Name + "\"이/가 반납되었습니다.");
}
else MessageBox.Show("대여 상태가 아닙니다.");
```
  - 교재 코드의 버그: 대여일을 **먼저 지운 뒤** 연체를 검사하고, 부등호도 반대(`>`면 아직 7일이 안 지난 것) → 0001년 기준이라 항상 "반납되었습니다"만 나옴
  - 고친 버전
```csharp
bool overdue = book.BorrowedAt.AddDays(7) < DateTime.Now;   // 지우기 전에 판단
book.UserId = 0; book.UserName = ""; book.isBorrowed = false; book.BorrowedAt = new DateTime();
// … 그리드 갱신, Save()
MessageBox.Show("\"" + book.Name + (overdue ? "\"이/가 연체 상태로 반납되었습니다." : "\"이/가 반납되었습니다."));
```
- **메뉴**: 관리 창을 **모달**로 띄우고, 닫히면 그리드 갱신
```csharp
private void ToolStripMenuItem1_Click(object? sender, EventArgs e)

```
### 도서 관리 (Form2) / 사용자 관리 (Form3)
- 버튼 이벤트를 람다로 연결하는 CRUD
```csharp
button1.Click += (sender, e) =>          // 추가
{
    try
    {
        if (DataManager.Books.Exists((x) => x.Isbn == textBox1.Text))
        {
            MessageBox.Show("이미 존재하는 도서입니다.");
        }
        else
        {
            DataManager.Books.Add(new Book()
            {
                Isbn = textBox1.Text,
                Name = textBox2.Text,
                Publisher = textBox3.Text,
                Page = int.Parse(textBox4.Text)
            });
            dataGridView1.DataSource = null;
            dataGridView1.DataSource = DataManager.Books;
            DataManager.Save();
        }
    }
    catch (Exception exception) { }     // 쪽수에 숫자가 아닌 값 등
};

button2.Click += (sender, e) =>          // 수정: Single로 찾아 속성 변경
{
    try
    {
        Book book = DataManager.Books.Single((x) => x.Isbn == textBox1.Text);
        book.Name = textBox2.Text;
        book.Publisher = textBox3.Text;
        book.Page = int.Parse(textBox4.Text);
        // 그리드 갱신, Save()
    }
    catch (Exception exception) { MessageBox.Show("존재하지 않는 도서입니다."); }
};

button3.Click += (sender, e) =>          // 삭제: Single로 찾아 Remove
{
    try
    {
        Book book = DataManager.Books.Single((x) => x.Isbn == textBox1.Text);
        DataManager.Books.Remove(book);
        // 그리드 갱신, Save()
    }
    catch (Exception exception) { MessageBox.Show("존재하지 않는 도서입니다."); }
};
```
- Form3도 같은 구조. 키가 `Id`(int)라 `x.Id == int.Parse(textBox1.Text)`, 중복이면 "사용자 ID가 겹칩니다."
- 빈 `catch { }`로 예외를 삼키면 원인을 알 수 없으니, 실제로는 최소한 메시지라도 띄우는 게 좋음
