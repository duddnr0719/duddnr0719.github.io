> 제10장(컨볼루션 신경망 2)과 제11장(영상인식)에서는 CNN의 5가지 합성곱 변형 구조와 **수용 영역(Receptive Field)** 개념을 정리하고, 이를 **영상 인식(image recognition)** 문제에 적용하는 방법을 다룬다. **CIFAR-10** 데이터셋으로 CNN 분류 모델을 직접 구축 · 학습한 뒤, **가중치 저장 및 복원**과 **전이 학습(transfer learning)**으로 사전 훈련된 `ResNet50` 모델을 활용하는 흐름까지 이어진다.

### CNN의 확장과 수용 영역(Receptive Field)
- **도입 주제** = **CNN(VGG16)** · **CNN의 가중치 업데이트**
- **컨볼루션의 5가지 종류**
  - **Pointwise convolution (`1×1` conv)** = `1×1` 필터 기반으로 채널 간 정보를 결합하고 채널 수를 변경하는 연산
  - **Grouped convolution** = 입력 · 출력 채널을 여러 그룹으로 분할한 뒤, 각 그룹 내부에서만 합성곱 연산 수행
  - **Depthwise convolution** = 입력의 개별 채널마다 독립적인 공간 합성곱을 적용하는 연산
  - **Transposed convolution** = 일반 컨볼루션(`General convolution`)과 반대로 축소된 데이터를 원본 이미지로 복원하는 **up-sampling** 단계에서 주로 활용하는 연산
  - **Dilated convolution** = 필터가 참조하는 픽셀 사이에 간격을 부여해 동일한 입력 픽셀 수로 더 넓은 영역을 수용하는 연산
    - `dilation rate` = 커널 내부 픽셀 간 간격을 정의하는 값
    - `dilation rate` = `2`인 `3×3` 커널 → `9`개 파라미터만 사용하면서 `5×5` 커널과 동일한 **receptive field** 확보
- **수용 영역(Receptive Field)**
  - **정의** = 특정 뉴런 하나의 활성화에 관여하는 영역
  - **특성** = 수용 영역이 넓을수록 단일 뉴런이 이미지 내 더 넓은 영역을 반영 → **전역적인 특징** 포착에 유리하며, 필터 크기에 따라 범위가 달라짐
  - **계층 적층과 파라미터 비교** = `3×3` conv layer `2`개를 쌓으면 `5×5` conv layer `1`개와 동일한 수용 영역을 얻지만, 파라미터 수는 `5×5` conv layer `1`개 쪽이 더 많음

### 영상 인식의 개요와 신경망 구조
- **제11장 학습 목표**
  - 컨벌루션 신경망(CNN)을 활용한 **영상 인식(image recognition)** 수행
  - 모델 **가중치 저장 및 복원** 기법 습득
  - **전이 학습(transfer learning)** 개념 이해
- **영상 인식과 ILSVRC 벤치마크**
  - **영상 인식(image recognition)** = 이미지 속에 포함된 물체를 식별하거나 범주로 분류하는 작업
  - **ILSVRC (ImageNet Large Scale Visual Recognition Challenge, 2010~2017)**
    - 학습 이미지 `1,281,167`개 · 검증 이미지 `50,000`개 구성
    - 테스트 이미지 `100,000`개 포함 · `1,000`개 이미지 클래스 분류 과제로 신경망 성능 평가
- **전통적 접근과 CNN 기반 영상 인식**
  - **생물학적 착안** = CNN이 영상 인식에만 국한되지는 않으나, 생물체의 영상 처리 구조에서 착안해 고안됨
  - **전통적인 영상 인식 시스템** = 신경망 기반 방식과 구별되는 구조로, 단일 특징 또는 복수의 특징을 사용해 물체를 분류하며 **과잉 적합** 문제가 함께 다뤄짐
  - **영상 인식 신경망 구조** = 영상 처리에는 CNN이 적합하며, 전체 신경망 구조는 크게 `2`개 부분으로 나뉨
- **컴퓨터 시각 분야 응용 예** = **Classification** · **Semantic Segmentation** · **Object Detection**

### 예제: CIFAR-10 영상 분류하기
- **CIFAR-10 데이터셋 구성**
  - **개발** = CIFAR 연구소에서 `CIFAR-100` 데이터 세트와 함께 제작함
  - **규모 및 크기** = `10`개 부류의 `32×32` 소형 컬러 영상 `60,000`장으로 구성
  - **클래스 목록 (`0` ~ `9`)**:
    - `0: airplane` · `1: automobile` · `2: bird` · `3: cat` · `4: deer`
    - `5: dog` · `6: frog` · `7: horse` · `8: ship` · `9: truck`
- **데이터 적재 · 시각화 · 정규화**
  - `keras.datasets.cifar10.load_data()` 호출 → 훈련 세트(`X_train`, `y_train`)와 테스트 세트(`X_test`, `y_test`) 반환
  - `plt.figure()`, `plt.imshow(X_train[1])`, `plt.colorbar()`로 두 번째 영상(`truck`) 시각화 후 픽셀 값을 `255.0`으로 나누어 `0`~`1` 범위로 정규화
- **CNN 분류 모델 구축 및 학습 코드**
```python
import numpy as np
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import Sequential
from tensorflow.keras.layers import *

# CIFAR-10 데이터 세트 적재
(X_train, y_train), (X_test, y_test) = keras.datasets.cifar10.load_data()

# 두 번째 영상(트럭) 시각화 및 [0, 1] 정규화
plt.figure()
plt.imshow(X_train[1])
plt.colorbar()

X_train = X_train / 255.0
X_test = X_test / 255.0

# 순차 모델 구성
model = Sequential()
model.add(Conv2D(64, activation='relu', kernel_size=(3, 3)))
model.add(MaxPooling2D(pool_size=(2, 2)))
model.add(Conv2D(32, activation='relu', kernel_size=(3, 3)))
model.add(Flatten(input_shape=(32, 32, 3)))
model.add(Dense(80, activation='relu'))
model.add(Dense(10, activation='softmax'))

# 모델 컴파일 및 훈련
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy'],
)
history = model.fit(X_train, y_train, epochs=10, verbose=1, validation_split=0.3)
```
- **모델 구성 요소 요약**
  - **계층 구성**:
    - `64`개 `3×3` `Conv2D`(`relu`) → `2×2` `MaxPooling2D` → `32`개 `3×3` `Conv2D`(`relu`)
    - `Flatten(input_shape=(32, 32, 3))` → `Dense(80, activation='relu')`
    - `Dense(10, activation='softmax')`
  - **컴파일 · 학습 설정** = `adam` 옵티마이저 · `sparse_categorical_crossentropy` 손실 함수 · `accuracy` 지표 · `epochs=10` · `validation_split=0.3`
- **실행 결과 및 손실 추이**
| Epoch | loss | accuracy | val_loss | val_accuracy |
|---|---|---|---|---|
| 1/10 | 1.4957 | 0.4596 | 1.2741 | 0.5512 |
| 2/10 | 1.1695 | 0.5858 | 1.1663 | 0.5869 |
| 9/10 | 0.5404 | 0.8100 | 1.1284 | 0.6453 |
| 10/10 | 0.4703 | 0.8339 | 1.2012 | 0.6419 |
  - 훈련 손실은 `1.4957`에서 `0.4703`으로 꾸준히 감소하고 훈련 정확도는 `0.4596`에서 `0.8339`까지 상승함
  - 반면 검증 손실(`val_loss`)은 Epoch `9`(`1.1284`) 이후 Epoch `10`에서 `1.2012`로 다시 증가했고, `val_accuracy`도 `0.6453` → `0.6419`로 소폭 하락함
- **손실 그래프 시각화 및 테스트 예측**
```python
# 손실 곡선 시각화
plt.plot(history.history['loss'])
plt.plot(history.history['val_loss'])
plt.title('loss')
plt.ylabel('loss')
plt.xlabel('epoch')
plt.legend(['loss', 'val_loss'], loc='lower right')
plt.show()

# 테스트 영상 예측
plt.figure()
plt.imshow(X_test[0])
y_pred = model.predict(X_test)
print("정답=", y_test[0])
print("예측값=", y_pred[0])
```
  - 테스트 첫 번째 영상 `X_test[0]`의 정답은 `[3]`(`cat`)이며, 예측 벡터 `y_pred[0]`에서도 인덱스 `3`의 값이 `9.9997449e-01`로 가장 높게 산출됨

### 데이터 증대와 가중치 저장 · 복원
- **데이터 증대 (Data Augmentation)**
  - **정의** = 보유 데이터가 제한적일 때 원본을 여러 형태로 변형해 학습 표본을 늘리는 기법
- **가중치 저장 및 복원의 목적**
  - **예측 재사용** = 학습된 모델 가중치를 저장해 두었다가 필요 시 복원해 즉시 추론 수행
  - **학습 재개** = 중단된 지점부터 훈련을 이어갈 수 있도록 옵티마이저 상태까지 함께 보존 · 복원
- **저장 · 복원 방식 및 저장 정보**
  - **저장 · 복원 명령** = `model.save('mymodel')` · `model = load_model('mymodel')`
  - **저장 항목** = 모델 아키텍처 및 구성 · 학습된 가중치 값 · 모델 컴파일 정보 · 옵티마이저 및 현재 상태(중단 시점 재훈련용)
  - **저장 형식** = `TensorFlow SavedModel` 형식 · 이전 `Keras H5` 형식
- **예제: 함수형 API 모델 저장 및 이어서 재학습**
```python
import numpy as np
import tensorflow as tf

# 난수로 훈련 예제 생성
test_input = np.random.random((128, 32))
test_target = np.random.random((128, 1))

# 함수형 API로 입력 32, 출력 1 노드인 신경망 구축
inputs = tf.keras.Input(shape=(32,))
outputs = tf.keras.layers.Dense(1)(inputs)
model = tf.keras.Model(inputs, outputs)
model.compile(optimizer="adam", loss="mean_squared_error")

# 3 에포크 훈련 후 저장
model.fit(test_input, test_target, epochs=3)
model.save("my_model")

# 저장된 모델을 복원해 다시 3 에포크 학습
saved_model = tf.keras.models.load_model("my_model")
saved_model.fit(test_input, test_target, epochs=3)
```
  - 첫 `3` 에포크 동안 손실이 `0.7929` → `0.7068` → `0.6226`으로 감소한 뒤 `my_model`에 저장됨
  - 모델 복원 후 다시 `3` 에포크를 실행하면 `0.5518` → `0.4866` → `0.4354`로 이어서 손실이 감소함

### 전이 학습과 사전 훈련된 모델 활용
- **전이 학습 (Transfer Learning)의 배경과 개념**
  - **배경** = 딥러닝은 `Object detection` · `image classification/segmentation` 분야에서 높은 성능을 보이나 대규모 데이터셋을 요구함
  - **과제와 해법** = 데이터가 없는 새로운 작업에 대한 대안으로 **전이 학습(transfer learning)**을 도입함
  - **정의** = 기존 문제에 대해 학습된 신경망 모델과 가중치를 새로운 문제에 적용해 활용하는 기법
- **사전 훈련된 신경망 모델 (Keras Applications)**
  - **케라스 애플리케이션(keras applications)** = 케라스에서 기본 제공하는 사전 훈련 딥러닝 모델 모음
  - **활용 방향** = 사전 훈련된 모델을 불러온 뒤 대상 프로젝트 목적에 맞게 재정의해 사용함
- **예제 #1: `ResNet50`으로 이미지 추론하기**
```python
from tensorflow.keras.applications.resnet50 import ResNet50
from tensorflow.keras.preprocessing import image
from tensorflow.keras.applications.resnet50 import preprocess_input, decode_predictions
import numpy as np

model = ResNet50(weights='imagenet')

img_path = 'dog.jpg'
img = image.load_img(img_path, target_size=(224, 224))  # 영상 크기 변경 및 적재
x = image.img_to_array(img)                              # 넘파이 배열 변환
x = np.expand_dims(x, axis=0)                            # 배치 차원 추가
x = preprocess_input(x)                                  # ResNet50 전처리 적용

preds = model.predict(x)
print('예측:', decode_predictions(preds, top=3)[0])
```
  - `weights='imagenet'` 설정으로 ImageNet으로 사전 학습된 `ResNet50` 가중치를 적재함
  - 입력 이미지를 `224×224` 크기로 불러온 뒤 배치 차원을 추가하고 `preprocess_input` 전처리를 거쳐 추론함
  - `decode_predictions(preds, top=3)` 결과로 `Samoyed` (`0.9557966`) · `white_wolf` (`0.01857086`) · `Pomeranian` (`0.00947881`)이 출력됨

### 핵심 요약
- **확장된 컨볼루션 연산** = `1×1` 필터로 채널을 다루는 Pointwise · 그룹별 연산을 수행하는 Grouped · 채널 독립 공간 합성곱인 Depthwise · up-sampling용 Transposed · 필터 간격을 넓히는 Dilated convolution으로 목적에 맞게 구조를 변형함
- **수용 영역(Receptive Field)** = 특정 뉴런 하나의 활성화에 관여하는 영역으로, `3×3` conv `2`개는 `5×5` conv `1`개와 수용 영역이 같지만 파라미터 수는 더 적게 사용함
- **CIFAR-10 CNN 분류** = `32×32` 컬러 이미지 `60,000`개(`10`개 부류)를 `0`~`1` 범위로 정규화해 `Conv2D` · `MaxPooling2D` · `Flatten` · `Dense` 구조로 학습하고 손실 곡선과 예측 결과를 확인함
- **가중치 저장 · 복원과 전이 학습** = `model.save`와 `load_model`로 모델 구조 · 가중치 · 컴파일 및 옵티마이저 상태를 보존하며, 데이터가 없는 새로운 작업에서는 `ResNet50` 같은 사전 훈련 모델을 활용하는 **전이 학습**을 적용함
