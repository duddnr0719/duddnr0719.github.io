# 배열
: 동일한 타입의 데이터를 한 번에 여러 개 만들 때 사용되는 기본적인 자료형. 기본이 되는 중요한 자료형으로서 많은 자료 구조들이 배열을 사용하여 구현된다.
```
int list1, list2, list3, list4, list5, list 6;
int list[6];
```
이처럼 6개의 정수를 저장할 공간이 필요한 경우, 배열이 없다면 첫 번째 줄처럼 6개의 정수형의 변수를 선언해야 하지만, 배열을 사용하면 두 번째 줄처럼 선언을 하면 된다.
## 배열 ADT
```
객체 : <인덱스, 값> 쌍의 집합
연산:
- create(size) ::= size개의 요소를 저장할 수 있는 배열 생성
- get(A,i) ::= 배열 A의 i번째 요소 반환
- set(A, i, v) ::= 배열 A의 i번째 위치에 값 v 저장
```
→ 배열이 기본적으로 구현되지 않는다면 프로그래머가 이를 직접 구현해야 함.
# 구조체
: 다양한 타입의 데이터를 한 번에 여러 개 만들 때 사용되는 자료형.
```c
struct 구조체이름 { // 구조체 선언
	항목1;
	항목2;
	...
};

int main() {
	struct 구조체이름 구조체변수; // 구조체 변수 생성
}
```
# 포인터
: 다른 변수의 주소를 가지고 있는 변수.
모든 변수는 메모리 공간에 저장되고 메모리의 각 바이트에는 주소가 매겨져 있다. 이 주소가 포인터에 저장된다. 모든 변수는 주소를 가지고 있다.
## 포인터 연산자
- & 연산자 - 주소 연산자
  → 변수의 주소를 추출하는 연산자. 포인터 p가 특정한 변수를 가리키게 하려면 변수의 주소를 &연산자로 추출하여서 p에 대입한다.
```
int a;   // 정수형 변수
p = &a;  // 변수의 주소를 포인터에 저장
```
- * 연산자 - 간접참조 연산자(역참조 연산자)
  → 포인터가 가리키는 장소에 값을 저장하는 연산자이다.
```
*p = 200;    // p가 가리키는 장소에 200을 저장
```
→ 위의 예제에서는 *p와 a가 동일한 메모리 위치를 참조한다. *p, a는 전적으로 동일하다. 즉 값만 같은 것이 아니고 동일한 실제적인 객체를 가리키기 때문에 *p의 값을 변경하면 a의 값도 변경된다.
### 함수 매개변수로 포인터 사용하기
포인터는 함수의 매개변수로 전달될 수 있는데, 매개변수로 전달되면 그 포인터를 이용하여 함수 안에서 외부 변수의 값을 변경할 수 있다.
```c
#include <stdio.h>

void swap(int *px, *py) {
	int tmp;
	tmp = *px;
	*px = *py;
	*py = tmp;
}

int main(void) {
	int a = 1, b = 2;
	swap(&a,&b);          // a=2, b=1로 변경
	return 0;
}
```
### 배열과 포인터
매개변수로 배열이 전달되면 함수 안에서 배열의 내용을 변경할 수 있는데, 그 이유는 배열의 이름이 배열의 시작위치를 가리키는 포인터이기 때문이다.

# 동적 메모리 할당
: 필요한 만큼의 메모리를 운영체제로부터 할당 받아서 사용하고, 사용이 끝나면 시스템에 메모리를 반납하는 기능.
일반적인 배열은 크기가 선언할 때 크기가 고정된다. → 이 고정된 크기 때문에 많은 문제가 발생한다. (프로그램을 작성할 때는 얼마나 많은 입력이 있을지 알 수 없음.)
처음 결정된 크기보다 더 큰 입력이 들어오면 처리하지 못하여 오류가 발생할 것이고, 더 작은 입력이 들어온다면 남은 메모리 공간이 낭비가 된다. → 이를 해결하기 위하여 동적 메모리 할당을 사용한다.
### heap
: 운영체제가 사용되지 않는 메모리 공간을 모아놓은 곳. → 필요한 만큼만 할당을 받고 또 필요한 때에 사용하고 반납하기 때문에 메모리를 매우 효율적으로 사용할 수 있다.
### 동적 메모리 할당 예시 코드
```
int *p;
p = (int *)malloc(sizeof(int));      // 1. 동적 메모리 할당
*p = 1000;                           // 2. 동적 메모리 사용
free(p);                             // 3. 동적 메모리 반납
```
1. 동적 메모리 할당
: malloc() 함수는 size바이트 만큼의 메모리 블록을 할당하는 역할을 한다. 동적 메모리 블럭의 시작 주소를 반환하고 그 타입은 (void *) 이므로 적절한 포인터롤 형변환을 해야한다. 이때, 메모리 확보가 불가능하면 NULL값을 반환한다. sizeof 키워드는 변수나 타입의 크기(바이트)를 숫자로 반환한다.
1. 동적 메모리 사용
: 동적 메모리는 포인터로만 사용할 수 있다. *p = 1000; 문장을 실행하면 p가 가리키는 장소에 1000이 저장된다.
1. 동적 메모리 반납
: free() 함수는 할당된 메모리 블럭을 운영체제에게 반환한다. 여기서 주의할 점은 malloc()함수가 반환했던 포인터 값을 잊어버리면 안 되는데, 그 이유는 포인터 값을 잊어버리면 동적 메모리를 반환할 수 없기 때문이다. malloc()함수는 메모리가 부족하여 NULL값을 반환하기 때문에 항상 반환값이 NULL인지 검사해야 한다.
## 구조체와 포인터
구조체에 대한 포인터를 선언하고 포인터를 통하여 구조체 멤버에 접근할 수 있다. 이때 주의할 것은 포인터를 통하여 구조체의 멤버에 접근하는 편리한 표기법 “→”이다.
ps가 구조체를 가리키는 포인터라고 할 때, (*ps).i 보다 ps→i라고 쓰는 것이 더 편리하다.
자료구조에서 구조체에 대한 포인터도 자주 함수의 매개변수로 전달되는데, 이 경우(구조체를 함수로 전달) 구조체가 함수로 복사되어 전달되기 때문에, 큰 구조체의 경우 구조체 포인터를 전달하는 것이 좋다.
