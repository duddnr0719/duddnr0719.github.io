## 자바 스크립트
- 동적인 웹페이지를 작성하기 위하여 사용되는 언어
- 웹의 표준 프로그래밍 언어
- 모든 웹 브라우저들은 자바 스크립트를 지원

### 자바 스크립트 특징
- 인터프리트 언어
- 동적 타이핑
- 구조적 프로그래밍 지원 (함수 사용)
- 객체 기반 → 자바 스크립트는 객체 지향 언어이다.
- 함수형 프로그래밍 지원 → 자바 스크립트에서 함수는 일급객체이다. ⇒ 함수는 그 자체로 객체이다. 람다식도 사용할 수 있다.

### 자바 스크립트의 용도
- HTML 콘텐츠를 동적으로 변경할 수 있다.
- 이벤트에 반응하는 동작을 구현할 수 있다.
- HTML 요소들의 속성을 동적으로 변경할 수 있다. ⇒ 색상과 같은 요소들의 스타일을 변경할 수 있다.
- HTML 요소를 표시하거나 숨길 수 있다.
- 사용자가 입력한 값들을 검증하는 작업을 할 수 있다.
- 게임이나 애니메이션과 같은 상호대화적인 콘텐츠를 구현할 수 있다.

## 자바 스크립트의 위치
- 내부 자바 스크립트 → head 태그 안에 \<script\> 태그를 사용하여 정의한다.
- 외부 자바 스크립트 → 외부에 파일을 생성하고(a.js) head 태그 안에 \<script src=”a.js”\> 를 사용하여 불러온다.
- 인라인 자바 스크립트 → 속성안에 정의한다.

### 주석문
- // : 한 줄짜리 주석문을 적을 때 사용
- /\* … \*/ : 여러 줄짜리 주석문을 적을 때 사용

### 변수
- var 
- let → 사용 권장
- const : 상수 선언하는 키워드 → 개발자가 변경할 필요가 없는 객체는 const로 정의하는 것이 좋다.

### 데이터 타입
- 수치형 : 정수, 실수
- 문자열 : 문자들이 연결된 것을 의미(텍스트)
- 부울형 : true or false
- 객체형 : 객체를 나타내는 타입
- undefined : 변수는 선언되었지만 아직 값이 정해지지 않은 상태를 나타냄

### 일치 연산자
- === : 피연산자의 값과 데이터 타입이 모두 일치할 때 참을 반환
- !== : 값이 다르거나 데이터 타입이 다르면 참을 반환
