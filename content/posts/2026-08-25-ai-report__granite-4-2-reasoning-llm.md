> IBM이 공개한 오픈 추론 모델로, 비동기 GRPO와 다단계 환경 커리큘럼을 결합해 도구 사용과 코딩 에이전트 능력을 학습시킴 !

# 개요
- 무엇 : IBM(Granite Team)이 2026.08.25 공개한 dense 추론 언어 모델 제품군
- 한 줄 정의 : Granite 4.2는 15T 토큰 사전학습 베이스 모델 위에서 다단계 비동기 GRPO를 거쳐 생각 모드 제어와 샌드박스 에이전트 행동을 학습한 오픈 LLM이다.
- 원문 : [Granite 4.2 LLMs: How They're Built](https://huggingface.co/blog/ibm-granite/granite-4-2)

# 그래서 도대체 뭔데 ?
- 모델 크기는 3B · 8B · 30B 3종으로 모두 단일 가중치(dense) 구조임.
- 생각(thinking) 모드를 켜고 끄거나, 쉬운 질문에 토큰 예산을 아끼는 저강도(low-effort) 모드를 지원함.
- 8B와 30B 모델은 실제 컨테이너 환경에서 도구 호출 · 터미널 제어 · 웹 검색을 수행하는 에이전틱 강화학습을 거침.
- Apache 2.0 라이선스로 공개되어 연구와 상업적 활용이 자유로움.
	- 💡 비동기 GRPO : 별도 가치 네트워크 없이 그룹 내 다른 답변들의 보상 평균과 비교하며, 생성 워커와 학습기를 분리해 지연 없이 파라미터를 갱신하는 강화학습 기법
	- 💡 Low-effort 모드 : 단순 질의에서 추론 길이를 짧게 제한해 토큰 소모를 줄이는 실행 방식

# 어떻게 동작하나 ?
1. 베이스 모델 사전학습과 5단계 확장
	- 15T 토큰 규모의 데이터셋으로 5단계에 걸쳐 학습을 진행함.
	- 마지막 5단계에서 롱컨텍스트 학습(LCE)을 적용해 최대 512K 컨텍스트를 확보함.
	→ 긴 문맥에서도 대규모 코드와 지시를 다룰 수 있는 컨텍스트 길이를 확보함.

2. 에이전트 비중을 높인 지도 미세조정(SFT)
	- 7.2M 샘플(약 100B 토큰, 학습 토큰 65B)로 SFT를 수행함.
	- 전체 데이터 중 에이전트 데이터 비중이 31.6%이며, 이 중 소프트웨어 엔지니어링이 69%를 차지함.
	- 30B 모델은 소프트웨어 엔지니어링과 다중 턴 도구 상호작용 궤적을 1 에폭 추가 학습(Phase 2)함.
	→ 일반 대화와 다중 턴 도구 호출 궤적을 표준 포맷으로 익힘.

3. 다단계 비동기 GRPO 강화학습
	- 단일 RL이 아니라 검증 가능 보상(RLVR) → 능력 부스터 → 에이전틱 RL → RLHF 순서로 웜스타트 체인을 이어감.
	- 생성 엔진(vLLM)과 학습 엔진(Megatron-Core)을 분리해 워커가 쉬지 않고 롤아웃을 수집함.
	- 워커의 정책 지연은 최대 1개 업데이트로 묶고, 남은 오차는 잘린 중요도 샘플링으로 보정함.
	→ 실제 샌드박스 테스트 통과 여부라는 희소 보상에서도 안정적으로 에이전트 정책을 수렴시킴.

# 기존이랑 뭐가 다른가 ?
- 이전 방식 :
	- 단일 RL 단계에서 추론과 도구 호출을 한꺼번에 학습시키거나 시뮬레이션 환경에 의존함.
	- 생성과 정책 업데이트가 동기 방식으로 맞물려 샌드박스 롤아웃 대기 시간 동안 GPU가 유휴 상태에 빠짐.
- 이번 방식 :
	- 수학 · 코딩 검증(RLVR)부터 터미널 · 리포지토리 제어까지 독립된 환경 단계를 순차적으로 통과함.
	- 비동기 GRPO로 생성단과 학습단을 분리해 대규모 샌드박스 환경에서도 장비 유휴 없이 학습을 유지함.
→ 기초 추론 능력을 먼저 검증 가능한 보상으로 다진 뒤 실제 실행 환경의 희소 보상으로 에이전트 행동을 덧붙였기 때문.

# 주의할 점 / 한계
- 3B 모델은 에이전틱 RL(SWE · Terminal · Search) 단계가 학습에서 제외되어 코딩 에이전트 평가가 없음(NA).
- 터미널 에이전트 단계는 최대 64턴에 달하는 환경 상호작용 롤아웃을 거치므로 높은 연산량과 긴 컨텍스트 윈도우가 요구됨.
- 비동기 생성 루프 특성상 롤아웃 도중 정책이 갱신되어 하나의 궤적에 두 정책 버전이 섞일 수 있으며, 최대 1개 업데이트의 정책 드리프트와 오프폴리시(off-policy) 샘플이 발생함.
- FP4 양자화(NVFP4 · MXFP4) 캘리브레이션은 2K 샘플 및 최대 2K 컨텍스트 조건에서 수행됨.

# 정리
- 검증 가능 보상과 실제 샌드박스 환경을 분리해 순차적으로 주입하는 다단계 비동기 GRPO 훈련 체계를 구성함.
- 128K(131072) 컨텍스트와 생각 모드 제어를 지원하며, OpenHands · OpenCode 등 코딩 에이전트 하네스 연동과 GGUF 경량 배포 환경을 갖춘 기업 및 연구 환경에 적합함.
