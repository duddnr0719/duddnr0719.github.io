> 정답 없이 비슷한 것끼리 묶으면 군집화(k-means, 비지도), 정답이 있는 데이터로 새 데이터의 그룹을 맞히면 분류(KNN·의사결정나무, 지도). 거리 기반이라 변수 범위를 맞추는 정규화가 필요하고, 성능은 k-fold 교차검증 평균으로 본다.
### 군집화 vs 분류
| | 군집화 (clustering) | 분류 (classification) |
|---|---|---|
| 학습 | 비지도 | 지도 |
| 하는 일 | 유사한 데이터끼리 묶기 | 알려진 그룹 중 새 데이터가 어디 속할지 예측 |
| 대표 | k-means | 로지스틱 회귀, 신경망, KNN, 의사결정나무 |
| 예 | 고객 세분화 | 정상인 / 환자 판정 |
- 지도학습: 문제와 답을 함께 학습 (분류, 회귀) / 비지도: 답 없이 패턴·구조 발견 (군집, 변환, 연관) / 강화학습: 에이전트가 환경에서 보상이 최대가 되는 행동을 시행착오로 학습
### k-means
- k개 군집, 각 군집의 **평균(중심)** 을 이용해 묶음
1. 데이터 준비
1. 임의의 중심점 k개 생성
1. 각 점을 가장 가까운 중심에 배정
1. 군집별로 중심(평균)을 다시 계산해 이동
1. 3~4 반복
1. 중심이 더 이상 움직이지 않으면 종료
- 거리
  - **유클리드**: d(p, q) = √Σ(pᵢ − qᵢ)²
  - **민코프스키** 계열: 유클리드(직선), 맨해튼(택시, Σ|pᵢ − qᵢ|), 체비쇼프(체스 킹, max|pᵢ − qᵢ|)
  - **마할라노비스**: 데이터의 분포(공분산)를 고려. (180cm, 80kg) ↔ (185cm, 85kg)은 흔한 변화라 가깝게, (180cm, 80kg) ↔ (180cm, 120kg)은 드문 변화라 멀게
- 한계
  - **k를 미리 정해야** 하고, 실제 군집 수와 다르면 엉뚱하게 묶임 (4개인데 k = 3, 5개인데 k = 8)
  - 초기 중심에 따라 **국소 최적**에 빠질 수 있음 → 여러 번 시작(`nstart`)
  - 둥근(구형) 군집을 가정 → 반달 모양처럼 휘어진 군집은 못 나눔 (밀도 기반 DBSCAN, 스펙트럴 군집 등이 대안)
```r
mydata <- iris[, 1:4]
fit <- kmeans(x = mydata, centers = 3)
fit
# K-means clustering with 3 clusters of sizes 62, 38, 50
# Cluster means: (5.90, 2.75, 4.39, 1.43) / (6.85, 3.07, 5.74, 2.07) / (5.01, 3.43, 1.46, 0.25)
# Within cluster SS: 39.82 23.88 15.15  (between_SS / total_SS = 88.4 %)
fit$cluster      # 각 데이터의 군집 번호
fit$centers      # 중심 좌표

library(cluster)
clusplot(mydata, fit$cluster, color = TRUE, shade = TRUE, labels = 2, lines = 0)
# 주성분 2개로 축소해 그림: "These two components explain 95.81 % of the point variability."
subset(mydata, fit$cluster == 2)
```
- 군집 **번호는 실행할 때마다 바뀜**(초기값이 랜덤) → `set.seed()`로 고정, 안정적 결과엔 `nstart = 25`
- 실제 품종과 비교하면 setosa 50개는 완벽히 한 군집, versicolor·virginica는 일부 섞임 (versicolor 48 + virginica 14 / versicolor 2 + virginica 36)
- 이 값 88.4%는 군집 간 거리가 전체 변동에서 차지하는 비율 → 클수록 잘 나뉜 것
### 정규화
- 키 180 vs 170, 시력 1.2 vs 0.9 → 거리 √(10² + 0.3²) = √(100 + 0.09) → 시력은 거의 반영 안 됨. **범위가 큰 변수가 거리를 지배**
- 모든 변수를 0~1로: **(x − min) / (max − min)** (예: (1, 2, 3) → (0, 0.5, 1), (10, 20, 30) → (0, 0.5, 1))
```r
std <- function(X) {
  return((X - min(X)) / (max(X) - min(X)))
}
mydata <- apply(iris[, 1:4], 2, std)
fit <- kmeans(x = mydata, centers = 3)
```
- 교재는 이걸 "표준화"라고 부르지만 엄밀히는 **최소-최대 정규화(min-max normalization)**. 통계에서 표준화는 (x − 평균) / 표준편차로 평균 0, 표준편차 1을 만드는 것 (R의 `scale()`)
### KNN (k-최근접 이웃)
- 유유상종. 그룹을 모르는 점 P에서 **가장 가까운 k개**를 찾아 **다수결**로 그룹 결정
  - 예: k = 7, 이웃이 A 4개, B 3개 → A
- 분류 = 판별분석. 예: 운동 시간 0.45, 일하는 시간 0.61인 사람은 환자? 정상?
- 장점: 단순, 분포 가정 없음, 훈련이 빠름(사실상 저장만)
- 단점: 모델이 없어 변수와 클래스의 관계를 해석하기 어려움, k 선택 필요, 예측할 때마다 **모든 훈련 데이터와 거리 계산** → 메모리·시간 큼
```r
library(class)
tr.idx <- c(1:25, 51:75, 101:125)     # 품종별 앞 25개씩 훈련용
ds.tr <- iris[tr.idx, 1:4];  ds.ts <- iris[-tr.idx, 1:4]
cl.tr <- factor(iris[tr.idx, 5]); cl.ts <- factor(iris[-tr.idx, 5])

pred <- knn(ds.tr, ds.ts, cl.tr, k = 3, prob = TRUE)   # prob: 다수결 비율 (2/3 = 0.667 등)
mean(pred == cl.ts)        # 0.9333333
table(pred, cl.ts)
#             setosa versicolor virginica
# setosa          25          0         0
# versicolor       0         23         3
# virginica        0          2        22
```
- k 고르기: 데이터가 100개면 10 미만, 보통 1~7을 차례로 실험해 정확도가 가장 높은 k. 동수면 `knn()`은 **무작위로** 하나 선택 → 그래서 실행마다 정확도가 0.92~0.93으로 조금 달라질 수 있음 (R 4.3에서 0.92가 나오기도 함). 동수를 피하려면 k를 홀수로
- KNN도 거리 기반이라 변수 범위가 다르면 정규화 필요
### k-fold 교차검증
- 훈련/테스트를 **어떻게 나누느냐에 따라 성능이 달라짐** → 데이터를 k등분해 각 조각을 한 번씩 테스트로 쓰고 나머지로 학습, k개 정확도의 **평균**
```r
library(cvTools)
k <- 10
folds <- cvFolds(nrow(iris), K = k)
acc <- c()
for (i in 1:k) {
  ts.idx <- folds$which == i
  ds.tr <- iris[!ts.idx, 1:4];  ds.ts <- iris[ts.idx, 1:4]
  cl.tr <- factor(iris[!ts.idx, 5]);  cl.ts <- factor(iris[ts.idx, 5])
  pred <- knn(ds.tr, ds.ts, cl.tr, k = 5)
  acc[i] <- mean(pred == cl.ts)
}
acc          # 0.933 1.000 0.933 0.933 1.000 1.000 0.933 1.000 1.000 0.933
mean(acc)    # 0.9666667
```
- 주의: `folds$which == i`는 TRUE/FALSE 벡터라서 교재처럼 `iris[-ts.idx, ]`로 쓰면 −1/0 숫자로 바뀌어 **1번 행만 빠진 149행이 훈련 데이터**가 됨 (R로 확인). 테스트 데이터가 훈련에 그대로 섞이니 정확도가 부풀려짐. 논리 벡터는 `!ts.idx`로 부정해야 함 (위 코드처럼). 또는 `ts.idx <- which(folds$which == i)`로 번호를 만들면 `-ts.idx`가 맞게 동작
- 폴드 분할도 랜덤이라 `set.seed()`로 고정해야 재현됨
### 의사결정나무
- 입력값 조합에 대한 **규칙(if-then)** 을 나무 모양으로 만들어 예측. 예측력은 다른 기법보다 대체로 낮지만 **해석이 쉬움**
  - 분류나무(출력이 범주), 회귀나무(출력이 연속)
- 절차: ① 성장(최대 크기 나무) → ② 가지치기(불필요한 가지 제거, 과적합 방지) → ③ 최적 나무 선택 → ④ 해석·예측
- 예: "날개가 있나? → 날 수 있나? → 독수리 / 펭귄", "지느러미가 있나? → 돌고래 / 곰"
- 예: 직업이 고용이면 나이 < 43 → 예, ≥ 43 → 아니오 / 자영 → 예 / 무직이면 강남 → 예, 강북 → 아니오
- iris (훈련 데이터로 만든 교재 그림): Petal.Length < 2.45 → setosa(35/35), 아니면 Petal.Length < 4.75 → versicolor(31/32), 아니면 virginica(34/38)
```r
library(rpart)
tree <- rpart(Species ~ ., data = iris)
tree
# Petal.Length < 2.45  → setosa (50개, 오분류 0)
# Petal.Width  < 1.75  → versicolor (54개 중 5개 오분류)
# Petal.Width >= 1.75  → virginica (46개 중 1개 오분류)
```
  - 전체 150개로 만들면 두 번째 분할 기준이 Petal.Width < 1.75로 바뀜 → 어떤 데이터로 학습했는지에 따라 규칙이 달라지는 게 나무의 특징(불안정성). 랜덤 포레스트는 나무 여러 개를 평균해 이를 보완
