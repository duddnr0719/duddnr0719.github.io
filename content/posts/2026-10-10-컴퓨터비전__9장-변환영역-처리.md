> 영상을 "밝기가 얼마나 빨리 변하나"(공간 주파수)로 바꿔 보는 처리. 푸리에 변환(FFT)으로 주파수 영역에 가서 저주파만 남기면 블러, 고주파만 남기면 에지가 되고, 경계를 완만하게 깎으면(가우시안·버터워스) 링잉이 사라진다. DCT는 실수만 쓰고 에너지가 저주파에 몰려 JPEG 압축의 핵심이다.
### 주파수와 공간 주파수
- 주파수(Hz) = 1초에 진동하는 횟수 (1Hz, 2Hz, 10Hz, 100Hz의 sin 파형을 그리면 촘촘해짐)
```python
t = np.arange(0, 1, 0.001)
for h in [1, 2, 10, 100]:
    plt.plot(t, np.sin(2 * np.pi * h * t))
```
- **공간 주파수** = 화소 거리에 따라 밝기가 얼마나 빨리 변하나
  - 저주파: 천천히 변하는 곳 (하늘, 벽, 배경) → 영상 에너지 대부분
  - 고주파: 급하게 변하는 곳 (에지, 경계, 잡음)
  - 저주파만 남기기 = 블러링, 고주파 강조 = 샤프닝
- 오일러 공식 e^(jθ) = cos θ + j sin θ (θ = π면 e^(iπ) + 1 = 0)
### 이산 푸리에 변환 (DFT)
- 주기 신호는 여러 사인·코사인(**기저 함수**)의 합 → 각 기저에 곱해지는 값(**주파수 계수**)을 찾는 것이 변환, 계수로 원 신호를 다시 합치는 것이 역변환
- 1차원 (N개 샘플, n: 위치, k: 주파수 번호)
  - DFT: G(k) = Σₙ g[n] · e^(−j2πkn/N)
  - IDFT: g[n] = (1/N) Σₖ G(k) · e^(j2πkn/N)
- 2차원: 가로로 1D 변환 후 세로로 1D 변환 (분리 가능)
  - G(k, l) = Σₘ Σₙ g[n, m] · e^(−j2π(kn/N + lm/M)), 역변환은 1/(NM)
- 결과는 **복소수** → 실수부/허수부로 나눠 계산하거나 2채널로 저장
- 예: 50Hz(0.6) + 120Hz(0.9) + 260Hz(0.2)를 1000Hz로 1초 샘플링
```python
def dft(g):
    N = len(g)
    return np.array([sum(g[n] * np.exp(-2j * np.pi * k * n / N) for n in range(N)) for k in range(N)])
```
  - |G| × dt를 그리면 50, 120, 260 위치에 0.3, 0.45, 0.1 → **진폭의 절반**이 나타남 (NumPy로 확인)
  - 같은 크기가 **950, 880, 740**에도 거울처럼 나타남: 실수 신호의 스펙트럼은 N/2(=500Hz, 나이퀴스트)를 기준으로 대칭이라 실제로 의미 있는 건 앞쪽 절반
  - 샘플링 주파수는 최고 주파수의 **2배보다 커야** 함(나이퀴스트). 여기선 1000 > 2 × 260이라 OK
  - 직접 구현은 O(N²)이라 1000개만 돼도 느림 → FFT
### 스펙트럼 시각화
- **크기(스펙트럼)** |G| = √(Re² + Im²) — 그 주파수 성분의 세기 / **위상** θ = tan⁻¹(Im/Re)
- 저주파(특히 (0, 0) = 평균 밝기)가 압도적으로 커서 그대로 정규화하면 한 점만 하얗게 → **log(1 + |G|)** 로 압축해 표시
```python
def calc_spectrum(complex):
    if complex.ndim == 2: dst = abs(complex)                                   # NumPy 복소수
    else: dst = cv2.magnitude(complex[:, :, 0], complex[:, :, 1])              # OpenCV 2채널
    dst = cv2.log(dst + 1)
    cv2.normalize(dst, dst, 0, 255, cv2.NORM_MINMAX)
    return cv2.convertScaleAbs(dst)
```
- DFT 결과는 저주파가 **네 모서리**, 고주파가 가운데 → **시프트**(1↔3사분면, 2↔4사분면 교환)로 저주파를 중앙에 모음: `np.fft.fftshift`
### 고속 푸리에 변환 (FFT)
- 삼각함수의 주기성을 이용해 짝수·홀수 번째로 계속 반씩 나눠(분할 정복) 계산 → O(N²) → **O(N log N)**
  - **스크램블**: 짝/홀 분리를 반복해 원소 순서 재배치
  - **버터플라이**: 이웃한 두 값을 G_even = g_even + g_odd·W, G_odd = g_even − g_odd·W로 합치며 올라감 (W = 회전 인자)
- 기본 FFT는 길이가 **2의 거듭제곱**이어야 함 → 부족한 부분을 0으로 채우는 **영삽입(zero-padding)**
```python
def zeropadding(img):
    h, w = img.shape[:2]
    m = 1 << int(np.ceil(np.log2(h)))     # 300 → 512, 240 → 256
    n = 1 << int(np.ceil(np.log2(w)))
    dst = np.zeros((m, n), img.dtype)
    dst[:h, :w] = img
    return dst
```
  - 2D FFT = 행마다 1D FFT → 전치 → 다시 행마다 1D FFT → 전치
  - 실제 라이브러리는 2의 거듭제곱이 아니어도 동작: `np.fft.fft2(img)`, `cv2.dft(np.float32(img), flags=cv2.DFT_COMPLEX_OUTPUT)`. OpenCV는 2·3·5의 곱 크기에서 빠르며 `cv2.getOptimalDFTSize(300)` = 300
  - 역변환: `np.fft.ifft2(F).real`, `cv2.idft(F, flags=cv2.DFT_SCALE)[:, :, 0]` (DFT_SCALE = 1/N 나누기)
### 주파수 영역 필터링
- FFT → 시프트 → **필터 행렬과 원소별 곱** → 역시프트 → IFFT → (영삽입 부분 잘라내기)
  - 공간 영역의 회선 = 주파수 영역의 곱셈 (큰 마스크일수록 주파수 쪽이 유리)
```python
dft = np.fft.fftshift(np.fft.fft2(image))
cy, cx = np.array(dft.shape) // 2
lowpass = np.zeros(dft.shape, np.float32)
cv2.circle(lowpass, (int(cx), int(cy)), 30, 1, -1)          # 반지름 30 안만 1
highpass = 1 - lowpass
low_img  = cv2.convertScaleAbs(np.fft.ifft2(np.fft.ifftshift(dft * lowpass)).real)    # 흐려짐
high_img = cv2.convertScaleAbs(np.fft.ifft2(np.fft.ifftshift(dft * highpass)).real)   # 에지만
```
  - OpenCV 2채널 결과에 원을 그릴 땐 `(1, 1)`처럼 두 채널 모두 값을 지정
- **이상적 필터의 문제**: 차단 경계에서 값이 뚝 끊겨 결과에 물결무늬(**링잉**)가 생김 → 경계를 완만하게
| 필터 | 식 (D = 중심에서의 거리, R = 차단 반지름) | 특징 |
|---|---|---|
| 이상적 | D ≤ R이면 1, 아니면 0 | 날카로움, 링잉 |
| 가우시안 | exp(−D² / 2R²) | 가장 부드러움, 링잉 없음 |
| 버터워스 | 1 / (1 + (D/R)^(2n)) | n이 크면 이상적 필터에, 작으면 가우시안에 가까움 (중간 성격) |
```python
y, x = np.mgrid[-cy:cy, -cx:cx]
D = np.sqrt(x ** 2 + y ** 2)
gauss  = np.exp(-(D ** 2) / (2 * 30 ** 2))
butter = 1 / (1 + (D / 30) ** (2 * 10))
```
  - 고주파 통과 버전은 1 − (저주파 필터)
### 이산 코사인 변환 (DCT)
- 1974년 라오(Rao) 등. DFT의 **실수(코사인) 부분만** 쓰는 직교 변환 → 복소수 계산이 없어 빠르고, 에너지가 **저주파(DC) 근처에 몰림** → 압축(JPEG, MPEG)
- F(k) = C(k) Σₙ g[n] cos((2n + 1)kπ / 2N), 역변환 g[n] = Σₖ C(k) F(k) cos((2n + 1)kπ / 2N)
  - C(0) = √(1/N) (DC 성분), C(k ≠ 0) = √(2/N) (AC 성분) — 기저 벡터의 길이(√N, √(N/2))로 나눠 정규화한 것
- 손 계산: g = [10, 20, 30, 40], N = 4
  - F(0) = 0.5 × (10 + 20 + 30 + 40) = **50** (평균 × √N)
  - F(1) = 0.7071 × [10 cos(π/8) + 20 cos(3π/8) + 30 cos(5π/8) + 40 cos(7π/8)] ≈ **−22.3**
  - `cv2.dct` 결과 [50, −22.30, 0, −1.59] → 뒤쪽 계수가 거의 0 = 에너지 집중 (직접 확인)
  - 부드러운 8×8 블록이면 왼쪽 위 2×2 계수에 에너지의 99.8%가 몰림 (직접 확인)
- 8×8 블록 필터링 (JPEG처럼 블록마다 DCT → 마스크 곱 → 역DCT)
| 필터 | 1로 둔 위치 | 결과 |
|---|---|---|
| DC Pass | [0, 0]만 | 블록 평균만 남아 모자이크 |
| High Pass | [0, 0]만 0 | 경계·디테일만 |
| Low Pass | 왼쪽 위 1/4 | 블러 |
| Vertical Pass | [0, 1:] (첫 행, 가로 방향 주파수) | **세로** 에지 강조 |
| Horizontal Pass | [1:, 0] (첫 열, 세로 방향 주파수) | **가로** 에지 강조 |
```python
for i in range(0, h, 8):
    for j in range(0, w, 8):
        block = cv2.dct(np.float32(image[i:i + 8, j:j + 8]))
        dst[i:i + 8, j:j + 8] = cv2.dct(block * mask, flags=cv2.DCT_INVERSE)
```
  - `cv2.dct`는 짝수 크기만 받음 → 영상 크기가 8의 배수가 아니면 패딩
