> 영상 처리 = 목적을 위해 화소에 수학적 연산을 가하는 것. 영상 f(x, y) = 조명 i(x, y) × 반사 r(x, y)이고, 카메라는 이를 표본화(공간 해상도 M×N)와 양자화(밝기 단계 2ᵏ)로 디지털화한다. 실습 도구는 Python + OpenCV.
### 영상 처리란
- **화소(pixel)**: 영상의 기본 단위. 영상 = 밝기·색이 다른 일정한 수의 화소 모임
- 영상 처리: 입력 영상을 **어떤 목적을 위해** 화소에 **수학적 연산**을 가해 바꾸는 기술 (아날로그 / 디지털)
- 예: 모든 화소에 +100 → 밝아짐, −100 → 어두워짐
  - 8비트(0~255)라서 그냥 더하면 넘침 주의: NumPy `uint8`에서 200 + 100 = **44**(256으로 나눈 나머지), `cv2.add`는 **255에서 멈춤(포화)**
```python
import numpy as np, cv2
a = np.array([[100, 200, 250]], np.uint8)
print(a + 100)            # [[200  44  94]]  ← 넘쳐서 어두워짐
print(cv2.add(a, 100))    # [[200 255 255]]  ← 포화 연산
```
### 영상 처리 수준
| 수준 | 결과 | 예 |
|---|---|---|
| 저수준 (좁은 의미의 영상 처리) | 영상 | 획득, 향상, 복원, 변환, 압축 |
| 고수준 (컴퓨터 비전) | 영상의 특성·정보 | 분할, 표현, 인식 |

### 영상 형성
- **f(x, y) = i(x, y) · r(x, y)** — 영상 밝기 = 조명의 세기 × 물체의 반사 계수
- 광원 → 물체 반사 → 렌즈(광학계) → **CMOS 센서**(빛 → 아날로그 전기 신호) → **A/D 변환** → 디지털 영상
- 디지털화 두 단계
  - **표본화(sampling)**: 연속 공간에서 일정 간격으로 값을 취해 **M × N개 화소**로 → 공간 해상도
  - **양자화(quantization)**: 밝기를 유한한 비트의 **정수**로 → k비트면 2ᵏ단계 (8비트 = 256단계, 0~255)
  - 예: 128.54 → 8비트 정수로 표현 (슬라이드는 128. 버림이면 128, 반올림이면 129 — 방식에 따라 다름)
### 디지털 영상 표현과 처리
- M × N 2차원 배열 f(x, y), 원점 (0, 0)이 왼쪽 위
  - OpenCV(NumPy)에선 `img[행, 열]` = `img[y, x]` 순서라 좌표 (x, y)와 뒤집혀 있음에 주의
- 처리 = **g(x, y) = T[f(x, y)]** (T: 화소 처리, 영역 처리, 기하학 처리 등)
| 분류 | 작업 | OpenCV 함수 |
|---|---|---|
| 화소 처리 | 밝기·대비 / 이진화 | `cv2.convertScaleAbs`, `cv2.threshold` |
| 영역(필터) 처리 | 블러 / 엣지 / 모폴로지 | `cv2.GaussianBlur`, `cv2.Canny`, `cv2.erode`, `cv2.dilate` |
| 기하학 처리 | 크기 / 회전·이동 / 원근 | `cv2.resize`, `cv2.getRotationMatrix2D` + `cv2.warpAffine`, `cv2.getPerspectiveTransform` |
| 기타 | 히스토그램 평활화 / 채널 | `cv2.equalizeHist`, `cv2.split`, `cv2.merge` |
- 실습 환경: IDLE, PyCharm, Jupyter Notebook (`plt.imshow(image, cmap="gray")`)

### Python과 개발 환경
- 귀도 반 로섬, 1991. **인터프리터**(한 줄씩 해석·실행), 고급 언어, 플랫폼 독립, 객체지향, **동적 타입**. 이름은 BBC 코미디 "몬티 파이썬의 날아다니는 서커스"에서
- 설치: python.org → 설치 첫 화면에서 **Add Python to PATH** 체크
- IDLE: 기본 셸 + 에디터. File → New File → 저장(`hello.py`) → Run → Run Module(F5)
- **PyCharm** (JetBrains, IntelliJ 기반): 프로젝트별 인터프리터·패키지 환경, 디버거, 운영체제와 무관한 UI. Community(무료) / Professional(유료)
  - 인터프리터 연결: Settings → Project Interpreter → Add → System Interpreter(`python.exe`) 또는 New environment(**가상환경**, 프로젝트별 라이브러리 버전 독립)
  - 패키지: Settings → Project Interpreter → [+] → `opencv-python`, `matplotlib` 설치 (또는 터미널에서 `pip install opencv-python matplotlib`)
- OpenCV 동작 확인
```python
import numpy as np
import cv2

image = np.zeros((300, 400), np.uint8)   # 300행 × 400열, 8비트 흑백
image.fill(200)                          # 회색으로 채움 (image[:] = 200 과 같음)

cv2.imshow("Window title", image)
cv2.waitKey(0)                           # 키 입력까지 대기
cv2.destroyAllWindows()
```
### 복습 질문
- 디지털 영상이란? → 표본화·양자화를 거친 M × N개 화소(정수 밝기값)의 2차원 배열
- 영상 형성 과정은? → 조명 × 반사 → 렌즈 → 센서(빛 → 전기) → A/D 변환
- 해상도와 표본화·양자화의 관계는? → 표본화 간격이 공간 해상도(화소 수), 양자화 비트 수가 밝기 해상도(단계 수)
