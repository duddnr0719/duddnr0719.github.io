> 화소의 위치를 옮기는 처리. 출력 화소마다 "입력의 어디서 왔나"를 거꾸로 계산(역방향 사상)하고 소수 좌표는 보간으로 채운다. 이동·회전·크기는 2×3 어파인 행렬, 원근은 동차 좌표의 3×3 행렬 하나로 표현되고, OpenCV는 warpAffine/warpPerspective로 처리한다.
### 사상
- 화소 배치를 바꿀 때 입력 좌표 ↔ 출력 좌표의 대응을 찾는 것
| | 순방향 (x, y) → (x', y') | 역방향 (x', y') → (x, y) |
|---|---|---|
| 순회 | 입력 화소마다 목적지 계산 | **출력 화소마다** 출처 계산 |
| 문제 | **홀**(아무 값도 안 온 출력 화소), **오버랩**(여러 입력이 한 곳에) | 없음 (한 입력 화소가 여러 출력에 쓰일 수는 있음) |
| 사용 | | `cv2.resize`, `cv2.warpAffine`, `cv2.warpPerspective` |
### 크기 변경
- x' = x · ratioX, y' = y · ratioY, ratio = 목적 크기 / 원본 크기
- **크기 표기 순서 주의**: OpenCV 함수의 size는 **(너비, 높이)**, NumPy `shape`는 **(높이, 너비, 채널)** → `size[::-1]`로 뒤집어 맞춤
```python
def scaling(img, size):                       # 순방향 사상, 벡터화
    dst = np.zeros(size[::-1], img.dtype)
    ratioY, ratioX = np.divide(size[::-1], img.shape[:2])
    y, x = np.meshgrid(np.arange(img.shape[0]), np.arange(img.shape[1]), indexing='ij')
    dst[np.int32(y * ratioY), np.int32(x * ratioX)] = img[y, x]
    return dst
```
  - 벡터화 2.67 ms vs 이중 for 188.34 ms (슬라이드 측정)
  - 확대하면 값이 안 들어간 칸이 생겨 **검은 격자무늬(홀)** → 보간 필요
### 보간
- 역방향으로 계산한 입력 좌표는 보통 소수 → 그 위치의 값을 주변 화소로 추정
- **최근접 이웃**: y = y' / ratioY, x = x' / ratioX를 정수로 (가장 가까운 화소)
  - 빠르지만 크게 확대하면 **모자이크·계단 현상**
- **양선형(bilinear)**: 주변 4화소 A(좌상), B(우상), C(좌하), D(우하)로 선형 보간을 **두 번**
  - α = x − x₁ (가로 거리 비율), β = y − y₁ (세로)
  - M₁ = A + α(B − A), M₂ = C + α(D − C) — 위아래 줄에서 가로 보간
  - P = M₁ + β(M₂ − M₁) — 그 둘을 세로 보간
  - 예: A = 10, B = 20, C = 30, D = 40, α = 0.5, β = 0.25 → M₁ = 15, M₂ = 35, P = 20
```python
def bilinear_value(img, pt):
    x, y = np.int32(pt)
    x = min(x, img.shape[1] - 2); y = min(y, img.shape[0] - 2)   # 오른쪽·아래 끝 처리
    A, B, C, D = np.float32(img[y:y + 2, x:x + 2].flatten())
    alpha, beta = pt[0] - x, pt[1] - y
    M1 = A + alpha * (B - A)
    M2 = C + alpha * (D - C)
    return np.clip(M1 + beta * (M2 - M1), 0, 255)
```
  - 슬라이드 코드는 α에 y 쪽 거리(`pt[1] - y`), β에 x 쪽 거리를 넣고 P1↔P3(세로)로 먼저 보간하는데, 이름만 바뀌었을 뿐 세로 먼저·가로 나중으로 계산 순서가 바뀐 것이라 결과는 같음
| flag | 값 | 방식 |
|---|---|---|
| `INTER_NEAREST` | 0 | 최근접 이웃 |
| `INTER_LINEAR` | 1 | 양선형 (기본값) |
| `INTER_CUBIC` | 2 | 바이큐빅, 4×4 이웃 (더 부드러움) |
| `INTER_AREA` | 3 | 영역 평균 — **축소할 때** 가장 깔끔 (모아레 적음) |
| `INTER_LANCZOS4` | 4 | 8×8 이웃, 고품질·느림 |
- **주의: 보간 방식은 반드시 키워드로**
```python
dst = cv2.resize(image, (350, 400), 0, 0, cv2.INTER_NEAREST)        # 슬라이드 방식
dst = cv2.resize(image, (350, 400), interpolation=cv2.INTER_NEAREST)  # 올바른 방식
```
  - `cv2.resize(src, dsize, dst, fx, fy, interpolation)` 순서라서 위치 인자 다섯 번째(`cv2.INTER_NEAREST`)는 **fy**로 들어가고 보간은 기본값(양선형)이 됨 → 슬라이드의 "최근접" 결과는 실제로 양선형과 같은 영상 (OpenCV 4.13에서 두 결과가 픽셀까지 동일함을 확인)
  - `cv2.warpAffine(image, M, size, cv2.INTER_LINEAR)`도 네 번째 위치가 `dst`라서 flag가 무시됨 → `flags=` 키워드로
### 평행이동
- x' = x + dx, y' = y + dy (역방향: x = x' − dx) → 범위를 벗어난 부분은 잘리고, 빈 곳은 0(검정)
```python
def translate(img, pt):
    dst = np.zeros(img.shape, img.dtype)
    for i in range(img.shape[0]):
        for j in range(img.shape[1]):
            x, y = j - pt[0], i - pt[1]
            if 0 <= y < img.shape[0] and 0 <= x < img.shape[1]:
                dst[i, j] = img[y, x]
    return dst
# 같은 일: cv2.warpAffine(img, np.float32([[1, 0, dx], [0, 1, dy]]), (w, h))
```
### 회전
- 순방향: x' = x cos θ − y sin θ, y' = x sin θ + y cos θ
- 역방향: x = x' cos θ + y' sin θ, y = −x' sin θ + y' cos θ
- 수학 좌표(y 위로)에선 반시계, **영상 좌표(y 아래로)에선 같은 식이 시계 방향**으로 보임
- 원점(왼쪽 위)이 아닌 중심 (cx, cy) 기준: 중심으로 옮기고 → 회전 → 되돌리기
  - x = (x' − cx) cos θ + (y' − cy) sin θ + cx, y = −(x' − cx) sin θ + (y' − cy) cos θ + cy
- 마우스로 회전각 정하기: 중심 p, 시작점 p₁, 끝점 p₂ → θ = atan2(p₂ − p) − atan2(p₁ − p) (`cv2.fastAtan2(dy, dx)`는 0~360° 반환)
### 어파인 변환
- 크기·회전·이동(+ 기울임)의 조합. 평행선은 평행 유지, 길이 비율 유지
- 이동은 덧셈이라 곱셈 하나로 합치려고 **3×3 동차 좌표** 사용 → 행렬을 곱해 합성한 뒤 마지막 행([0 0 1])을 빼면 **2×3**
  - 크기 [[α, 0, 0], [0, β, 0], [0, 0, 1]], 이동 [[1, 0, tx], [0, 1, ty], [0, 0, 1]], 회전 [[cos, −sin, 0], [sin, cos, 0], [0, 0, 1]]
  - 오른쪽 행렬부터 적용됨: 중심 기준 회전 = 이동(+c) · 회전 · 이동(−c)
- 미지수 6개 → **대응점 3쌍**이면 결정
| 함수 | 역할 |
|---|---|
| `cv2.getAffineTransform(src3, dst3)` | 3쌍 → 2×3 행렬 |
| `cv2.getRotationMatrix2D(center, angle, scale)` | 중심 기준 회전 + 크기, **양수 = 화면에서 반시계** |
| `cv2.invertAffineTransform(M)` | 역변환 (역방향 사상용) |
| `cv2.warpAffine(src, M, dsize, flags=…, borderMode=…)` | 변환 적용 |
```python
pt1 = np.float32([(30, 70), (20, 240), (300, 110)])
pt2 = np.float32([(120, 20), (10, 180), (280, 260)])
aff_mat = cv2.getAffineTransform(pt1, pt2)              # [[0.683 -0.607 142.0] [0.743 0.985 -71.2]]
rot_mat = cv2.getRotationMatrix2D((200, 200), 30, 1)    # (200, 200) 기준 반시계 30°
size = image.shape[::-1]                                # (너비, 높이)
dst3 = cv2.warpAffine(image, aff_mat, size, flags=cv2.INTER_LINEAR)
dst4 = cv2.warpAffine(image, rot_mat, size, flags=cv2.INTER_LINEAR)
```
  - 직접 구현: `inv = cv2.invertAffineTransform(M)` 후 출력 좌표 (j, i, 1)마다 `inv @ (j, i, 1)`로 입력 좌표를 구해 양선형 보간
  - 방향 확인: 중심 (60, 50)의 오른쪽 점 (100, 50)을 +30° 돌리면 (94.6, 30) → y가 줄어 **위로** 이동 = 반시계 (직접 계산). 슬라이드의 수식 회전(시계 방향)과 부호가 반대라는 점에 주의
- 테두리: `BORDER_CONSTANT`(기본, 검정), `BORDER_REPLICATE`, `BORDER_REFLECT`, `BORDER_WRAP`
### 원근(투영) 변환
- 3차원을 2차원에 비스듬히 찍으면 평행선이 한 점으로 모임 → 이를 되돌리거나 만드는 변환 (문서 스캔, 차선 버드아이뷰)
- **동차 좌표**: (x, y) ↔ (ωx, ωy, ω), 되돌릴 땐 ω로 나눔. 예: (5, 7, 5) → (1, 1.4)
- ω·[x', y', 1]ᵀ = M(3×3) · [x, y, 1]ᵀ — 마지막에 ω로 나누기 때문에 직선은 직선으로 가지만 평행은 유지되지 않음
- 자유도 8 (M₃₃ = 1로 고정) → **대응점 4쌍**
```python
pts1 = np.float32([(80, 40), (315, 133), (75, 300), (335, 300)])    # 비스듬한 사각형
pts2 = np.float32([(50, 60), (340, 60), (50, 320), (340, 320)])     # 반듯한 직사각형
M = cv2.getPerspectiveTransform(pts1, pts2)
# [[ 0.6258  0.0398  -6.888]
#  [-0.5027  1.0636  51.392]
#  [-0.0016  0.0005   1.0  ]]
dst = cv2.warpPerspective(image, M, image.shape[1::-1], flags=cv2.INTER_CUBIC)

# 좌표 변환 확인
h = np.c_[pts1, np.ones(4)] @ M.T        # (80, 40, 1) → (44.77, 53.72, 0.895)
h / h[:, 2:]                             # → (50, 60, 1)  ω로 나눠야 목적 좌표
cv2.perspectiveTransform(pts1.reshape(-1, 1, 2), M)   # 나눗셈까지 해 주는 함수
```
  - 슬라이드 결과의 `[44.77 53.72 0.895]`는 **ω로 나누기 전** 값. 나누면 정확히 (50, 60) (직접 확인)
  - `cv2.transform`은 나눗셈을 하지 않으니 원근 변환 좌표에는 `cv2.perspectiveTransform`
- 응용: 마우스로 네 꼭짓점을 끌어 옮기면 그때마다 `getPerspectiveTransform` → `warpPerspective`로 정면 보정 영상 갱신
