> 다층 퍼셉트론의 순방향 연산으로 출력과 정답 간의 오차를 계산하고, 연쇄 법칙(chain rule)을 통해 오차를 출력층에서 은닉층 방향으로 역전파하여 가중치별 기울기를 구한다. 이를 바탕으로 경사 하강법을 적용해 가중치를 갱신하여 전체 오차를 줄인다.

### 2-2-2 신경망 구조와 기호 정의
- **2-2-2 다층 퍼셉트론 구조**
  - 입력층(input layer) 노드 2개: `I1`, `I2` (슬라이드 원문 표기 `l1`, `l2`)
  - 은닉층(hidden layer) 노드 2개: 가중합 `h1`, `h2` 및 활성화 출력 `H1`, `H2`
  - 출력층(output layer) 노드 2개: 가중합 `y1`, `y2` 및 활성화 출력 `Y1`, `Y2`
- **슬라이드 다이어그램 노드-가중치 대응 관계**
  - 원문 슬라이드의 `y1H1`, `y2H2` 표기는 은닉 노드 `H1`, `H2` 출력이 출력 가중합 `y1`, `y2`로 전달되는 상호 연결 구조를 나타냄
  - `v1` ~ `v4` 가중치 연결선을 통해 각 은닉 노드 출력이 두 출력 노드로 완전 연결(fully connected)됨
- **가중치(weight) 표기**
  - 입력층 → 은닉층 연결 가중치: `w1`, `w2`, `w3`, `w4`
    - `w1`: 입력 `I1` → 은닉 노드 1(`H1`) 연결
    - `w2`: 입력 `I1` → 은닉 노드 2(`H2`) 연결
    - `w3`: 입력 `I2` → 은닉 노드 1(`H1`) 연결
    - `w4`: 입력 `I2` → 은닉 노드 2(`H2`) 연결
  - 은닉층 → 출력층 연결 가중치: `v1`, `v2`, `v3`, `v4`
    - `v1`: 은닉 출력 `H1` → 출력 노드 1(`Y1`) 연결
    - `v2`: 은닉 출력 `H1` → 출력 노드 2(`Y2`) 연결
    - `v3`: 은닉 출력 `H2` → 출력 노드 1(`Y1`) 연결
    - `v4`: 은닉 출력 `H2` → 출력 노드 2(`Y2`) 연결
- **활성화 함수: 시그모이드(Sigmoid)**
  - 비선형 활성화 함수로 각 층의 가중합을 0과 1 사이 값으로 사상
  - 함수식: `σ(x) = 1 / (1 + exp(-x))`
  - 시그모이드 미분 도함수식: `σ'(x) = σ(x) · (1 − σ(x))`
    - 활성화 출력값을 `out`이라 두면 도함수는 `out · (1 − out)` 형태로 간결하게 정리됨

### 순방향 패스 (Forward Pass) 연산
- **은닉층 연산**
  - 입력값과 가중치의 곱합으로 은닉 가중합 `h1`, `h2` 산출
  - 수식:
    - `h1 = w1 · I1 + w3 · I2`
    - `h2 = w2 · I1 + w4 · I2`
  - 각 가중합에 시그모이드 활성화 함수 적용:
    - `H1 = σ(h1)`
    - `H2 = σ(h2)`
- **출력층 연산**
  - 은닉층 출력 `H1`, `H2`와 가중치 `v1` ~ `v4`의 곱합으로 출력 가중합 `y1`, `y2` 산출
  - 수식:
    - `y1 = v1 · H1 + v3 · H2`
    - `y2 = v2 · H1 + v4 · H2`
  - 각 가중합에 시그모이드 활성화 함수 적용:
    - `Y1 = σ(y1)`
    - `Y2 = σ(y2)`
- **정답과 실제 출력**
  - 목표 정답: `t1`, `t2`
  - 신경망의 최종 출력: `Y1`, `Y2`

### 손실 함수 (Loss Function)
- **평균제곱오차 (MSE: Mean Squared Error) 기반 전체 손실**
  - 정답 `t`와 모델 출력 `Y`의 차이를 제곱하여 오차 측정
  - 전체 손실 `E_total`은 각 출력 노드 오차 `E1`, `E2`의 합산
  - 수식: `E_total = E1 + E2 = ½(t1 − Y1)² + ½(t2 − Y2)²`
  - 계수 `½`의 역할:
    - 오차 함수를 편미분할 때 지수 2가 앞으로 내려와 계수 `½`과 곱해져 상쇄됨 → 수식 계산 단순화

### 역전파 연산 원리와 연쇄 법칙 (Chain Rule)
- **역전파(Backpropagation)의 필요성**
  - 신경망 학습은 손실 함수 `E`를 최소화하는 가중치를 찾는 최적화 과정
  - 경사 하강법을 적용하려면 손실 함수 `E`에 대한 각 가중치의 편미분값(기울기)이 필요함
  - 은닉층 가중치는 오차에 간접적으로 연결되어 직접 미분 불가 → 합성함수의 미분법인 **연쇄 법칙(chain rule)** 적용
- **오차 역전파의 기본 방향**
  - 순방향 패스: 입력층 → 은닉층 → 출력층 (신호 전달)
  - 역방향 패스: 출력층 → 은닉층 → 입력층 (오차 신호 역전파)
  - 출력층 가중치는 출력 노드 오차에 바로 연결되므로 단일 경로로 미분
  - 은닉층 가중치는 은닉 노드가 여러 출력 노드로 뻗어나가므로 각 경로의 오차를 합산하여 미분

### 출력층 가중치(v)의 역전파 기울기 유도
- **연쇄 법칙을 통한 3단계 분해**
  - 가중치 `v1`(`H1 → Y1`)에 대한 손실 편미분:
    - `∂E/∂v1 = (∂E/∂Y1) · (∂Y1/∂y1) · (∂y1/∂v1)`
- **각 항의 미분 계산**
  - 1단계 (오차의 출력 미분):
    - `∂E/∂Y1 = ∂/∂Y1 [ ½(t1 − Y1)² ] = −(t1 − Y1) = Y1 − t1`
  - 2단계 (출력의 가중합 미분, 시그모이드 도함수):
    - `∂Y1/∂y1 = ∂/∂y1 [ σ(y1) ] = Y1 · (1 − Y1)`
  - 3단계 (가중합의 가중치 미분):
    - `∂y1/∂v1 = ∂/∂v1 [ v1 · H1 + v3 · H2 ] = H1`
- **출력층 델타(delta)와 최종 기울기**
  - 출력 노드 1의 오차 신호 델타 정의:
    - `δ_Y1 = (∂E/∂Y1) · (∂Y1/∂y1) = −(t1 − Y1) · Y1 · (1 − Y1)`
  - 최종 가중치 기울기:
    - `∂E/∂v1 = δ_Y1 · H1`
- **출력층 나머지 가중치 유도**
  - `v2` (`H1 → Y2`): `∂E/∂v2 = δ_Y2 · H1` (단, `δ_Y2 = −(t2 − Y2) · Y2 · (1 − Y2)`)
  - `v3` (`H2 → Y1`): `∂E/∂v3 = δ_Y1 · H2`
  - `v4` (`H2 → Y2`): `∂E/∂v4 = δ_Y2 · H2`
- **기울기 규칙 요약**
  - 출력층 가중치의 편미분 = `(해당 연결선이 도달하는 출력 노드의 델타) · (연결선 출발 노드의 출력 H)`

### 은닉층 가중치(w)의 역전파 기울기 유도
- **은닉 노드의 오차 전파 구조**
  - 가중치 `w1`(`I1 → H1`)에 대한 손실 편미분:
    - `∂E/∂w1 = (∂E/∂H1) · (∂H1/∂h1) · (∂h1/∂w1)`
  - 은닉 노드 `H1`의 출력은 두 출력 노드 `Y1`과 `Y2` 모두에 전달됨
  - 전체 손실 `E`에 대한 `H1`의 변화율은 두 경로의 오차 합산:
    - `∂E/∂H1 = (∂E1/∂H1) + (∂E2/∂H1)`
- **은닉 노드로 역전파되는 오차 항 계산**
  - 노드 1 경로 (`H1 → Y1`):
    - `∂E1/∂H1 = (∂E1/∂Y1) · (∂Y1/∂y1) · (∂y1/∂H1) = δ_Y1 · v1`
  - 노드 2 경로 (`H1 → Y2`):
    - `∂E2/∂H1 = (∂E2/∂Y2) · (∂Y2/∂y2) · (∂y2/∂H1) = δ_Y2 · v2`
  - 두 경로 합산:
    - `∂E/∂H1 = δ_Y1 · v1 + δ_Y2 · v2`
- **나머지 미분 항 계산**
  - 활성화 함수 도함수:
    - `∂H1/∂h1 = H1 · (1 − H1)`
  - 가중합의 가중치 미분:
    - `∂h1/∂w1 = ∂/∂w1 [ w1 · I1 + w3 · I2 ] = I1`
- **은닉층 델타와 최종 기울기**
  - 은닉 노드 1의 델타 정의:
    - `δ_H1 = (∂E/∂H1) · (∂H1/∂h1) = (δ_Y1 · v1 + δ_Y2 · v2) · H1 · (1 − H1)`
  - 최종 가중치 기울기:
    - `∂E/∂w1 = δ_H1 · I1`
- **은닉층 나머지 가중치 유도**
  - `w2` (`I1 → H2`): `∂E/∂w2 = δ_H2 · I1`
    - 단, `δ_H2 = (δ_Y1 · v3 + δ_Y2 · v4) · H2 · (1 − H2)`
  - `w3` (`I2 → H1`): `∂E/∂w3 = δ_H1 · I2`
  - `w4` (`I2 → H2`): `∂E/∂w4 = δ_H2 · I2`
- **행렬 관점의 역전파 표기**
  - 은닉 노드로 역전파되는 오차 합산은 출력층 델타 벡터와 가중치 행렬 `V`의 전치 행렬(`V.T`) 곱으로 표현 가능함

### 경사 하강법을 통한 가중치 갱신
- **가중치 갱신 원리**
  - 손실 함수가 감소하는 방향은 기울기의 반대 방향
  - 학습률(learning rate) `η`를 기울기에 곱해 기존 가중치에서 차감
  - 일반 갱신식: `W ← W − η · (∂E/∂W)`
- **출력층 가중치 갱신식**
  - `v1 ← v1 − η · (∂E/∂v1) = v1 − η · δ_Y1 · H1`
  - `v2 ← v2 − η · (∂E/∂v2) = v2 − η · δ_Y2 · H1`
  - `v3 ← v3 − η · (∂E/∂v3) = v3 − η · δ_Y1 · H2`
  - `v4 ← v4 − η · (∂E/∂v4) = v4 − η · δ_Y2 · H2`
- **은닉층 가중치 갱신식**
  - `w1 ← w1 − η · (∂E/∂w1) = w1 − η · δ_H1 · I1`
  - `w2 ← w2 − η · (∂E/∂w2) = w2 − η · δ_H2 · I1`
  - `w3 ← w3 − η · (∂E/∂w3) = w3 − η · δ_H1 · I2`
  - `w4 ← w4 − η · (∂E/∂w4) = w4 − η · δ_H2 · I2`
- **기울기 부호에 따른 동작**
  - 기울기 < 0: 가중치를 증가시켜 손실 감소
  - 기울기 > 0: 가중치를 감소시켜 손실 감소

### 2-2-2 신경망 역전파 연산 구현
- 넘파이(NumPy)를 활용하여 2-2-2 구조의 순방향 계산과 역전파 가중치 갱신을 실행 가능한 형태로 작성
```python
import numpy as np

# 시그모이드 활성화 함수 및 도함수
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_deriv(out):
    return out * (1 - out)

# 입력 및 정답 설정 (수식 검증을 위한 예시값)
I = np.array([1.0, 0.0])      # 입력 I1=1, I2=0
t = np.array([1.0, 0.0])      # 정답 t1=1, t2=0
eta = 0.5                     # 학습률

# 가중치 초기화 (수식 검증을 위한 예시값)
# W: 입력(2) -> 은닉(2) [w1, w2; w3, w4]
W = np.array([
    [0.5, -0.5],              # I1 -> H1(w1), H2(w2)
    [0.3, 0.8]                # I2 -> H1(w3), H2(w4)
])

# V: 은닉(2) -> 출력(2) [v1, v2; v3, v4]
V = np.array([
    [1.0, -1.0],              # H1 -> Y1(v1), Y2(v2)
    [1.0, 1.0]                # H2 -> Y1(v3), Y2(v4)
])

# 1. 순방향 패스 (Forward Pass)
# 은닉층 연산
h = np.dot(I, W)              # 은닉 가중합 [h1, h2]
H = sigmoid(h)                # 은닉 출력 [H1, H2]

# 출력층 연산
y = np.dot(H, V)              # 출력 가중합 [y1, y2]
Y = sigmoid(y)                # 최종 출력 [Y1, Y2]

# 손실 계산 (MSE)
loss = 0.5 * np.sum((t - Y) ** 2)
print("순방향 출력 Y:", Y)
print("초기 손실:", loss)

# 2. 역방향 패스 (Backward Pass)
# 출력층 델타: -(t - Y) * Y * (1 - Y)
delta_Y = -(t - Y) * sigmoid_deriv(Y)

# 출력층 가중치 기울기: H.T x delta_Y
grad_V = np.outer(H, delta_Y)

# 은닉층 델타: (delta_Y x V.T) * H * (1 - H)
delta_H = np.dot(delta_Y, V.T) * sigmoid_deriv(H)

# 은닉층 가중치 기울기: I.T x delta_H
grad_W = np.outer(I, delta_H)

# 3. 가중치 갱신 (Gradient Descent)
V_updated = V - eta * grad_V
W_updated = W - eta * grad_W

print("갱신된 출력층 가중치 V:\n", V_updated)
print("갱신된 은닉층 가중치 W:\n", W_updated)
```

### 역전파 연산 단계별 요약
- **1단계: 순방향 가중합 및 활성화 계산**
  - 입력 신호에 가중치를 곱하고 합산한 뒤 시그모이드 활성화 함수를 적용하여 은닉 출력과 최종 출력을 순차적으로 도출함
- **2단계: 오차 측정 및 출력층 델타 계산**
  - 목표 정답과 실제 출력의 차이를 바탕으로 각 출력 노드의 손실을 구하고 활성화 도함수를 곱해 출력층 오차 델타 `δ_Y`를 계산함
- **3단계: 은닉층으로의 오차 역전파**
  - 출력층 델타에 연결 가중치 `v`를 곱해 거꾸로 전달하고 은닉 노드의 활성화 도함수를 곱해 은닉층 델타 `δ_H`를 계산함
- **4단계: 가중치별 기울기 산출**
  - 각 노드의 오차 델타와 이전 층에서 전달된 입력 신호를 곱하여 각 가중치의 손실 편미분값을 도출함
- **5단계: 경사 하강법 적용 가중치 갱신**
  - 계산된 기울기에 학습률을 곱해 기존 가중치에서 감산하여 오차를 줄이는 방향으로 파라미터를 업데이트함
- **6단계: 전체 학습 반복(에포크)**
  - 가중치 갱신 후 전체 오차가 허용 기준 이하로 수렴할 때까지 모든 훈련 데이터에 대해 순방향과 역전파 과정을 반복 수행함
