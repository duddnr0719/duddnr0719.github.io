> 클래스 = 사용자 정의 자료형. `new`로 만든 인스턴스에 점을 찍어 쓰는 게 인스턴스 멤버, 클래스 이름에 점을 찍어 쓰는 게 클래스(static) 멤버. 리스트에서 반복하며 지울 땐 반드시 뒤에서부터.
### 왜 클래스인가
- 주차장 관리: 차량 번호, 입차 시간, 출차 시간을 변수·배열 여러 개로 따로 관리하면 차가 많아질수록 엉망
- 관련된 속성(+ 행위)을 하나로 묶은 **사용자 정의 자료형** = 클래스
```csharp
class Car
{
    int carNumber;
    DateTime inTime;
    DateTime outTime;

    public void SetInTime()  { this.inTime = DateTime.Now; }
    public void SetOutTime() { this.outTime = DateTime.Now; }
}

Car car = new Car();
car.SetInTime();
car.SetOutTime();
```
- `Car car = new Car();`
  - `Car`: 클래스(대문자로 시작하는 관례)
  - `car`: **인스턴스(객체)** — 클래스로 만든 변수
  - `Car()`: **생성자** — 클래스와 이름이 같은 메서드
### Random
```csharp
Random random = new Random();
Console.WriteLine(random.Next(10, 100));    // 10 이상 100 미만 정수
Console.WriteLine(random.Next(10));         // 0 이상 10 미만
Console.WriteLine(random.NextDouble());     // 0.0 이상 1.0 미만 실수
Console.WriteLine(random.NextDouble() * 10);// 0.0 이상 10.0 미만
```
- 인스턴스를 만들고 그 뒤에 점을 찍어 쓰는 멤버 = **인스턴스 멤버**
### List
- 크기가 고정인 배열과 달리 **크기가 늘었다 줄었다** 하는 컬렉션 (`using System.Collections.Generic;`, 최신 .NET은 기본 포함)
- `<int>`처럼 담을 자료형을 지정 = **제네릭**
```csharp
List<int> list = new List<int>();
list.Add(52); list.Add(273); list.Add(32); list.Add(64);
// 또는 new List<int>() { 52, 273, 32, 64 };

list.Remove(52);       // 값으로 제거
// list.RemoveAt(0);   // 인덱스로 제거
foreach (var item in list)
    Console.WriteLine("Count: " + list.Count + "\titem: " + item);
// Count: 3  item: 273 / 32 / 64
```
- 개수는 배열 `Length`, 리스트 `Count`
### Math
- 인스턴스 없이 **클래스 이름에 바로 점** = **클래스(정적) 멤버**
| 메서드 | 설명 | 예 → 결과 |
|---|---|---|
| `Abs(x)` | 절댓값 | `Abs(-52273)` → 52273 |
| `Ceiling(x)` | 올림 | `Ceiling(52.273)` → 53 |
| `Floor(x)` | 내림 | `Floor(52.273)` → 52 |
| `Max(a, b)` / `Min(a, b)` | 큰 값 / 작은 값 | 273 / 52 |
| `Round(x)` | 반올림 | `Round(52.273)` → 52 |
- 주의: `Math.Round`의 기본은 **은행원 반올림**(0.5면 가장 가까운 짝수로) → `Round(2.5)` = 2, `Round(3.5)` = 4. 일반 반올림은 `Math.Round(2.5, MidpointRounding.AwayFromZero)` = 3
- 상수: `Math.PI`, `Math.E`. 클래스 정보는 MS Learn 문서(learn.microsoft.com)에서
### 클래스 만들기
- `class 이름 { }`. 세 가지 위치
  1. 한 파일(Program.cs)에 여러 클래스
  1. 클래스 안에 클래스 (중첩 클래스)
  1. **파일을 나눠서** (권장): 솔루션 탐색기 → 추가 → 새 항목 → 클래스 → `OtherFileClass.cs`
- 없는 클래스를 먼저 써놓고(`Product product = new Product();`) `Ctrl + .` → 클래스 자동 생성
- 이름 충돌 주의: `class Math { }`를 만들면 `Math.Abs()`가 내 Math를 가리켜 CS0117 오류 → 기본 클래스와 겹치지 않는 이름을
### 인스턴스 변수
- `[접근 제한자] [자료형] [이름]`. 소문자로 시작하는 관례, 보통 `private`이지만 지금은 `public`으로
```csharp
class Product
{
    public string name = "default";   // 선언하며 초기값 가능
    public int price = 1000;
}

Product product = new Product();
product.name = "감자";
product.price = 2000;
Console.WriteLine(product.name + " : " + product.price + "원");   // 감자 : 2000원

// 생성과 동시에 초기화 (객체 이니셜라이저)
Product productB = new Product() { name = "고구마", price = 3000 };
```
### 클래스 변수 (static)
- `[접근 제한자] static [자료형] [이름]`. 인스턴스 없이 `클래스이름.변수`로, 모든 인스턴스가 하나를 공유
```csharp
class MyMath
{
    public static double PI = 3.141592;
}
Console.WriteLine(MyMath.PI);   // 3.141592
```
### 추상화
- 객체 지향의 4대 특징: **추상화, 캡슐화, 상속, 다형성**
- 추상화: 무한히 많은 속성 중 **프로그램 목적에 필요한 핵심만** 뽑아내는 것
```csharp
// 학생 관리 프로그램에 필요한 학생
class Student
{
    public string id;
    public string name;
    public int grade;
    public string major;
    public DateTime birthday;
}
```
### 모델 클래스 + List
- 인스턴스 변수만 가진 데이터용 클래스 = **모델 클래스** (실무 앱 코드의 대부분)
```csharp
class Student { public string name; public int grade; }

List<Student> list = new List<Student>()
{
    new Student() { name = "윤인성", grade = 1 },
    new Student() { name = "연하진", grade = 2 },
    new Student() { name = "윤아린", grade = 3 },
    new Student() { name = "윤명월", grade = 4 },
    new Student() { name = "구지연", grade = 1 },
    new Student() { name = "김연희", grade = 2 },
};
foreach (var item in list)
    Console.WriteLine(item.name + " : " + item.grade);
```
### 반복하면서 제거하기 (2학년 이상 제거)
- foreach 안에서 `list.Remove(item)` → `InvalidOperationException: 컬렉션이 수정되었습니다` (열거 중엔 컬렉션 변경 불가)
- 정방향 for + `RemoveAt(i)` → 결과 `윤인성, 윤아린, 구지연` ✗
  - i = 1에서 연하진을 지우면 윤아린이 인덱스 1로 당겨지는데, 다음엔 i = 2를 검사하니 윤아린을 **건너뜀**
- **역방향 for** → `윤인성, 구지연` ✓ (뒤에서 지우면 앞쪽 인덱스는 안 바뀜)
```csharp
for (int i = list.Count - 1; i >= 0; i--)
{
    if (list[i].grade > 1)
        list.RemoveAt(i);
}
```
- 한 줄 대안: `list.RemoveAll(s => s.grade > 1);`
### 윈도 폼 맛보기
- 새 프로젝트 → **Windows Forms 앱** → `FirstFormApplication` → .NET 8.0
- 파일 구성
  - `Program.cs`: `Main()`에서 `Application.Run(new Form1());`
  - `Form1.cs`: 내가 작성하는 코드
  - `Form1.Designer.cs`: 디자이너가 자동 생성 (`InitializeComponent()` 안에서 컨트롤 생성·배치)
  - 두 파일 모두 `public partial class Form1 : Form` → **partial**: 한 클래스를 여러 파일에 나눠 작성
- 도구 상자에서 Button을 끌어다 놓고, 속성 창에서 `Text`(표시 글자), `(Name)`을 `myButton`으로 바꾸면 Designer.cs에 `private Button myButton;`이 생김
- 코드로 속성 변경 + 버튼 동적 생성
```csharp
public partial class Form1 : Form
{
    public Form1()
    {
        InitializeComponent();

        int width = 100, height = 23, margin = 6;
        myButton.Text = "코드에서 변경!";
        myButton.Width = width;

        for (int i = 0; i < 5; i++)
        {
            Button button = new Button();
            Controls.Add(button);                                     // 폼에 추가
            button.Location = new Point(margin, (height + margin) * (i + 1) + margin);
            button.Text = "동적 생성 " + i + "번째";
            button.Width = width;
            button.Height = height;
        }
    }
}
```
- 실행하면 "코드에서 변경!" 아래로 "동적 생성 0번째" ~ "4번째" 버튼 5개가 세로로 배치됨
