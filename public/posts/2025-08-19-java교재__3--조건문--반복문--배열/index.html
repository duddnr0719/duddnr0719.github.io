3. 조건문, 반복문, 배열

2025년 8월 19일 Java(교재)

조건문

if-else 문

- 조건에 따라서 서로 다른 처리를 하고 싶을 때 사용하는 구조 ![](/images/826a5d4cb3bc6c3f.png) ![](/images/c6310e489882b1b2.png)

switch 문

- if-else 문과 비슷하지만 좀 더 일정한 형식이 있는 구조 - case 문 내부에 break는 해당 case 문을 실행한 뒤 switch 문을 빠져나가기 위한 것이다. → break 문이 없다면 그 다음의 case 문에 속한 문장들이 실행된다. ![](/images/409d56618fe269cd.png)

향상된 switch 문

public class Test { 
public static void main(String args[]) {
var day = "SAT";
var today = "";
switch(day) {
case "SAT", "SUN" -> today = "주말";
case "MON", "TUE", "WED", "THU", "FRI" -> today = "평일";
default -> System.out.println("Error");
}
}
}

반복문

for 문

- 조건식이 참인 동안 괄호 안의 문장들을 반복하다 거짓이 되면 반복문을 벗어난다. 처음엔 초기값을 실행하며, 조건식에 참일 동안 괄호 안에 문장을 반복 실행한다. ![](/images/fbe0336fe95190c7.png)

while 문

- 조건문이 참인 동안 while 문이 수행할 문장들을 반복하여 수행한다. - while 문을 사용하여 무한 루프를 생성할 수 있는데, while(true)를 이용하면 된다. → 조건식이 항상 true(참)이므로 무한 루프 안에 break 문처럼 빠져나올 수 있는 문장이 있는 경우를 제외하고는 무한 루프의 굴레에 빠지게 된다. - continue 문을 사용하여 조건문으로 돌아가게 할 수 있다. → while 문 안의 문장을 수행할 때 어떤 조건을 검사해서 참이 아닌 경우 반복문을 벗어나는 것이 아닌 조건문으로 돌아간다. ![](/images/c1c092b226afa595.png) ![](/images/71ed6c1c6a4f09d1.png)

do-while 문

- 조건문을 만족하지 않아도 무조건 한 번 실행하는 조건문. - 한 번 실행 후에도 조건식을 만족한다면 반복문에 해당하는 문장 반복, 조건식이 false가 되면 탈출 ![](/images/9085684bd1933893.png)

중첩 반복문(Nested Loop)

- 반복문 안에 다른 반복문이 실행되는 형태. - 주로 2차원 이상의 데이터 구조를 다룰 때 사용 → ex) 2차원 배열을 순회할 때 ![](/images/19ee91fe040b3ab7.png)

배열

배열

- 여러 개의 변수를 하나로 묶어 넣은 것 - 배열을 사용하면 같은 종류의 대량의 데이터를 한 번에 선언할 수 있다.

배열의 선언

  • 배열 참조 변수부터 선언한다.
int[] s; // 배열 참조 변수가 int[]형인 배열 선언

s = new int[10]; // 실제 선언 시 new 연산자를 사용하여 선언해야 함.
![](/images/cef438189501abff.png)

반복문과 배열

  • 배열의 각각의 요소는 인덱스(index)를 통하여 접근할 수 있다.
  • 반복문의 초기식, 조건식, 증감식을 잘 다루어 사용하면 배열의 모든 요소에 접근할 수 있다.
public class ArrayTest {
public static void main(String args[]) {
int[] s = new int[10];
// 배열 값 초기화
for(int i = 0; i < s.length; i++) { // .length -> 배열의 크기를 가져옴
s[i] = i;
}
// 배열 값 참조
for(int i = 0; i < s.length; i++) {
System.out.print(s[i] + " ");
}
}
}

for-each 반복문

- 키워드가 따로 있는 것이 아닌 for 문을 이용하는데, 조건문의 문법이 다르다. - iterate는 루프를 돌릴 객체이고 iterate 객체에서 한 개씩 순차적으로 변수명에 대힙되어 for 문이 수행된다. ![](/images/d9a1f543e16ba3d0.png) ```java for(type 변수명 : iterate) { sentence; } ```

2차원 배열

  • 일반적인 배열 선언과 마찬가지로 배열 참조 변수부터 선언하지만 대괄호 두 개를 사용하여 선언한다.
int[][] s = new int[3][5]; // 3은 행의 개수 5는 열의 개수를 의미한다.

래그드 배열

- 각 행의 길이가 달라도 되는 배열. → 첫 번째 차원은 고정되지만 두 번째 차원은 각각 다를 수 있음. ### 특징 1. 메모리 효율성 → 꼭 필요한 크기만 할당 가능하다. ⇒ 메모리 공간을 절약할 수 있다. 2. 유연성 → 한 차원은 고정된 길이지만 다른 차원은 자유롭게, 다르게 설정 가능하다. 3. 1차원 배열의 배열 → 자바에서 2차원 배열은 1차원 배열의 배열로 구현되는데 래그드 배열은 이 구조를 활용한다. ⇒ 각 행에 서로 다른 길이의 1차원 배열을 할당하기 때문에 각 행의 크기가 다를 수 있다. ```java int[][] ragged = new int[3][]; ```
