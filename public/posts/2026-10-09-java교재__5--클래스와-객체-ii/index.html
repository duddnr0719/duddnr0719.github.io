5. 클래스와 객체 II

2025년 8월 27일 Java(교재)

객체의 생성, 소멸, 가비지 컬렉션

- 객체를 생성하는 연산자는 있지만, 객체를 삭제하는 연산자는 없다. - 자바에서는 가비지 컬렉션이라고 하는 자동 메모리 시스템을 사용한다.

가비지 컬렉터(Garbage Collector)

  • 힙 메모리에서 더 이상 필요 없는 객체를 찾아 지우는 작업을 수행함.

참조 변수와 대입 연산

  • 기초 변수와 참조 변수는 대입 연산에서 상당히 다르게 작용한다. 💡 기초 변수(Primitive Type)

  • 변수 공간 안에 실제 값을 직접 저장한다.

  • 기초 변수의 대입 연산 : 값의 복사
    기초 변수를 다른 변수에 대입하면 저장되어 있던 실제 값이 그대로 복사되어 새로운 변수에 할당된다. 따라서 대입 이후 두 변수는 완전히 독립적인 존재가 된다. 💡 참조 변수(Reference Type)

  • 실제 객체는 힙 메모리에 있으며 변수 공간 안에는 그 객체를 가리키는 메모리 주소를 저장한다.

    - 참조 변수의 대입 연산 : 주소의 복사
    참조 변수를 다른 변수에 대입하면 객체의 데이터가 복사되는 것이 아니라 객체를 가리키는 메모리 주소값이 복사된다. 결과적으로 두 변수는 동일한 하나의 객체를 함께 가리키게 된다.

인수 전달 방법

  • 자바에서 메소드로 인수가 전달되는 방법은 기본적으로 값에 의한 호출(call-by-value)이다.

객체가 전달되는 경우

  • 우리가 객체를 메소드로 전달하게 되면 객체 자체가 복사되어 전달되는 것이 아니고 객체의 참조값만 복사되어서 전달된다. → 참조 변수는 주소(참조값)을 가지고 있다.
  • 참조값이 매개 변수로 복사되면 메소드의 매개 변수도 동일한 객체를 참조하게 된다.

배열이 전달되는 경우

  • 배열도 객체이기 때문에 배열을 전달하는 것은 배열 참조 변수를 복사하는 것이다.

정적 멤버

  • 여러 객체 간에 공유해야 하는 데이터를 관리할 때 사용 → 여러 개의 객체가 하나의 변수를 공유하는 경우

정적 변수

  • 클래스당 하나만 생성되는 변수.
  • 변수를 정의할 때 static 키워드를 사용하여 만들 수 있다.

정적 메소드

  • 정적 변수를 선언할 때와 마찬가지로 메소드 이름 앞에 static 키워드를 사용하여 만들 수 있다.
  • 정적 메소드는 정적 멤버만 사용할 수 있다. → 정적 메소드 안에서는 인스턴스 멤버를 사용할 수 없다.
  • 정적 메소드에서 정적 메소드를 호출하는 것은 가능하다.
  • 정적 메소드는 this 키워드를 사용할 수 없다. 💡 인스턴스 멤버
  • 클래스로부터 생성된 객체(인스턴스)만이 사용할 수 있는 필드와 메소드.
  • 멤버들은 객체 하나하나에 고유한 값을 가지며, 객체를 생성해야만 메모리에 할당되어 접근하고 사용할 수 있다.

정적 블록

  • 클래스가 메모리에 로드될 때 한 번만 실행되는 문장들의 집합.

final 키워드

  • 어떤 필드에 final 키워드를 사용하면 상수가 된다. 상수를 정의할 때 static , final 수식어를 동시에 사용하는 경우가 많다. → 상수는 클래스를 변수로 만들어서 공유하여 메모리 공간을 절약한다.

객체 배열

- 객체를 저장하는 배열 - 동일 타입의 여러 객체를 생성하여 사용할 때 사용한다. - 객체 배열에는 객체에 대한 참조값이 저장되어 있다. ### 동적 객체 배열 - 자바의 표준 배열은 크기가 결정되면 변경하기 힘들기 때문에 동적 배열 ArrayList를 사용한다. ![](/images/6840064cb38f8a02.png)
