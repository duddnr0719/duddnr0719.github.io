7. 자바 스크립트 기초

2025년 10월 21일 HTML/CSS/JS

자바 스크립트

  • 동적인 웹페이지를 작성하기 위하여 사용되는 언어
  • 웹의 표준 프로그래밍 언어
  • 모든 웹 브라우저들은 자바 스크립트를 지원

자바 스크립트 특징

  • 인터프리트 언어
  • 동적 타이핑
  • 구조적 프로그래밍 지원 (함수 사용)
  • 객체 기반 → 자바 스크립트는 객체 지향 언어이다.
  • 함수형 프로그래밍 지원 → 자바 스크립트에서 함수는 일급객체이다. ⇒ 함수는 그 자체로 객체이다. 람다식도 사용할 수 있다.

자바 스크립트의 용도

  • HTML 콘텐츠를 동적으로 변경할 수 있다.
  • 이벤트에 반응하는 동작을 구현할 수 있다.
  • HTML 요소들의 속성을 동적으로 변경할 수 있다. ⇒ 색상과 같은 요소들의 스타일을 변경할 수 있다.
  • HTML 요소를 표시하거나 숨길 수 있다.
  • 사용자가 입력한 값들을 검증하는 작업을 할 수 있다.
  • 게임이나 애니메이션과 같은 상호대화적인 콘텐츠를 구현할 수 있다.

자바 스크립트의 위치

  • 내부 자바 스크립트 → head 태그 안에
