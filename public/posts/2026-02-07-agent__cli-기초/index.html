CLI 기초

2026년 2월 7일 agent

CLI ?

→ CLI (Command Line Interface) : 가상 터미널 또는 터미널을 통해 사용자와 컴퓨터가 상호작용 하는 방식. 리눅스의 터미널은 키보드의 입력과 모니터의 출력으로 모든 작업을 할 수 있다. 리눅스는 GUI가 개발되기 이전부터 컴퓨터를 조작하기 위해 사용된 프로그램으로 GUI가 할 수 있는 모든 작업을 CLI로 할 수 있다.

개념

터미널(Terminal) vs 셸(Shell)

  • 터미널 : 사용자와 컴퓨터가 상호작용하는 입출력 창. 글자를 입력받고 결과를 화면에 보여주는 인터페이스 역할을 한다.(iTerm2, Windows Terminal, VS Code 통합 터미널)
  • 셸 : 터미널에 입력한 명령어를 해석해서 운영체제의 핵심인 커널에 전달하는 번역기 역할을 한다.(bash, zsh, powershell)
  • 명령행 (Command Line) : 명령어를 입력하여 프로그램을 실행하는 텍스트 구문
  • 명령행 인터페이스 (Command LIne Interface) : 명령행 방식을 통해 기능을 제공하는 인터페이스. 명령 프롬프트, 터미널, 셸, 콘솔이라고도 한다.
  • 명령행 프로그램 : 명령행 인터페이스를 제공하는 프로그램. 셸, 셸 프로그램이라고도 한다.

명령어가 실행되는 과정

  • 명령어를 입력했을 때 일어나는 5단계
  1. 입력 및 구문 분석 (Parsing)
  • 셸은 사용자가 입력한 문자열을 명령어와 인자로 나눈다.

    rm -rf / → 명령어 : rm, 옵션/인자 : -rf /

  1. 명령어 위치 찾기 (PATH 탐색)
  • 셸은 이 명령어가 어디에 설치되어 있는지 찾는다. 이때 환경 변수 PATH에 등록된 폴더들을 순서대로 찾아본다.
    • 만약 /user/bin/ls에 실행 파일이 있다면 해당 파일을 실행한다.
    • 찾지 못하면 command not found 에러를 출력한다.
  1. 프로세스 생성 (Forking)
  • 현재 실행 중인 셸이 자신을 복제하여 새로운 프로세스를 만든다. → fork
  1. 프로그램 실행 (Execution)
  • 복제된 프로세스에 실제 명령어 프로그램 코드를 덮어씌워 실행한다. → exec
  1. 결과 출력 및 종료
  • 프로그램이 작업을 마치면 표준 출력(stdout)을 통해 결과를 터미널에 보여주고 프로세스는 종료된다.

표준 입출력 (Standard I/O)

모든 명령어는 기본적으로 3가지 통로를 가지고 있다. → 이 통로드를 조작하는 것이 리다이렉션(>, »)과 파이프( | )다.

  • ls > list.txt : 출력을 화면이 아닌 파일로 저장한다.
  • cat a.txt | grep “hello” : cat의 결과물을 다음 명령어인 grep의 입력값으로 넘긴다.

환경변수 (Environment Variables)

셸이 동작하는 Context를 결정하는 설정값들이다.

  • HOME : 사용자의 홈 디렉토리 경로
  • PATH : 명령어를 찾을 폴더들의 목록
  • USER : 현재 로그인한 사용자 이름

셸 프롬프트와 명령행의 구조

  • 컴퓨터 이름 : 시스템 설정>일반>정보>이름 에서 설정한 컴퓨터 이름이 표시된다. 뒤에 콜론(:)이 붙는다.
  • 현재 작업 디렉토리 : 홈 폴더를 의미하는 물결(~) 기호가 표시된다. 다른 디렉토리로 이동하면 해당 디렉토리 이름이 표시된다.
  • 사용자명 : 현재 로그인한 사용자명이 표시된다. 뒤에 달러 기호($)가 붙는다. 명령행은 아래 3가지의 요소로 구성된다.
  • 명령어 : 실행할 프로그램 이름과 절대경로. 프로그램이 위치한 경로를 매번 입력하지 않으려면 PATH 환경변수를 설정하면 된다.
  • 인수 : 프로그램에 전달할 옵션이나 값으로 공백으로 구분하여 여러 개를 전달 할 수 있다. 인수값에 공백이 있다면 큰 따옴표(”)로 묶어서 써야 제대로 전달된다.
  • 옵션 : 대시(-) 또는 이중 대시(–)로 시작하는 인수로 플래그라고도 한다.

명령어로 실행 프로그램을 지정하는 방법

  1. 절대 경로 + 프로그램 파일명 : 셸이 실행되는 작업 경로에 구애받지 않고 절대 경로를 포함한다.
/Library/Frameworks/Python.framework/Versions/3.11/bin/python3 --version
  1. PATH 환경변수 설정 + 프로그램 파일명 : PATH 환경변수에 프로그램이 파일이 위치한 경로를 등록하면 프로그램만 이름만 입력해서 사용할 수 있다.
export PATH="/Library/Frameworks/Python.framework/Versions/3.11/bin:$PATH"
python3 --version
  1. 경로 이동 + 프로그램 파일명 : 프로그램 파일이 위치한 경로로 이동 후 프로그램 이름만 입력해서 사용할 수 있다.
cd /Library/Frameworks/Python.framework/Versions/3.11/bin
python3 --version

PATH 환경변수 설정

  • 명령어를 입력하기 위해 긴 절대경로를 포함하거나 매번 경로 이동하는 번거로움을 줄이기 위해 PATH 환경변수를 사용한다.
  • 터미널에서 echo $PATH 명령행을 실행하면 등록된 디렉토리를 확인할 수 있다. 콜론 기호(:)로 구분된 여러 디렉토리가 문자열로 등록이 되어 있는데, 셸 프로그램은 이 값에서 앞에 위치한 디렉토리부터 확인하며 명령어에 맞는 프로그램이 있는지 검색한다.

임시로 PATH 값에 경로를 추가하는 방법

export PATH="...."

이 방식은 현재 프로세스에서만 유효하기 때문에 터미널 창을 닫고 다시 열면 효능이 사라진다.

  • 자주 사용하는 명령어는 셸 프로그램 실행 시 PATH 값으로 등록하는 것이 편리하다.
    • bash : ~/.bashrc 파일이나 ~/.bash_profile
    • zsh : ~/.zshrc
  • 위 파일에 설정값을 추가하면 된다.

필수로 알아야 할 명령어

  • env : 셸의 환경변수 확인
  • echo : 셸의 특정 환경변수 값 확인
  • which : 명령어가 가리키는 프로그램 파일 위치
  • open : 파일/폴더 열기
  • cd : 디렉토리 변경
  • ls : 현재 디렉토리에 있는 폴더와 파일 표시
  • cp : 파일/폴더 복사
  • mv : 파일/폴더 이동 또는 이름 변경
  • rm : 파일/폴더 삭제
  • mkdir : 폴더 생성
  • clear : 터미널 내용 삭제
