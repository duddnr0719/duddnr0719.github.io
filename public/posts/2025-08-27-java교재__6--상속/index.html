6. 상속

2025년 8월 27일 Java(교재)

상속

  • 기존 클래스(부모 클래스)의 필드와 메소드를 새로운 클래스(자식 클래스)가 물려받아 재사용하고 확장하는 객체 지향 프로그래밍의 핵심 개념.
  • 코드의 재사용성을 높이고 개발 시간을 단축할 수 있다.
  • 클래스 간의 계층적 관계를 형성하여 코드의 유지보수성과 유연성을 향상시킨다.
  • extends 키워드를 사용하여 상속을 정의할 수 있다. → 자식 클래스 뒤에 ‘extends 부모클래스’ 형식으로 사용한다.

자바 상속의 특징

  • 다중 상속을 지원하지 않는다. 다중 상속 : 여러 개의 클래스로부터 상속을 받는 것.
  • 상속의 횟수에는 제한이 없다.
  • 상속 계층 구조의 최상위에는 java.lang.Object 클래스가 있다.
  • 자식 클래스는 부모 클래스의 public 멤버, protected 멤버, default 멤버를 상속받는다. 하지만 부모 클래스의 private 멤버는 상속되지 않는다.
  • protected는 자식 클래스만 접근이 가능하다.

상속과 생성자

  • 생성자의 호출 순서 : 부모 클래스의 생성자 → 자식 클래스의 생성자 순서. 💡 명시적인 생성자 호출
  • super()를 호출하면 부모 클래스의 생성자가 호출 된다.
  • super() 메소드 인수의 형태에 따라 적절한 생성자가 선택된다. 💡 묵시적인 생성자 호출
  • 컴파일러는 부모 클래스의 기본 생성자가 자동으로 호출되도록 한다.
  • 묵시적인 부모 클래스 생성자 호출을 사용하려면 부모 클래스에 기본 생성자가 반드시 정의되어 있어야 한다.

메소드 오버라이딩(Method Overriding)

  • 자식 클래스가 부모 클래스의 메소드를 자신의 필요에 맞추어서 재정의하는 것.
  • 메소드의 이름이나 매개 변수, 반환형은 반드시 동일하여야 한다.

@Override 어노테이션

  • 철자를 잘못 쓰는 경우, 컴파일러는 이것을 새로운 메소드 이름으로 인식한다. → 메소드 오버라이드가 일어나지 않는다.
  • 이러한 오류를 방지하기 위해서 오버라이딩된 메소드 이름 앞에는 @Override 어노테이션을 붙이는 것이 좋다.
  • 만약 부모 클래스에 오버라이딩 하고자 하는 메소드의 이름과 같은 메소드가 없다면 컴파일러가 오류를 발생한다.

메소드 오버로딩(Method Overloading)

  • 같은 메소드명을 가진 여러 개의 메소드를 작성하는 것.

super를 통한 부모 클래스 멤버 접근

  • super 키워드는 상속 관계에서 부모 클래스의 메소드나 필드를 명시적으로 참조하기 위하여 사용.
  • 부모 클래스의 메소드를 오버라이딩한 경우에 super를 사용하면 부모 클래스의 메소드를 호출할 수 있다.

다형성(polymophism)

  • 객체들의 타입이 다르면 똑같은 메세지가 전달되더라도 서로 다른 동작을 하는 것.
  • 동일한 코드로 다양한 타입의 객체를 처리할 수 있는 기법.
## 업캐스팅 - 부모 클래스 변수로 자식 클래스 객체를 참조하는 것. - 업캐스팅은 묵시적으로 수행될 수 있다. - 업캐스팅을 사용하면 부모 클래스의 멤버에 접근할 수 있다. (자식 클래스의 멤버는 접근이 불가능)

다운캐스팅

  • 부모 객체를 자식 참조 변수로 참조하는 것.
  • 다운캐스팅은 묵시적으로 수행될 수 없다. → 명시적으로 하여야 한다.

상속 vs 구성

### 상속 - is-a(\~는 \~이다) 관계. - 한 클래스가 다른 클래스의 필드와 메소드를 그대로 물려받아 새로운 클래스를 정의하는 것.
💡 상속의 특징 - 코드 재사용 : 부모 클래스에 정의된 필드와 메소드를 자식 클래스에서 다시 작성할 필요 없이 사용할 수 있다. - 계층 구조 : 클래스 간의 명확한 계층 구조를 형성한다. - 다형성 : 부모 클래스 타입의 참조 변수로 자식 클래스 객체를 참조할 수 있어 코드의 유연성과 확장성을 높인다. - 메소드 오버라이딩 : 자식 클래스에서 부모 클래스의 메소드를 재정의하여 자신에게 맞게 동작을 변경할 수 있다. ### 구성 - has-a(\~는 \~를 가진다) 관계. - 한 클래스가 다른 클래스의 인스턴스를 자신의 멤버 변수로 포함하여 사용하는 방식. → 필요한 기능을 가진 기존 클래스를 부품처럼 사용하여 새로운 클래스를 조립하는 개념
💡 구성의 특징 - 느슨한 결합 : 포함되는 클래스의 내부 구현이 변경되어도 해당 클래스를 사용하는 클래스는 큰 영향을 받지 않는다. → 유지보수성 향상 - 유연성 : 런타임에 포함할 객체를 동적으로 변경할 수 있어 높은 유연성을 제공한다. - 캡슐화 강화 : 다른 클래스의 기능을 직접 물려받는 것이 아니라 필요한 기능만 외부로 노출된 인터페이스를 통해 사용하므로 캡슐화 원칙을 잘 지킬 수 있다. - 다중 상속의 대안 : 자바는 클래스의 다중 상속을 지원하지 않지만 구성을 사용하면 여러 클래스의 기능을 조합하여 다중 상속과 유사한 효과를 낼 수 있다.
