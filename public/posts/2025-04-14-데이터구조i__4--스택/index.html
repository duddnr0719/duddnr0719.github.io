4. 스택

2025년 4월 14일 데이터구조I

스택 ?

  • 선형 자료구조 중 하나. 일상 속의 예제로는 과자 프링글스가 있다. 한 쪽은 막혀있고 한 쪽은 뚫려있어 생산될 때 밑에서부터 차곡차곡 쌓이게 된다. 처음 들어간 과자일수록 통의 아랫부분에 위치, 나중에 들어간 과자일수록 통의 윗부분에 위치할 것이다. 과자를 먹을 때는 나중에 들어간 위에 있는 것부터 먹고 마지막에 나중에 들어간 것을 먹을 것이다. → 스택은 이와 같이 나중에 들어간 것이 먼저 나오는 구조이다.

스택의 특징

후입선출 , LIFO (Last-In-First-Out) : 가장 최근에 들어온 데이터가 가장 먼저 나감.

스택의 구조

  • 공백 스택 : 비어있는 스택, 요소가 하나도 존재하지 않는 것.
  • 스택 상단 (top) : 요소들 중 최상단에 위치한 것, 입출력이 이루어지는 곳.
  • 스택 하단 (bottom) : 스택 상단의 반대쪽, 제일 먼저 들어온 요소가 위치하는 곳.
  • 요소 (element) : 스택에 저장되는 것.

시스템 스택 : 시스템 스택을 이용한 함수 호출

스택 ADT

객체 : 0개 이상의 원소를 가지는 유한 선형 리스트.
연산 :

- create(size) ::= 최대 크기가 size인 공백 스택을 생성한다.
- is_full(s) ::=
			if(스택의 원소수 == size) return True;
			else return False;
- is_empty(s) ::=
			if(스택의 원소수 == 0) return True;
			else return False;
- push(s, item) ::=
			if(is_full(s)) return ERROR_STACKFULL;
			else 스택의 맨 위에 item을 추가한다.
- pop(s) ::=
			if(is_empty(s)) return ERROR_STACKEMPTY;
			else 스택의 맨 위 원소를 제거해서 반환한다.
- peek(s) ::=
			if(is_empty(s)) return ERROR_STACKEMPTY;
			else 스택의 맨 위 원소를 제거하지 않고 반환한다.
  • is_empty(s) : 스택이 공백상태인지 검사.
  • is_full(s) : 스택이 포화상태인지 검사.
  • create() : 스택을 생성.
  • peek(s) : 요소를 스택에서 삭제하지 않고 보기만 하는 연산.
  • pop(s) : 요소를 스택에서 완전히 삭제하면서 반환하는 연산. push 연산

배열을 이용한 스택의 구현

![](/images/a0f719679249d0e1.png) 1차원 배열 stack[]. 가장 먼저 들어온 요소는 stack[0]에, 가장 마지막에 들어온 요소는 stack[top]에 저장. top 변수 : 스택에서 가장 최근에 입력되었던 자료를 가리킴. 스택이 공백상태이면 top == -1 --- ### 스택의 구현 ``` #define MAX_SIZE 100

typedef int element; element stack[MAX_SIZE]; int top = -1; // 포화 상태 검출 함수 int is_full() { return (top == (MAX_SIZE-1)); } // 공백 상태 검출 함수 int is_empty() { return top == -1; } // 삽입 함수 void push(element item) { if(is_full()) { fprintf(stderr, “스택 포화 에러\n”); return; } else stack[++top] = item; } // 삭제 함수 element pop() { if(is_empty()) { fprintf(stderr, “스택 공백 에러\n”); exit(1); } else return stack[top–]; } // 피크 함수 element peek() { if(is_empty()) { fprintf(stderr, “스택 공백 에러\n”); return; } else return stack[top]; }

### 스택의 요소를 구조체로 정의하기
스택에 저장되어야 하는 값이 정수나 문자가 아니고 더 복잡한 구조를 갖는 요소 → 스택에 구조체를 저장하여 구조체 안에 필요한 모든 정보를 저장하여 해결.

#define MAX_SIZE 100

typedef struct { int x; char name; }Stack;

Stack stack[MAX_SIZE];

// 공백 상태 검출 함수 int is_empty() { return top == -1; } // 포화 상태 검출 함수 int is_full() { return top == MAX_SIZE-1; } // 삽입 함수 void push(element item) { if(is_full()) { fprintf(stderr, “스택 포화 에러\n”); return; } else stack[++top] = item; } // 삭제 함수 element pop() { if(is_empty()) { fprintf(stderr, “스택 공백 에러\n”); exit(1); } else return stack[top–]; } // 피크 함수 element peek() { if(is_empty()) { fprintf(stderr, “스택 공백 에러\n”); return; } else return stack[top]; }
