2. 자바 프로그래밍 기초

2025년 8월 27일 Java(교재)

자바 프로그램 구성 요소

클래스(Class)

- 자바와 같은 객체 지향 언어의 기본적인 빌딩 블록. - 클래스들이 모여 하나의 자바 프로그램을 이룬다. ![](/images/5a571e362d606759.png) ### 클래스와 소스 파일 이름 → 자바에서 소스 파일 이름은 항상 public이 붙은 클래스의 이름과 동일해야 한다.(public이 없는 경우 실행자가 파일을 실행할 수 없다.) 💡자바에서는 소스 파일 이름과 클래스 이름이 상당한 관련이 있다. 일단 하나의 소스 파일 안에는 하나의 클래스만이 있는 것이 바람직하지만 하나의 소스 파일 안에 여러 개의 클래스가 들어 있을 수 있다.

- 소스 안에 public 클래스가 하나 있다면 반드시 소스 파일의 이름은 public 클래스의 이름과 일치해야 한다. 다른 클래스는 public 클래스가 아니어야 한다.
- 만약 하나의 소스 파일 안에 public 클래스가 없다면, 소스 파일 안에 포함된 어떤 클래스의 이름으로 하여도 상관없다.
- 하나의 소스 파일 안에 public 클래스가 2개 이상 있다면 컴파일 오류가 발생한다.

메소드

- 입력을 받아서 어떤 처리를 하고 처리의 결과를 돌려주는 코드들의 모임. - 클래스 안에 정의딘 함수. ![](/images/b193b2d3140fb28a.png)

자바 프로그램의 일반적인 구조

- 일반적으로 하나의 소스 파일은 하나의 클래스를 포함하고 있다. - 하나의 클래스 안에는 여러 개의 메소드가 포함될 수 있으며 하나의 메소드 안에는 여러 개의 문장이 포함될 수 있다. ![](/images/f09b65d7fdad94a7.png)

문장

- 사용자가 컴퓨터에게 작업을 지시하는 단위. - 문장은 프로그램을 이루는 가장 기초적인 단위가 된다. ![](/images/1ec75a2aaefd1754.png)

주석

  • 주석은 소스 코드가 하는 일을 설명하는 설명글.
  • 프로그램의 실행 결과에 영향을 끼치지 않는다. /* text */ → 주석의 시작 : /* , 주석의 끝 : */ ⇒ 여러 줄의 주석 처리를 할 때 사용한다.

    //text → // 에서 줄의 끝까지가 주석 ⇒ 한 줄짜리 주석을 작성할 때 사용한다.

변수와 자료형

변수

  • 데이터를 담아두는 상자.
  • 알파벳 문자와 숫자, 밑줄 문자()로 이루어진다. 한글 이름도 가능하다.
    - 첫 번째 문제는 반드시 알파벳 또는 밑줄 문자(    )로 시작해야 한다. 숫자로 시작할 수 없다.
    - ‘%’, ‘&’, ‘#’와 같은 특수 문자는 사용할 수 없다. 단 ‘$’와 ‘_’는 가능하다.
    - 대문자와 소문자를 구별하여 서로 다른 것으로 취급한다. 따라서 index, Index, INDEX는 모두 서로 다른 변수이다.
    자바 언어 키워드(if, while, true, false, null, …) 와 같은 이름은 허용되니 않는다.

자료형

  • 변수에 저장되는 데이터의 타입.

기본 자료형 vs 참조 자료형

### 기본 자료형 (Primitive Data Types) - 단순한 값을 저장하는 데이터 타입 - 변수에 실제 값이 직접 저장됨 - 종류: boolean, byte, char, short, int, long, float, double - 스택(Stack) 메모리에 저장됨 - null 값을 가질 수 없음 ### 참조 자료형 (Reference Data Types) - 객체의 주소를 저장하는 데이터 타입 - 변수에는 객체의 메모리 주소(참조)가 저장됨 - 종류: 클래스, 인터페이스, 배열 등 - 힙(Heap) 메모리에 객체가 저장됨 - null 값을 가질 수 있음 💡 기본 자료형은 메모리에 값 자체가 저장되지만, 참조 자료형은 객체의 주소값이 저장됩니다. 따라서 참조 자료형 변수를 다른 변수에 할당하면 같은 객체를 가리키게 됩니다. ### 자바의 기본 자료형 종류
자료형 설명 크기(바이트) 범위
byte 부호있는 정수 1바이트 -128\~127
short 부호있는 정수 2바이트 -32,768 \~ 32,767
int 부호있는 정수 4바이트 -2,147,483,648 \~ 2,147,483,647
long 부호있는 정수 8바이트 9,223,372,036,854,775,808 \~ 9,223,372,036,854,775,807
float 부동소수점형 4바이트 ±3.4 × 10\^-38 \~ ±3.4 × 10\^38
double 부동소수점형 8바이트 ±1.7 × 10\^-308 \~ ±1.7 × 10\^308
char 문자형 2바이트 \\u0000 \~ \\uFFFF
boolean 논리형 1바이트 true, false

문자형

- 문자형 char을 이용하여 하나의 문자를 저장할 수 있다. - 자바에서는 모든 문자를 2바이트의 유니코드(unicode)로 나타낸다. ```java char ch1 = 'a'; char ch2 = '\uac00'; ```

리터럴

  • 소스 코드에 직접 쓰여 있는 값. → ex) x = 100; 에서 100을 의미
  • 리터럴에는 정수형, 부동소수점형, 문자형 등의 여러 가지 타입이 있다.

논리형 리터럴

  • 참과 거짓을 나타내는 데 사용된다.
  • 논리형 리터럴은 true / false 만을 가질 수 있다.

상수

  • 프로그램이 실행되는 동안 값이 변하지 않는 수 또는 변경 불가능한 수.

문자열

  • 문자들의 모임
String s1 = "Hello";
String s2 = "World!";

형변환

- 산술적인 연산을 하기 위해 피연산자의 데이터 타입을 통일시켜야 한다. ```java double sum = 1.3 + 12; // == 1.3 + 12.0 ``` ![](/images/1771857b2e8bd774.png) ### 강제적인 형변환 ```java int x = 3; double y - (double) x; // 정수형 변수 x를 강제로 부동소수점형 변수 double로 형변환한다. ```

import

- 자바에서 클래스를 불러와 사용하기 전에 import 문장을 사용하여 불러와야 한다. ```java import java.util.*; ```

Scanner 클래스

  • 키보드로부터 바이트 값을 받아 불리자를 이용하여 각 바이트들을 토큰(token)으로 분리한다.
  • 특별한 지정을 하지 않으면 분리자는 공백문자이다.

수식과 연산자

  • 수식은 피연산자와 연산자로 이루어진다.
  • 연산자(operator) : 특정한 연산을 나타내는 기호
  • 피연산자(operand) : 연산의 대상
  • 산술 연산자
![](/images/529fd0e95f1f4782.png) ### 관계 연산자(Relational Operator) - 두 개의 피연산자를 비교하는 데 사용된다. ![](/images/855ae8c83ff5655c.png) ### 논리 연산자 - 여러 개의 조건을 조합하여 참인지 거짓인지를 따질 때 사용된다. ![](/images/63d648d673b5db87.png)

조건 연산자

absolute_value = (x > 0) ? x: -x; // 절대값 계산
max_value = (x > y) ? x: y; // 최대값 계산
min_value = (x < y) ? x: y; // 죄소값 계산
